# 低吸趋势因子 v4 研究报告（2026-08-05）

## 一、研究背景

- 起点：`量化因子研究/低吸研究/`（主人 15 个个人案例体系）+ `task/低吸因子错误样本分析.txt` 中主人对 **6 个趋势低吸坏样本**（双枪科技 05-20、东方新能 03-30、西部材料 04-23、多氟多 05-22、风华高科 03-02、科伦药业 07-16，D+1 全部 -10%）的逐条盘感分析。
- 方法：把主人的每条盘感转成可计算特征 → 在近半年（32,851 个趋势候选）和全量 811 交易日（290,618 个趋势候选）上做单调性交叉验证 → 保留总体成立的根因子，否决不成立的 → 落地为规则。
- 数据：raw_unadjusted（qfq 同步未完成，探索级）；D+1 收盘到收盘标签，排除一字板。

## 二、最终保留的因子（只有这两个根条件 + 一个基础形态）

### 基础形态：安静 K 线（candle_quiet）
- 定义：D 日振幅 ≤ 5%（(high-low)/前收）。
- 依据：全量最单调变量。振幅 <3%: +0.013% → 3~5: -0.031 → 5~7: -0.176 → 7~10: -0.322 → ≥10: **-0.734%**。
- 含义（主人原义）：小阴小阳的下影线低点才算回踩；嘈杂 K 线的影线是噪音。

### 根条件 1：首阴追高否决（trend_first_crack_chase）
- 定义：嘈杂 K 线（振幅>5%）**且** 收盘没回到 MA5（c5≥0）**且** 昨日仍在涨（prior_daily_return>0）。
- 含义：大涨后的**第一根**分歧巨震，追高买首阴；昨日已跌说明分歧已开始释放，才算低吸语境。
- 依据：全量单调 —— 昨日 <-5% 组 -0.058% → 昨日 ≥5% 组 **-0.867%**；否决集 n=33,143 均值 -0.340%/中位 -0.739%，是趋势族最毒的子集。
- 成绩：**6/6 坏样本全部命中**（昨日涨幅 +0.29~+10.03）。

### 根条件 2：趋势过伸否决（trend_overextended）
- 定义：当前 M5-M10 距离 ≥ 本段多头趋势内此前每次 M5 回踩日距离中位数 + 2 个百分点。
- 含义（主人"相较于前面每次回踩过高"的原义）：相对**本段自己的回踩签名**判断趋势老嫩，不用绝对阈值。
- 依据：全区间单调 —— 超额 <0: -0.134% → 0~2: -0.134 → 2~4: -0.416 → 4~6: -0.630 → ≥6: **-1.049%**。

### 落地规则（`daily_factor_extended_discovery.py`）
- `v4_trend_quiet_pullback`：多头排列 + 安静 K 线低点回踩 MA5/MA10 + 非过伸（主人"小阴小阳低吸"最纯形态）。
- `v4_trend_authentic_pullback`：多头排列 + 低点回踩 MA5/MA10 + 非首阴追高 + 非过伸（通用形态，quiet 是其子集）。

## 四、被数据否决的假设（诚实记录，勿再试）

1. 疲劳计数门禁（回踩次数越多越差）—— 总体不单调，3+ 次组反而回升。
2. M5 向 M10 极速靠拢（距离崩塌）否决 —— 方向反了，距离**扩张**才差；且有一鸣 07-27（崩塌-7.2 但次日涨停）反例。
3. M5 曾下穿 M10 否决 —— 区分度太弱（-0.383 vs -0.352）。
4. 距 20/60 日高点门禁 —— 小样本方向在总体上**反转**（离高点远的桶更差，=趋势坏掉）。
5. 缩量救巨震 —— 嘈杂+跌回 MA5 桶内缩量组仍全负（-0.61~-0.76）；华电辽能 04-30 是妖股幸存者。
6. 长上影+无下影"失败拉起"签名单独否决 —— 近半年方向不成立（上影连续变量有效，已含于振幅/首阴逻辑）。
7. 绝对位置（c30/前 10 日涨幅）区分好坏 —— 华建案例与坏样本完全重叠（前 10 日涨幅 +38~+54% vs +12~+38%）。

## 五、关键认知（与主人协作得出）

1. **华建集团案例的真身** = 连板妖股首阴后 MA5 连线低吸（4 连板 → 09-17 首阴 → 09-18~24 低点贴 MA5 五天 + 缩量 → 第二波 4 连板），属打板/龙头语境。它与坏样本在日线上不可分（底噪），最终靠"昨日已跌 vs 昨日仍涨"恰好分开。
2. **华电辽能 04-30 不是小阴线**（双数据源核实 -4.89%、振幅 11.6%）；主人描述的"小阴线+价格控制好"与其《量化因子研究/低吸研究/低吸研究-2026.md》中 03-05 案例（振幅 2.1%）原文一致，系两个案例记忆叠加。04-30 能保留是因为：昨日已跌 + 收盘真跌回 MA5 下方。
3. **趋势族 D+1 仍整体为负**：v4 把负期望削掉 90% 但不翻正，行情主导的老结论未变。D+1 翻正要等大盘择时门禁。
