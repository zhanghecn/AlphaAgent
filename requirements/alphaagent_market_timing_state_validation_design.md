# AlphaAgent 金银手指持续状态验证设计

## 背景

现有市场择时回测以金银事件为样本，分别评估候选日或确认日之后的收益。但产品
展示的是持续状态：一个确认金会一直显示到确认银，一个确认银会一直显示到确认金。
用户每天看到的是“当前为金还是银”，不是当天是否刚产生事件。

因此事件胜率不能回答以下问题：

- 金状态期间未来回报和最大回撤是否确实优于银状态。
- 新增失败银是否降低了金状态中的亏损暴露，还是只把反弹日标成银。
- 银状态持续太久时是否错过主要上涨。
- 扩大银触发是否带来短期反复切换。

本设计只增加研究和验证能力，不修改生产 v9 信号、API、页面或缓存结构。

## 比较版本

### v8 严格银基线

从当前事件列表中排除 `GOLD_FAILURE_SILVER`，再用
`build_active_directions` 重建持续状态。其余金、顶部银和结构银完全保留。

### v9 当前生产版本

使用完整当前事件列表构建持续状态。v8 和 v9 的唯一预期差异是
`2026-07-02` 失败银及其后的持续方向。

### 研究用波动迟滞版本

该版本只用于压力测试“更早翻银”是否值得，不进入生产信号。它以 v8 确认事件
作为基础状态，并允许金状态在当日收盘满足以下风险条件时立即切为银：

```text
up_ratio <= 0.25
bear_force >= bull_force
mom_5d < 0
并且满足以下任一条件：
  A. return_1d <= -1.5% 且 return_1d <= -2 * prior_20d_volatility
  B. close < MA20 且 trend_breakdown >= 60
```

`prior_20d_volatility` 只用当前日之前 20 个交易日的综合指数日收益标准差，
不把当天急跌放进自己的基准。银状态只由已确认金事件切回金，形成进入敏感、退出
严格的迟滞，避免每天按分数正负抖动。

这个版本故意采用可解释的宽阈值，不做网格调参。若它在时间切分中没有稳定改善，
结论应是拒绝扩大银触发，而不是继续加条件。

## 状态级评估

输入为与 `CompositeBar` 完全按日对齐的 `GOLD / SILVER / NEUTRAL` 序列。
首个确认事件前的 `NEUTRAL` 不参与方向统计。

固定观察周期为 `1 / 3 / 5 / 10 / 20` 个交易日。每个状态日 `t` 计算：

- `return_pct`：`close[t+h] / close[t] - 1`。
- `correct`：金要求收益大于 0，银要求收益小于 0。
- `directional_return_pct`：金使用原收益，银使用相反数；大于 0 统一表示方向正确。
- `adverse_excursion_pct`：金取 `min(0, 未来窗口最低收盘收益)`，银取
  `max(0, 未来窗口最高收盘收益)`；整个窗口没有逆向走势时统一记为 0。
- `adverse_3pct`：金的未来窗口最低收益 `<=-3%`，或银的未来窗口最高反弹
  `>=+3%`。

每个 `period × direction × horizon` 输出：样本日数、方向命中率、平均原收益、
平均方向收益、平均不利波动、最坏不利波动和 3% 不利波动比例。

时间段固定为：

- `ALL`：完整样本。
- `EARLY`：`< 2025-07-01`。
- `LATE`：`>= 2025-07-01`。

状态日高度重叠，不能把数百个日级样本解释为数百次独立交易。报告必须同时输出
状态运行统计：金/银覆盖天数、连续区间数、平均区间长度、金银转换次数，以及
持续不超过 3 个交易日的短区间数量作为抖动代理。

## 数据与因果边界

- 状态构造只读取 `<=t` 的确认事件、因子、综合指数收益和参与度。
- 波动基准只读取 `<t` 的 20 日收益。
- 未来 `t+1..t+h` 价格只进入回测标签，不参与状态生成。
- 修改某日之后的价格、因子和参与度不能改变该日及以前的状态。
- 所有指标均从状态日收盘起算，继续声明 `executable=false`，不等同于下一开盘
  可成交收益。

## 决策标准

本轮不自动上线新算法。研究迟滞版本只有同时满足以下条件才值得进入下一轮设计：

- `EARLY` 和 `LATE` 的银状态 5 日平均原收益都小于 0。
- 两段银状态 5 日方向命中率都不低于 60%。
- 金状态未来 5 日 `adverse_3pct` 比 v9 明显下降。
- 银状态未来 5 日 `adverse_3pct` 没有明显上升。
- 短区间数量和转换次数没有显著膨胀。
- 参数和状态前缀满足无未来函数测试。

若未通过，生产版本继续保持 v9，报告明确记录失败，不围绕 7 月 2 日继续调参。

## 验收

- 合成序列能复现逐日收益、不利波动和时间切分统计。
- 合成状态能复现区间长度、转换数和短区间数。
- 研究迟滞状态只在当日条件成立后切银，修改未来数据不改变历史前缀。
- 真实对照中 v8/v9 只从 2026-07-02 开始不同。
- 市场择时后端测试、完整前端测试和生产构建保持通过。
- 真实报告包含样本限制、重叠日级样本说明和生产版本保持/变更结论。
