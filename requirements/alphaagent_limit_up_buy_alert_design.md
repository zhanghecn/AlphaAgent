# AlphaAgent 打板买点涨幅与提醒设计

## 状态

- 设计日期：2026-07-15。
- 用户已批准：实时买点展示当前涨幅，并增加声音、浏览器通知和手动测试。
- 产品范围：现有 `/limit-up` 综合首板实时操作列表；不改变选股、买点或账户算法。

## 交互

1. 实时候选由后端透传信号时点的 `last_price` 和 `change_pct`。买点行在触发价旁显示
   “现价 / 现涨 / 距板”，缺失字段显示 `-`，不得用之后快照回填。
2. 实时页顶部增加铃铛图标按钮。用户点击后才申请浏览器通知权限并初始化声音，设置保存
   在浏览器本地；再次点击关闭提醒。
3. 提醒启用后显示扬声器测试按钮。点击后立即播放与真实买点相同的短提示音，并发送
   “AlphaAgent 买点提醒测试”浏览器通知，方便在没有买点时验证。
4. 真实提醒只处理 live、非 stale、非盘后计划的 `trigger_ready/actionable` 信号。通知包含
   股票名称、代码、当前涨幅、距板和策略名称；点击通知聚焦当前页面。
5. 同一轮询结果不重复提醒。按交易日和股票保存最近提醒时间；信号离开买点后重新进入且
   距上次提醒不少于 60 秒时允许再次提醒。

## 浏览器边界

- 自动播放和通知权限必须由用户手势解锁，页面不在首次加载时弹权限框。
- 通知被拒绝时保留声音提醒和手动声音测试，并在按钮提示中说明权限状态。
- 当前不引入 Service Worker 或服务端推送。页面完全关闭后无法继续发现新买点；浏览器
  保持页面打开或后台标签页时可提醒。
- 不添加音频资源文件，使用 Web Audio API 生成短双音，避免资源加载失败和许可证问题。

## 验证

- 后端测试验证实时信号透传当时 `last_price/change_pct`。
- 前端纯函数测试覆盖买点识别、首次提醒、重复轮询去重、60 秒冷却和 stale/盘后排除。
- 前端组件构建验证通知 API 不可用或权限被拒绝时不抛异常。
- Vitest、TypeScript、生产构建、Docker 页面和手动测试按钮全部通过后部署。
