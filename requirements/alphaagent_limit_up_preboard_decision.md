# AlphaAgent 首板板前决策合同

## 目标

在不改变当前正式打板质量规则、二进三、两仓、费用和 D+1 官方收盘退出的前提下，
对已经通过首板高质量门的股票持续计算板前触板概率，并在严格低于涨停价时形成可审计的
概率观察排序。历史复测与实时推荐必须调用同一质量评估、特征、模型、状态和选择函数；
只有历史账户和独立前向账户先后晋级后，排序结果才允许成为正式行动信号。

## 不变基线

- 历史：`limit-up-history-v15`
- 实时：`limit-up-live-v15`
- 调度：`limit-up-scheduled-v9`
- 现金账户：`limit-up-cash-v5`
- 每日最多两个仓位
- D+1 使用官方日线收盘价并扣除正式费用
- 二进三规则和订单逐笔不变

正式历史首板使用当天真实触板事件生成候选，只能作为 A 基线和标签来源。它不能直接
作为板前母池，否则会把当天后来触板这一未来事实带入决策。

## 点时集合

```text
raw_capture_pool
  技术行情输入，可包含全市场，只提供点时行情和市场横截面统计。

eligible_first_board_pool
  使用当前正式同源规则，在当时已知信息上通过主板交易资格、首板身份、正式 lane 质量门
  和 prior-only D+1 盈利门的高质量母池。它在集合资格语义上先于 3% 观察线；底层适配器
  可以在股票首次达到观察线时才执行这次点时评估。

quality_pool
  eligible_first_board_pool 中涨幅已经达到 >=3% 且尚未触板的股票。只有本层股票可进入
  个股模型和页面观察池。

action_pool
  quality_pool 中进一步满足历史/实时同源的风险、完整分钟、严格板前价格、冻结双概率门
  和正式执行窗口的股票。市场、行业/概念、个股资金、换手和新鲜度只有在点时历史覆盖
  通过同源审计后才能升级为共享硬门；当前只作诊断和后续研究输入。

filled_pool
  action_pool 按时间顺序和冻结排序键选出的最多两个首板仓位。误报会真实占仓，后来股票
  不得替换。
```

`>=3%` 只启动观察，不是买点，也没有固定 5%、8%、9% 或 9.5% 买入档。
底层行情适配器可以为了计算横截面先取得全市场报价，但集合语义必须固定为“先通过正式
同源高质量过滤，再由 >=3% 激活观察”。普通 3% 股票不得成为候选、训练负样本或页面推荐。

## 复用的历史先验

以下字段继续来自当前 prior-only `historical_evidence`，新模型不得重新拟合或覆盖：

- `expected_d1_net_return_pct <- d1_money_effect_average_return_pct`
- `d1_win_probability <- d1_money_effect_win_rate`
- `seal_probability_given_touch <- seal_success_rate`
- `d1_win_probability_given_seal <- d1_money_effect_win_rate`
- 同股触板、封板、D+1 样本数和历史联合率

所有底层结算样本必须满足 `result_date < signal_date`。缺失先验只能观察，不得填零或进入
行动池。

## 动态模型

共享模型只输出：

- `touch_probability_3m`：从当前决策时点起三个交易分钟内进入正式首板触板基线的概率。
- `eventual_touch_probability`：从当前决策时点起到当日正式执行窗口结束前进入该基线的概率。

训练样本只能来自点时 `quality_pool`。负样本必须是同一质量池内后来未触板的股票，不能
使用普通全市场 3% 股票稀释。D 日最终 high/close、首次触板时间、最终封板、正式订单、
D+1 结果和成交代理价只能用于标签或结算。

## 状态和排序

- `observe`：进入 quality pool，持续显示概率和质量证据，不占仓。
- `prepare`：达到双概率门和共享环境要求，但尚未进入正式窗口或未抢到两个仓位，不占仓。
- `actionable`：严格板前、全部共享行动硬门通过并被两仓选择器选中；只允许在
  `shadow/formal` 执行模式出现。
- `missed`：报价已经达到涨停价，或状态为 `sealed/resealed/failed`。
- `rejected`：质量或结构硬门失败。

行动排序依次为：D+1 预期净收益、D+1 胜率、三分钟触板概率、最终触板概率、触板后封板
概率、正式 lane 支撑分、决策时间、股票代码。旧 `buy_now` 和旧 `portfolio_selected`
只用于最近交易日根因诊断，不得限制新行动资格，也不再构成可选择的板前产品。

## 因果回放

- A：当前正式触板首板 + 原二进三，作为触板 benchmark 和正标签来源。
- C：同源点时 quality pool + 新双概率触发和新排序 + 原二进三，作为唯一模拟实时推荐的
  严格板前账户。

旧触发和旧两仓时序只用于解释“为什么触板后才显示”，不再形成产品、版本开关或晋级
比较对象。

冻结的历史股票日清单只作为完整行情路径的存储索引。清单中后来触板、封板、D+1 或
正式身份字段不得成为点时质量资格；装载每条路径后必须在每个 `decision_at` 重新运行
当前共享质量门。清单版本重建失败不得被误报为行情路径丢失，路径完整性和实时硬门历史
覆盖率必须分别审计。

行业/概念、个股资金、市场状态、当前换手和新鲜度无法按
`known_at <= decision_at` 重建时，必须标记 `parity_status=diagnostic` 且
`blocking=false`，既不能用日终值补造，也不能成为实时独有硬门。只有明确标记
`parity_status=shared` 的风险、窗口、完整分钟和严格板前价格可以阻断 C；量价-only
诊断仍不能替代实时同源账户验收。

A/C 使用相同正式费用、D+1 官方收盘和资金占用规则；A 从真实触板事件入场，C 从点时
高质量母池按概率触发。板前成交使用行动后第一条严格低于涨停价的新报价；一分钟代理
使用下一分钟开盘，等于涨停价或缺失即未成交。

逐时点源对象只在当日投影期间存在。特征投影完成后，回放行不得保留分钟前缀、完整行情
路径、横截面快照或原始逐笔序列；89 日冻结回放必须记录峰值 RSS，但不以固定内存阈值中止研究，
不得继续训练或把局部结果写成最终结论。

## 提升门

现有 89 日按 44 fit、15 calibration、30 validation 冻结。validation 不得调参。至少
20 笔严格板前成交，首板及联合账户 D+1 胜率不得低于同期正式基线 2 个百分点，复利不得
低于 90%，最大回撤不得恶化超过 2 个百分点，利润因子至少 1.5，双倍费用后复利仍为正。

模型不可用或概率资格门失败时只保留无概率观察，不得输出准备或行动。概率资格门通过但
历史账户门失败时可以展示研究概率和排序，执行效果固定为 `research_only`；历史账户门
通过后才能进入影子账本。独立前向账本通过相同门槛后，才允许整体替换旧首板触发和两仓
排序。自动下单和 L2 队列成交不在本合同范围。
