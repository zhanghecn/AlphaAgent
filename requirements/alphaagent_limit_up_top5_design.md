# AlphaAgent 龙头 Top5 量化打板设计

## 1. 设计状态

本设计已确认的产品方向：

- 第一版只做研究、盘中预警、模拟打板、盘后复盘和历史回测。
- 不连接券商实盘，不自动下单。
- 只覆盖沪深主板普通股票的 10cm 涨跌幅制度。
- 排除创业板、科创板、北交所、ST/风险警示、退市整理、无涨跌幅限制的新股阶段和异常停复牌股票。
- 不展示大而全的涨停候选池。系统只输出全市场龙头 Top5。
- 主链路固定为：情绪环境 -> 热门资金板块 -> 板块内龙几 -> 全市场龙 Top5 -> 封板/成交/次日收益评估。

本文是产品和算法设计，不包含业务代码实现。实施前需要据此生成单独的任务计划。

## 2. 目标与非目标

### 2.1 目标

系统需要回答五个实际问题：

1. 当前短线情绪是否允许打板。
2. 当前资金真正流入哪些热门概念板块。
3. 热门板块中谁是龙一、龙二，谁只是后排杂毛。
4. 某只股票在当前时点封板、排队成交和次日净盈利的概率分别是多少。
5. 从历史起点逐日、逐时点运行同一套规则，实际能选出什么股票，模拟成功率、收益和回撤是多少。

### 2.2 非目标

- 不复制或宣传网上未经审计的“游资 80%/88% 胜率”。
- 不把龙虎榜席位名称直接作为盘中硬规则；龙虎榜通常盘后才可见。
- 不用收盘后的最终封单、最终炸板次数或最后封板时间预测当天更早的下单决策。
- 不把触及涨停等同于可以买到。
- 不把现有 `mainline_dragon_pullback` 低吸策略改名为打板策略。
- 不在第一版模拟三板以上的高位接力买入。

## 3. 已核实的本地基础与缺口

### 3.1 可复用能力

AlphaAgent 已具备：

- `/mainline` 情绪走势图，包含涨跌家数、涨跌停、炸板代理、最高连板和总体晋级率。
- 概念板块即时、3日、5日、10日、20日资金流入口。
- 概念成分股、个股主力净流入、5日涨幅和近期涨停次数。
- 涨停池、昨日涨停池、强势池、炸板池和跌停池同步。
- 现有组合回测账本、订单、成交、持仓、权益、报告、成本压力和样本外验证能力。
- LightGBM、scikit-learn、pandas 和 numpy 依赖。

### 3.2 当前数据审计

本地 PostgreSQL 审计结果：

- `stock_daily_bars`：约 181 万行，6804 个交易日，范围为 1996-02-09 至 2026-07-09。
- `stock_minute_bars`：约 40 万行，只有 54 个交易日且股票覆盖不完整。
- `limit_pool_zt`：4847 条，只有 21 个交易日，范围为 2026-06-12 至 2026-07-09。
- `sector_fund_flows / 即时`：只有 15 个交易日，范围为 2026-06-18 至 2026-07-09。

结论：现有数据足够验证接口和页面，不足以给出可信的多年打板成功率和收益。长区间回测必须先补历史涨停事件、板块资金和盘中成交数据。

### 3.3 外部资料边界

公开资料中可验证的数据字段包括：

- Tushare `limit_list_d`：封单金额、首次封板时间、最后封板时间、炸板次数、涨停统计、连板数。
- AkShare/东方财富涨停池：封板资金、首次/最后封板时间、炸板次数、连板数，但官方说明只支持近期日期。
- 交易所规则：主板股票通常为 10% 涨跌幅限制，价格笼子、异常交易和虚假申报需要遵守现行规则。

这些日终字段可以支持事件研究，但不能单独证明排队能否成交。真实成交仿真仍需要 Tick、逐笔成交或至少盘口快照。

## 4. 产品语义

### 4.1 三种成功率必须分开

| 指标 | 定义 | 用途 |
| --- | --- | --- |
| 封板成功率 | 发出候选后，股票收盘仍封在涨停；另统计委托后是否再次开板 | 衡量选板能力 |
| 委托成交率 | 模拟委托在真实排队约束下成交 | 衡量策略可执行性 |
| 净盈利胜率 | 已成交交易按 T+1 退出规则，扣除费用和滑点后收益大于 0 | 衡量实际交易价值 |

主 KPI 是已成交组合的净收益、最大回撤和尾部损失。封板率只作为中间诊断，不能替代收益。

### 4.2 龙头 Top5

系统每天和盘中每个刷新时点最多展示五只股票：

- 普通候选必须来自热门资金板块，并且是该板块龙一或龙二。
- 同一板块默认最多进入两只，避免单一题材把 Top5 全部占满。
- 妖股没有额外候选名额。只有全市场身位、资金和封板强度足够高时，才能在同一排序中进入 Top5。
- Top5 是研究候选，不代表五只都可打；每只仍显示 `可打`、`观察` 或 `禁打`。

### 4.3 板型范围

| 板型 | 第一版处理 |
| --- | --- |
| 主线启动首板 | 主研究和模拟交易池 |
| 一进二 | 主研究和模拟交易池 |
| 二进三 | 条件研究池，只在修复/主升环境模拟，风险预算减半 |
| 三板以上 | 只观察、统计和用于计算龙头身位，不模拟买入 |
| 一字板、集合竞价直接封死 | 记录为强势事件，但默认不可成交 |
| 早盘秒板后不再开板 | 默认不可成交，不能计入模拟收益 |
| 炸板回封 | 单独建模，不与一次封死的涨停混为同一类 |

## 5. 用户界面

新增独立路由 `/limit-up`，不与当前 `/quant` 低吸候选混在同一策略语义中。

### 5.1 盘中工作台

第一屏按决策顺序展示：

1. 情绪走势图和当前阶段。
2. 最高身位、涨跌停、封板/炸板、一进二和二进三晋级、昨日涨停溢价。
3. 热门板块资金榜。
4. 全市场龙头 Top5。
5. 选中龙头的资金、量能、换手和封板力度证据。
6. 当前风险预算和禁打原因。

热门板块榜字段：

- 板块名称、资金排名和主线状态。
- 主力净流入金额和流入占比。
- 资金 1/3/5 日加速度和连续流入天数。
- 板块涨幅、上涨家数占比和成交额。
- 涨停家数、炸板家数、最高身位和梯队完整度。
- 板块 Top5 个股资金集中度。

龙头 Top5 字段：

- 市场龙位和板块内龙位。
- 股票、所属核心概念、首板/一进二/二进三和当前身位。
- 个股主力净流入、流入占比和对板块流入的贡献。
- 成交额、换手率、量比和触板前增量换手。
- 首次触板、当前最后回封、截至当前炸板次数和连续封板时长。
- 封单金额、封单/流通市值、封单/成交额。
- 封板概率、成交概率、次日净盈利概率。
- `可打`、`观察`、`禁打` 和可解释原因。

### 5.2 连板梯队

参考同花顺短线界面的有效信息，但使用 AlphaAgent 自己的设计：

- 左侧显示昨日首板、二板、三板及以上。
- 右侧显示今日实际晋级、断板和炸板。
- 分别计算一进二、二进三、三进四晋级率。
- 每一档显示昨日股票今日竞价溢价、开盘溢价和收盘溢价。
- 支持点击股票进入 `/stocks/:vtSymbol`。

### 5.3 盘后复盘

- 展示当日 Top5 在每个决策时点的排名变化。
- 展示候选、委托、未成交、成交、开板、回封和收盘结果时间线。
- 明确区分“选对但买不到”“成交后封住”“成交后炸板”。
- 次日更新开盘、最高、最低、收盘和模拟退出收益。

### 5.4 回测页签

- 选择策略版本和历史范围，不向普通用户暴露大量实验开关。
- 显示数据覆盖和成交模型可信度。
- 展示 Top1 至 Top5 分层结果、板型分层、情绪分层和年度分层。
- 展示权益曲线、回撤、月度收益、最差交易、未成交订单和参数稳定性。

### 5.5 大盘云图

云图保留为二级视图：

- 面积可切换板块成交额、主力净流入绝对值。
- 颜色显示涨跌或资金流入/流出。
- 点击板块联动龙头 Top5 和板块详情。
- 云图不直接产生买入信号，主决策仍以资金榜、梯队和龙头排序为准。

## 6. 情绪周期

复用现有 `/mainline` 情绪走势图，在同一数据语义上增量扩展，不新建相互冲突的情绪算法。

阶段固定为：

`冰点 -> 修复 -> 主升 -> 分歧 -> 高潮 -> 退潮`

新增输入：

- 分板位晋级率，而不是只有总体晋级率。
- 昨日涨停股今日竞价、开盘和收盘溢价。
- 昨日炸板股今日亏钱效应。
- 龙头 Top5 平均封板强度和平均次日溢价。
- 热门板块资金净流入、扩散宽度和资金集中度。

默认交易语义：

- 冰点：不打或只观察首个强修复信号。
- 修复：允许主线首板和一进二试错。
- 主升：允许首板、一进二；二进三风险预算减半。
- 分歧：只允许主线龙头的可验证回封，禁止后排。
- 高潮：降低预算，不追高位一致加速。
- 退潮：停止打板，等待修复。

阶段阈值使用滚动历史分位数和状态转移确认，不使用永久固定的涨停家数阈值。

## 7. 热门资金板块模型

### 7.1 初始可解释基线

第一版先建立可审计的板块基线分数：

```text
sector_score =
    0.25 * net_inflow_amount_percentile
  + 0.20 * net_inflow_ratio_percentile
  + 0.15 * inflow_acceleration_percentile
  + 0.15 * relative_strength_percentile
  + 0.10 * breadth_percentile
  + 0.15 * limit_up_structure_percentile
```

所有输入使用同一时点可见数据做横截面分位数，避免不同数量级直接相加。

### 7.2 必须同时看金额和比例

- 只看净流入金额会天然偏向大板块。
- 只看流入比例会放大小板块噪声。
- 板块价格上涨但主力明确净流出，标记为派发/退潮，不能排在热门资金板块前列。
- 板块资金缺失不等同于流出，标记为数据不足并降低置信度。

### 7.3 主线准入

一个板块进入龙头选择池，需要同时满足：

- 资金综合排名进入当日候选板块前列。
- 至少有一个可验证涨停或多个接近涨停的前排股票。
- 板块上涨宽度和成交活跃度不是单股独撑。
- 当前阶段不是明确资金派发。

## 8. 板块内“龙几”与市场龙 Top5

### 8.1 龙头特征族

板块内排序使用六类信息：

1. 身位：连续涨停板数、近期涨停次数、是否板块最高板。
2. 资金：个股主力净流入、流入占比、超大单/大单净流入、板块流入贡献。
3. 封板：首次触板、回封速度、截至当前炸板次数、连续封板时长、封单强度。
4. 量能：成交额、换手率、量比、触板前成交和换手是否失控。
5. 板块地位：是否核心业务成员、是否与资金主线一致、是否前排带动同板块股票。
6. 风险：高位天量、异常减持解禁、公告风险、低流动性和监管异常。

### 8.2 初始龙头基线

```text
dragon_score =
    0.25 * sector_strength
  + 0.20 * position_score
  + 0.20 * seal_strength
  + 0.15 * stock_fund_flow
  + 0.10 * volume_turnover_quality
  + 0.10 * auction_and_crowd_quality
  - risk_penalty
```

该加权分只是模型上线前的可解释对照组。最终默认排序必须与 LightGBM 三概率模型进行样本外比较，不能因为某组权重回测最好就直接上线。

### 8.3 杂毛排除

普通股票出现下列任一情况即不能进入 Top5：

- 不属于当时可见的热门资金板块。
- 在所属板块内不是龙一或龙二。
- 板块已有明显更高身位、更强资金和更早封板的同类型股票。
- 只是板块普涨中的后排跟随，不能带动板块扩散。
- 个股上涨但板块和个股资金均在明显流出。

### 8.4 妖股规则

妖股只是一类可观察的高辨识度样本，不是免检通道。进入 Top5 必须满足：

- 身位接近或等于全市场最高板。
- 个股资金和成交容量真实，不是低流动性小单封死。
- 封板强度进入当日同板型前列。
- 当前情绪不是明确退潮，且没有严重监管/公告风险。
- 与普通候选使用同一 Top5 名额和三概率决策。

## 9. 封板力度特征

### 9.1 时点特征

下单时可使用：

- 当前封单金额。
- 封单金额/流通市值。
- 封单金额/当日累计成交额。
- 涨停买一队列/最近 1 分钟成交额。
- 首次触板时点。
- 截至当前的开板次数。
- 最近一次开板到回封耗时。
- 当前连续封住时长。
- 触板前 1/3/5 分钟成交额、主动买入比例和换手增量。
- 涨停价成交量、撤单比例和队列变化；只有数据源提供时才使用。

### 9.2 仅用于标签和复盘的日终特征

- 最后封板时间。
- 全天最终炸板次数。
- 收盘最终封单金额。
- 收盘后龙虎榜和盘后公告。

这些字段不得进入同日更早的预测特征。

## 10. 三概率决策模型

### 10.1 封板模型

预测：`P(close_sealed | information_at_t)`。

标签同时保留：

- 收盘是否涨停。
- 委托后是否开板。
- 开板后是否回封。
- 从委托到收盘的封板时长占比。

### 10.2 成交模型

预测：`P(fill | order_at_t, queue_state)`。

成交模型独立于封板模型。最强的秒板往往最难成交，不能因为封板概率高就假设买到。

### 10.3 次日收益模型

预测：

- D+1 开盘、最高、最低、收盘净收益分布。
- 按固定退出和规则退出计算的扣费收益。
- 跌停无法卖出的尾部概率。

### 10.4 最终决策

```text
expected_value =
  P(fill)
  * (
      P(seal) * expected_return_if_sealed
      + (1 - P(seal)) * expected_return_if_failed
    )
  - transaction_cost
  - tail_risk_penalty
```

`可打` 需要期望值为正、尾部风险达标且通过硬门槛；`观察` 表示有龙头地位但成交或收益置信度不足；其余为 `禁打`。

## 11. 早盘秒板与排队成交仿真

### 11.1 核心原则

- 一字板和集合竞价后始终封死：成交率按 0 处理。
- 早盘数秒内封板且之后未开板：基础模型按未成交处理。
- 日线或普通 1 分钟 K 线无法证明排队成交，不允许默认成交。
- 只有逐笔/盘口数据能够确认队列前方卖单被消耗到模拟订单位置时，才记录真实模型成交。

### 11.2 三种成交口径

每次回测必须同时输出：

| 口径 | 成交条件 | 用途 |
| --- | --- | --- |
| 悲观 | 委托后真实开板并再次回封，或逐笔成交明确穿透模拟队列 | 可执行下限 |
| 基准 | 使用盘口队列、涨停价成交量、撤单和模拟订单位置计算 | 产品主结果 |
| 乐观 | 非一字板且委托后涨停价成交量达到宽松阈值 | 研究上限，不能作为宣传结果 |

如果历史只有日终涨停池：

- `first_time <= 09:31:00`、`open_times = 0` 的早盘秒板统一判定未成交。
- `first_time = 09:25:00` 或开盘即涨停且全天未开板统一判定未成交。
- 有开板记录的回封板只进入悲观/乐观场景，主结果标记缺少队列证据。

这些时间规则是缺少 Tick 数据时的保守代理。获得逐笔数据后，基准结果必须替换为队列模型。

### 11.3 订单队列模型

模拟订单记录：

- 委托时间、价格、数量。
- 委托时涨停买一未成交数量。
- 委托前方估算队列。
- 后续涨停价主动卖出成交量。
- 后续撤单对前方队列的保守估计。
- 开板、部分成交、完全成交和收盘未成交状态。

默认不假设自己的订单享有队列优先级。

## 12. T+1 退出和组合模拟

### 12.1 退出对照组

为避免同时过拟合买点和卖点，先比较四个固定退出基线：

1. D+1 开盘可成交价退出。
2. D+1 09:35 可成交价退出。
3. D+1 10:00 可成交价退出。
4. D+1 收盘退出。

再研究一个规则退出：

- D+1 竞价和开盘明显弱于预期时尽早退出。
- D+1 强势晋级或保持板块龙头时允许持有。
- 跌停或无流动性时不能假设成功卖出，订单顺延并记录风险暴露。

### 12.2 组合约束

模拟盘默认：

- 全市场只从龙 Top5 产生订单。
- 同日最多 3 笔新委托。
- 单票最大初始资金占比 10%。
- 单板块最大初始资金占比 20%。
- 二进三单票预算为首板/一进二的一半。
- 情绪修复、主升、分歧使用不同总风险预算；高潮、退潮显著降低或归零。
- 未成交订单不占用最终持仓，但在排队期间占用可用资金。

## 13. 历史回测设计

### 13.1 历史逐时点选择

回测不能先取得当日最终涨停股票再反推候选。每个交易日必须：

1. 载入该时点以前可见的市场、资金、板块、个股和盘口数据。
2. 计算情绪阶段。
3. 计算热门资金板块。
4. 计算板块龙一、龙二和市场龙 Top5。
5. 当股票接近或触及涨停时生成模拟委托。
6. 按队列模型判断未成交、部分成交或完全成交。
7. 按 T+1 规则退出并更新组合净值。

### 13.2 与现有量化回测的关系

复用现有能力：

- `backtest_runs`、订单、成交、权益、持仓和指标持久化。
- 回测报告、CSV、年度/月度分段、成本压力和反过拟合诊断。
- 参数网格、walk-forward 和 PBO/CPCV 工具。

不得复用的旧假设：

- 现有 `legacy_next_open` 是 D 日信号、D+1 开盘执行，不能模拟同日涨停排板。
- 现有日线“涨停未买”逻辑不能证明盘中队列成交。

新增独立 `limit_up_queue` 执行模型和盘中事件驱动回测路径，同时保留现有报告接口形状。

### 13.3 数据目标

目标回测范围为 2020-01-01 至本地最新完整交易日：

- 全量沪深主板股票日线和证券状态历史。
- 每日涨停、炸板、首次/最后封板、开板次数和连板数。
- 概念成员的历史时点版本或可回放映射。
- 历史概念资金流；缺失时必须单列降级版本，不能用当前成员/资金冒充历史。
- 盘口/Tick 覆盖范围内运行基准成交模型。

如果精确盘口只能覆盖较短区间，报告必须拆成：

- 长区间信号/事件研究。
- 短区间真实可成交回测。

不得拼成一个未经说明的单一收益数字。

### 13.4 数据切分

在数据覆盖达到 2020 至今的前提下：

- 2020-2023：训练和规则发现。
- 2024：验证和阈值选择。
- 2025 至最新：锁定样本外测试。
- 另做 60 日训练、20 日测试、20 日步进的 walk-forward。

所有模型和阈值必须按时间顺序训练，禁止随机打乱未来样本。

## 14. 回测报告

### 14.1 核心指标

- 历史交易日和股票覆盖率。
- 每日 Top1/Top3/Top5 信号数。
- 一字/秒板不可成交数和比例。
- 模拟委托数、完全成交、部分成交、未成交和成交率。
- 封板成功、委托后炸板、回封和收盘未封。
- D+1 净胜率、平均/中位收益、盈亏比和利润因子。
- 组合总收益、年化收益、最大回撤、Sharpe、Sortino、CVaR。
- 最大连续亏损次数和最长回撤恢复时间。
- 资金容量、换手和交易成本敏感性。

### 14.2 必须分桶

- 首板、一进二、二进三。
- 龙1 至龙5。
- 冰点、修复、主升、分歧、高潮、退潮。
- 首次封板时间段和回封次数。
- 热门板块资金排名和资金流入强度。
- 封板强度、换手率、成交额和流通市值分位数。
- 年度、月份、市场环境和板块。
- 悲观、基准、乐观成交模型。

### 14.3 基准对照

- 所有可交易涨停等权。
- 所有热门板块首板等权。
- 只按身位排序。
- 可解释加权 `dragon_score`。
- LightGBM 三概率决策。
- 不考虑成交队列的虚假乐观模型，用于显示高估幅度。

## 15. 无未来函数和真实性测试

必须自动验证：

- 修改时点 `t` 之后的数据，`t` 及以前的情绪、板块、龙几和订单不变。
- 删除收盘最终封单和最终炸板字段，盘中候选仍能重算。
- 盘后龙虎榜和公告不能影响同日盘中候选。
- 当前板块成员不能覆盖历史成员关系而不留版本。
- 一字板和早盘秒板不会出现在已成交交易中。
- 只有涨停价成交量不足以穿透队列时，订单保持未成交。
- 跌停无法卖出时，不生成虚假卖出成交。
- 同一交易日多次计算使用固定运行版本和时间戳，不能读到稍后缓存。

## 16. 数据和服务边界

新增以下规范化业务对象：

- `limit_up_events`：日级涨停/炸板事实和最终结果。
- `limit_up_snapshots`：盘中触板、封单、开板、回封和队列快照。
- `sentiment_snapshots`：盘中情绪和分板位晋级状态。
- `sector_flow_snapshots`：板块时点资金、强度和覆盖质量。
- `limit_up_candidates`：每个决策时点的板块、龙位、特征和三概率。
- 回测账本继续使用现有 `backtest_runs`、`backtest_orders`、`backtest_trades`、`backtest_daily_equity` 和 `backtest_daily_positions`。打板运行在持久化参数中固定写入 `run_type=limit_up`，现有回测列表和 `_run_type_from_params` 扩展为支持 `limit_up` 过滤，不新增重复的打板账本表。

`stock_events.raw` 可继续作为原始落地点，但回测不能长期依赖中文 JSON 字段临时解析。需要规范字段、来源、采集时间、交易时间和数据可见时间。

## 18. 实施阶段和验收门

### 阶段 1：数据契约与覆盖审计

- 规范涨停事件、封板快照、板块资金和历史成员。
- 补历史事件数据。
- 输出数据质量报告。

验收：不能再把 21 日事件覆盖误写成多年回测可用。

### 阶段 2：情绪梯队和龙几基线

- 扩展现有情绪曲线。
- 实现分板位晋级。
- 实现热门板块和板块龙一/龙二。
- 输出市场龙 Top5。

验收：历史回放只使用当时可见数据，普通候选全部来自热门板块前排。

### 阶段 3：封板、成交和收益模型

- 建立可解释基线和 LightGBM 模型。
- 建立 `limit_up_queue` 成交模型。
- 秒板、一字板和队列不足严格未成交。

验收：触板数、封板数、成交数和盈利交易数能够完整对账。

### 阶段 4：历史回测与报告

- 从历史起点逐日逐时点生成 Top5。
- 运行 T+1 组合模拟。
- 输出长区间事件研究和精确成交区间报告。

验收：报告包含样本外、年度、情绪、板型、龙位、成交情景和成本压力结果。

### 阶段 5：前端工作台

- 上线 `/limit-up` 四个页签。
- 与 `/mainline`、`/stocks/:vtSymbol` 和现有回测报告联动。

验收：用户第一屏只看到资金主线和龙 Top5，不出现杂乱候选海洋。

### 阶段 6：模拟盘观察

- 连续记录至少 20 个交易日用于流程验证。
- 达到 60 个交易日后重新评估成交概率校准、收益稳定性和数据中断风险。

验收：模拟订单、排队、成交、封板、炸板和 T+1 退出全部可审计。

## 20. 最终设计决策

- 产品采用独立 `/limit-up` 工作台。
- 第一版只做沪深主板非 ST 10cm。
- 只输出龙 Top5，普通候选必须是热门板块龙一或龙二。
- 妖股不设额外通道。
- 热门板块以资金金额、流入占比、加速度、广度和涨停梯队共同判断。
- 决策必须同时建模封板、成交和次日净收益。
- 秒板和一字板默认不可成交；没有盘口证据时宁可低估成交，也不制造虚假收益。
- 复用现有回测账本和报告，但新增独立盘中事件和排队执行模型。
- 回测从历史逐时点选择 Top5，严格执行 T+1、费用、滑点、涨跌停和流动性约束。
