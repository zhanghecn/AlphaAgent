# AlphaAgent 稳定复利打板系统设计

## 1. 设计状态

- 用户确认日期：2026-07-10。
- 产品范围：沪深主板非 ST 的 10cm 股票。
- 当前阶段：研究、历史回放、代理回测和模拟交易，不接实盘自动下单。
- 核心原则：先验证成交后净期望，再控制回撤，最后讨论复利速度。

“稳定复利”是研究和风险目标，不是收益承诺。系统不得以单段历史收益、训练集胜率或未经核验的游资传闻宣称已经稳定盈利。

## 2. 目标与验收定义

系统需要完成四件事：

1. 判断当日是否应该空仓，而不是每天强制交易。
2. 在主线板块中识别真正前排、具有可成交机会的 0-2 只股票。
3. 分别估计成交、封板和扣费后收益，只有净期望为正才生成模拟交易计划。
4. 用仓位降档、连续亏损保护和动态退出控制尾部风险。

默认策略升级必须满足：

- 至少 500 个有效交易日，优先达到 750 个交易日。
- 至少 300 笔样本外可成交闭合交易。
- 最终留出集总收益为正。
- 样本外利润因子大于 1.25。
- 样本外最大回撤小于 15%。
- 双倍佣金、印花税和滑点压力下仍为正收益。
- 样本外滚动季度至少 60%为正。
- 单月、单股或单一题材对样本外总毛利润的贡献均不得超过 35%。
- 不同市场阶段下风险可控；退潮期不得依赖持续交易贡献收益。
- 概率模型在留出集完成校准检查，不能只比较排序准确率。

任何一项不达标，策略版本继续保留在研究区，不升级为默认模拟策略。

## 3. 非目标

- 不承诺百倍收益、固定年化或固定胜率。
- 不把营业部、网名或席位推断作为盘中硬因子。
- 不把一字板、封死秒板或队列未知订单假设为成交。
- 不通过删除亏损交易、使用未来字段或反复调留出集参数美化结果。
- 不向普通用户暴露大量参数开关。
- 不在 Tick/L2 和模拟盘验证完成前接入自动实盘。

## 4. 总体架构

```text
数据时点审计
  -> 情绪准入/空仓
  -> 主线板块资金
  -> 板块前排与形态
  -> 可成交概率
  -> 封板概率
  -> D+1收益分布
  -> 净期望过滤
  -> 仓位与风险预算
  -> T+1退出
  -> 逐日账本与样本外评估
```

系统仍展示研究 Top5，但模拟执行池每天允许 0-2 只。Top5 是解释和观察列表，不等于交易计划。

## 5. 数据时点与质量门槛

### 5.1 必需数据

- 交易日历、股票基础信息、ST/退市/上市状态。
- 复权日线和不复权实际成交价格。
- 涨停/炸板事件版本：首次触板、每次开板和回封、最终状态。
- 历史概念成员版本，不能用今天成员覆盖过去。
- 板块资金分钟快照：净流入金额、比例、加速度和扩散宽度。
- 个股资金、成交额、换手率和量比。
- 集合竞价价格、成交量、未匹配量及开盘状态。
- Tick/L2：买一队列、封单变化、撤单速度、逐笔成交和可成交队列位置。
- 指数、全市场涨跌家数、涨跌停、炸板、晋级和昨日涨停溢价。

### 5.2 时点规则

每个特征必须携带 `as_of_time`、数据来源和代理等级。决策时只能读取该时点已经发布或已经发生的数据。

- 前一日盘后计划只能使用 D 日收盘及以前数据。
- 竞价决策只能使用当日 09:25 已完成竞价数据。
- 首次触板决策只能使用首次触板时点及以前数据。
- 回封决策可以读取此前开板记录，不能读取后续最终封板结果。
- 最终封单、最终炸板次数和收盘状态只能作为标签和复盘结果。

缺少历史成员、竞价或 L2 时必须标记代理模式，不能静默当成真实成交回测。

## 6. 情绪准入与空仓模型

现有情绪服务已经实现冰点、修复、分歧、高潮、退潮五阶段。目标系统复用同一指标和历史点，并在样本验证后把持续增强的修复阶段拆分为“主升”；在拆分规则冻结前不得事后改写历史标签。目标输入包括：

- 涨跌家数和全市场宽度。
- 涨跌停数量及变化速度。
- 分板位晋级率。
- 炸板率和回封率。
- 昨日涨停竞价、开盘和收盘溢价。
- 龙头 Top5 的次日溢价和亏钱效应。
- 主线板块资金净流入、扩散宽度和集中度。

准入规则：

| 阶段 | 默认动作 | 允许形态 |
| --- | --- | --- |
| 冰点 | 空仓 | 只记录首次修复信号 |
| 修复 | 小风险试错 | 主线首板、一进二 |
| 主升 | 正常风险预算 | 主线首板、一进二，二进三减半 |
| 分歧 | 严格收缩 | 核心龙头换手回封 |
| 高潮 | 降低风险 | 禁止高位一致加速和后排 |
| 退潮 | 空仓 | 等待修复确认 |

阶段只是准入层，不直接保证交易。即使处于主升，候选净期望不足也必须空仓。

## 7. 主线板块模型

板块模型同时使用资金金额和资金比例，避免偏向大板块或放大小板块噪声。

```text
sector_score =
    flow_amount_percentile
  + flow_ratio_percentile
  + flow_acceleration
  + consecutive_inflow
  + relative_strength
  + breadth
  + limit_up_ladder
  - distribution_penalty
```

板块准入需要：

- 资金排名和资金加速度位于市场前列。
- 上涨宽度不是单股独撑。
- 存在首板、二板等可验证梯队。
- 价格上涨时没有明确大额资金派发。
- 历史概念成员和业务相关性达到数据可信门槛。

系统需要识别旧主线减速、新主线加速和分歧日切换，但不能根据未来几日涨幅反推“新主线”。

## 8. 候选形态与杂毛排除

第一阶段保留三种交易形态：

1. 主线启动首板。
2. 主线一进二。
3. 主线核心分歧换手回封。

二进三只在修复或主升阶段进入减半风险研究池。三板以上只观察，不进入默认模拟执行。

下列候选直接排除：

- 不属于当时主线资金板块。
- 在所属板块不是龙一或龙二。
- 明显中位跟风，板块已有更强同类型前排。
- 一字封死或秒板后没有可验证开板机会。
- 板块和个股同时资金流出。
- 高位天量、严重公告风险、异常监管或低流动性。
- 数据时点、历史成员或价格连续性不可信。

## 9. 三模型与净期望

采用规则边界加概率模型的混合架构：

### 9.1 成交模型

估计 `P(fill)`，特征包括首次触板时间、开板和回封路径、封单变化、撤单速度、排队位置、逐笔成交、换手和市场拥挤度。

在没有 L2 时：

- 09:31 前封死且没有开板：不可成交。
- 有开板后回封：仅记为保守代理成交。
- 非秒板但没有开板：队列未知，保守场景不成交。

### 9.2 封板模型

估计 `P(seal | fill)`，只使用委托时点可见的板块资金、市场情绪、板位、触板路径、封单变化、换手和前排带动。

### 9.3 收益模型

估计成交后 D+1 净收益分布，不只预测涨跌方向：

- 正收益概率。
- 平均盈利和平均亏损。
- 5%、25%、50%、75%、95%收益分位数。
- D+1 开盘、冲高、收盘和最差路径代理。

模型默认使用 LightGBM 对照可解释规则基线，并执行时间序列交叉验证和概率校准。模型身份、参数和特征版本必须随每次回测落入审计报告。

### 9.4 净期望

```text
trade_ev =
    P(fill)
  * (P(profit) * average_profit - P(loss) * average_loss)
  - commission
  - stamp_tax
  - slippage
  - queue_uncertainty_penalty
```

只有 `trade_ev > 0`、净期望的 80% bootstrap 置信区间下界大于 0、样本数量达标的候选才进入默认模拟执行池。净期望排序后最多选择两只；没有达标候选时输出空仓。

三模型上线前，阶段一只生成 `research_plan` 供规则回测，不生成已达标的 `simulation_plan`。当前 18 日样本不足时页面必须显示“研究计划/样本不足”，不能把规则候选包装成正式可执行信号。

## 10. 仓位和风险预算

初始模拟风险规则不参与收益调参：

- 单笔计划风险不超过账户权益的 0.5%。
- 每日最多两个新仓。
- 同一板块风险敞口不超过当日预算的 50%。
- 组合回撤达到 5%：风险预算减半。
- 组合回撤达到 8%：风险预算降至四分之一。
- 组合回撤达到 12%：停止新开仓并进入策略审计。
- 当日已实现及压力估计损失达到 1.5%：停止新增计划。
- 连续 4 笔亏损，或最近 5 个交易日累计净亏损达到 2.5%，触发至少 3 个有效交易日冷却期；冷却结束后只有情绪进入修复或主升才恢复研究计划。

A 股 T+1 意味着买入当日不能卖出。回测和风险压力必须计算隔夜跳空和跌停无法退出，不能使用虚假的日内止损。

## 11. 退出模型

第一阶段保留两个透明基准：D+1 开盘退出、D+1 收盘退出。动态退出模型在有竞价和分钟数据后加入：

- D+1 竞价收益低于冻结收益模型的 25%分位数且板块进入退潮：集合竞价或开盘优先退出。
- D+1 竞价收益高于冻结收益模型的 75%分位数，但板块资金转为净流出或上涨宽度低于前一日一半：开盘后按预注册规则分批兑现。
- 核心股继续超预期且主线增强：允许持有，但必须使用当日可见状态逐分钟决定。
- 冲高回落、开板失败或板块资金反转：按规则退出。
- 达到最大持有时间：时间止盈/止损。

动态退出必须与固定退出基准做独立样本外对比。不得用当日最高价反推卖点。

## 12. 回测与反过拟合

### 12.1 逐事件回测

回测按真实决策事件推进：竞价、首次触板、开板、回封、收盘和 D+1 退出。每个决策只能看到此前状态。

必须记录：

- 候选、拒绝原因和空仓原因。
- 模拟委托、排队、撤单、未成交和成交。
- T+1 持仓、退出信号和真实可用价格。
- 费用、滑点、印花税和冲击成本。
- 单票、板块、情绪、板位和时间分桶。
- 权益曲线、回撤、连续亏损和尾部损失。

### 12.2 Walk-forward

- 最少 252 个交易日训练窗。
- 63 个交易日验证窗。
- 63 个交易日滚动测试窗。
- 最终至少 20%时间区间作为一次性留出集。
- 留出集只能在候选版本冻结后运行，不能反复用于调参。

比较对象包括：

- 当前固定 Top5 基线。
- 只加情绪空仓。
- 情绪加主线过滤。
- 再加成交模型。
- 完整三模型净期望系统。
- 固定退出与动态退出。

每一层必须通过增量归因说明收益来自哪里，不能只展示最终最优曲线。

## 13. 用户界面

`/limit-up` 保持一个默认策略版本，不向普通用户暴露实验参数。

### 13.1 今日决策

- 当前情绪阶段和动作：空仓、试错、正常、降仓。
- 当日风险预算、最大新仓数和停止原因。
- 热门板块资金、扩散和梯队。
- 研究 Top5，以及真正可执行的 0-2 只。
- 每只股票展示成交概率、封板概率、收益概率、净期望和数据可信度。
- 明确区分观察、计划、未成交、成交和退出。

### 13.2 历史日期

继续使用前一交易日、日期选择和后一交易日。切换后同步显示：

- 当日情绪和准入动作。
- 当时可见 Top5 和执行计划。
- 空仓/拒绝原因。
- 最终封板、成交代理和 D+1退出结果。
- 当日权益、仓位和风险降档状态。

### 13.3 回测研究

- 默认只展示冻结版本的样本外主报告。
- 显示数据覆盖、真实/代理成交比例和模型版本。
- 展示情绪、板位、龙位、板块、首次触板、开板次数和换手分桶。
- 显示 walk-forward 每个测试窗，不只展示合并收益。
- 显示成本压力、最差交易、未成交、空仓日和参数稳定性。

## 14. API 与模块边界

保留：

- `GET /api/limit-up/dates`
- `GET /api/limit-up/dashboard?date=`
- `GET /api/limit-up/backtest`

按阶段增加：

- `GET /api/limit-up/policy?date=`：情绪准入、风险预算和空仓原因。
- `GET /api/limit-up/decisions?date=`：研究 Top5 与实际 0-2 执行计划。
- `GET /api/limit-up/backtest/report`：冻结版本样本外报告。
- `GET /api/limit-up/backtest/windows`：walk-forward 窗口结果。
- `GET /api/limit-up/data-quality`：历史成员、竞价、分钟和 L2 覆盖。

业务规则放在 `alphaagent/server/services/limit_up/`，API 只处理参数和响应。复用现有情绪周期服务，不从 API 模块反向导入私有函数。

## 15. 错误和降级

- 没有有效交易日：返回 `empty`。
- 指定日期不存在：保留指定日期并返回前后有效交易日，不静默替换。
- 情绪数据不足：默认空仓，不回退为正常风险。
- 板块资金缺失：降低可信度，不能把缺失当作流出或流入。
- 历史成员缺失：候选只进入研究观察，不进入正式样本外结论。
- Tick/L2 缺失：只能运行代理成交，报告显著标记。
- 模型文件、特征版本或校准器不一致：拒绝生成计划。
- 数据出现非交易日、价格跳变或未来时间戳：隔离该日并写入数据质量报告。

## 16. 实施阶段

### 阶段一：空仓与规则闭环

- 把情绪阶段加入回测分桶。
- 建立准入动作和空仓原因。
- 执行池从固定 Top5 改为 0-2 只。
- 规则候选标记为 `research_plan`；在样本和三模型验收前，正式 `simulation_plan` 保持为空。
- 修复高位观察股仍进入回测等规则不一致。
- 加入风险预算和回撤降档账本。

### 阶段二：历史数据补齐

- 补至少 500 个交易日涨停事件版本和历史概念成员。
- 补竞价、板块分钟资金、个股分钟和首次触板路径。
- 建立数据质量与时点审计报告。

### 阶段三：三模型净期望

- 训练并校准成交、封板和收益模型。
- 完成 walk-forward、留出集和消融对比。
- 只在验收门槛全部通过后冻结默认版本。

### 阶段四：模拟盘

- 连续运行至少 60 个交易日。
- 比较预测成交和实际可成交代理偏差。
- 审计空仓、计划、未成交、退出和风险降档。
- 模拟盘不达标则回到研究阶段，不接实盘。

## 17. 第一阶段验收

第一阶段完成时必须满足：

- 页面每天可以明确输出空仓或最多两只执行计划。
- 冰点、高潮和退潮的风险动作可以逐日审计。
- 高位观察和数据不足候选不会进入模拟收益。
- 情绪阶段、板位、龙位、首次触板和开板次数分桶可见。
- 当前 18 日基线保持不被改写，并作为负期望对照组。
- 新规则在当前小样本上只能称为探索结果，不得升级为稳定策略。
- 定向测试、前端构建、API 和桌面/手机浏览器验收通过。
