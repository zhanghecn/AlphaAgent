# AlphaAgent 实时打板操作台设计

## 目标

把 `/limit-up` 从盘后研究页改成面向人工短线交易的实时操作台。系统在交易日直接回答某只主板股票应当“现在打、尾盘打、明早竞价或放弃”，保存当时推荐，并允许按日期和买点复核 D+1 结果。

## 用户范围

- 仅沪深主板非 ST 的 10cm 股票。
- 普通候选必须位于动态市场龙 Top5，同时是所属板块龙一或龙二。
- 用户不配置策略参数。系统根据时间、市场状态和盘口路径决定动作。
- 第一版只提供人工决策，不接自动下单。

## 操作通道

### 现在打

- 09:20-09:30 显示竞价打候选。
- 09:30-14:20 显示快封、扫板和回封候选。
- 候选必须通过实时市场、动态龙位和对应买点约束。

### 尾盘打

- 14:30-14:57 显示仍在动态 Top5、连续快照保持封住且板块未明显退潮的候选。
- 使用 14:30 分钟价或涨停价作为回测入场代理。

### 明早竞价

- 盘后根据当日封板、龙位和板块状态生成次日条件计划。
- 次日竞价只有落在可接受区间且未出现市场恶化时才转为竞价打，否则取消。

## 信号状态

每只候选沿以下状态推进：

`near_limit -> first_touch -> opened -> resealed_n -> stable_seal -> failed`

用户动作使用固定枚举：

- `buy_now`: 现在打。
- `wait_tail`: 尾盘确认。
- `next_auction`: 明早竞价计划。
- `pass`: 不打。

信号必须包含触发条件、失效条件、有效时间、数据时间和执行可信度。缺少 Tick/L2 时显示盘口代理，不声称真实排队成交。

## 数据与持久化

保留 `stock_events` 作为日终事件表，新增追加式 `limit_up_signal_snapshots`：

- `id`
- `trade_date`
- `captured_at`
- `session_stage`
- `strategy_version`
- `source`
- `source_updated_at`
- `market_context` JSON
- `candidates` JSON
- `recommendations` JSON
- `data_quality` JSON

交易时段每分钟同步一次实时涨幅榜、涨停池、炸板池、板块资金与情绪代理，并保存系统当时输出。相同分钟和策略版本幂等更新，不能覆盖其他时点。

## 推荐算法

算法按门槛顺序执行，不再用单一加权总分决定买入：

1. 市场门：当前情绪变化、主板炸板率、涨跌停扩散。
2. 龙头门：动态市场 Top5 可被后续强股替换，且候选是板块龙一或龙二。
3. 买点门：竞价、快封/扫板、回封、尾盘分别使用独立条件。
4. 历史边际门：对应历史样本满足最低样本数后才展示预期溢价；样本不足只降低可信度，不伪造胜率。

过期金银手指不参与打分。封单绝对额只作证据，连续快照中的封单变化、开板路径和封住时长优先。

## API

- `GET /api/limit-up/live`: 获取最新盘中快照和三个操作通道。
- `POST /api/limit-up/live/refresh`: 拉取并保存一次实时快照，供定时任务和人工刷新复用。
- `GET /api/limit-up/signals?date=...&as_of=...`: 获取某日某时点实际保存的推荐。
- `GET /api/limit-up/dates`: 合并盘中快照日期和日终事件日期。
- `GET /api/limit-up/backtest`: 增加 `entry_mode`，支持 `auction`、`sweep`、`tail`、`next_auction`。

## 回测口径

- 竞价打：D 日开盘入场，验证 D 日收盘和 D+1 开盘。
- 盘中扫板：D 日涨停价入场，验证 D+1 开盘/收盘。
- 尾盘打：D 日 14:30 分钟价或涨停价入场，验证 D+1 开盘/收盘。
- 明早竞价：D+1 开盘入场，验证 D+1 收盘和 D+2 开盘。

有保存快照的日期使用严格信号账本。旧日期使用日终代理并明确标注 `historical_proxy`，两类结果不得合并成同一个可成交结论。

## 界面

- 顶部固定显示交易日期、当前阶段、数据时间和刷新按钮。
- 第一屏是“现在打 / 尾盘打 / 明早竞价”三个操作通道，不使用营销式说明。
- 候选行显示股票、动作、触发价、龙位、板位、板块、回封路径、预期 D+1 和取消条件。
- 点击候选后显示盘前证据、盘中证据和结果，字段按可见时间分组。
- 历史日期复用同一布局，展示当时保存信号和最终结果。
- 回测区按买点切换，展示收益、胜率、回撤、硬亏损、封板率、成交可信度和逐笔记录。

## 验收标准

- 最新交易日可以返回三个通道及明确动作，响应带数据时间和质量状态。
- 后续强股可以替换早期 Top5，不再冻结最早五只。
- 历史查询只返回目标时点之前保存的信息。
- 四种买点回测分别计算，D+1 或 D+2 结果与入场日期一致。
- 无未来字段进入实时推荐；最终封板、日终封单和 D+1 行情只进入结果归因。
- 后端测试、前端测试、生产构建和桌面/手机浏览器验收通过。
