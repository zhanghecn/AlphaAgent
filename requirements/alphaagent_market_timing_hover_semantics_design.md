# AlphaAgent 金银手指悬停与方向语义设计

## 问题

市场择时页面已经区分三类数据，但展示仍容易混淆：

- `active_direction`：最近一次已确认手指形成的持续方向，直到相反手指确认。
- `zone_direction`：当日因子是否进入金手指或银手指候选区域。
- `event`：当日产生的候选事件及其确认、否决或待确认状态。

当前最近交易日表把 `active_direction=GOLD` 显示成“金行情”。例如
`2026-07-02` 的真实载荷为 `zone_direction=NEUTRAL`、无当日事件，但页面仍显示
“金行情”，用户会把最近确认方向误读成当日金手指区域。

K 线悬停还使用 Lightweight Charts 默认日期格式，只在时间轴显示英文日期，没有
A 股软件常见的日期、开高低收、涨跌幅和当日金银状态摘要。

## 已验证事实

- `2026-07-01`：`zone_direction=GOLD`，产生 `TREND_GOLD` 候选。
- `2026-07-02`：该候选被 `INVALIDATED`；当日
  `bull_force=53.6375`、`bear_force=55.4`、`zone_direction=NEUTRAL`、无新事件。
- `2026-07-02` 的 `active_direction=GOLD` 仅表示最近确认方向仍来自
  `2026-06-11` 金手指，不表示 7 月 2 日处于金手指区域。

## 目标

- 鼠标移动到 K 线时，按 A 股日 K 习惯显示完整中文日期和当日行情数据。
- 同时显示当日候选区域、当日事件，以及在当日完成确认或否决的候选。
- 页面不再把 `active_direction` 命名为当日“行情”或“手指区域”。
- 保留“已确认方向持续到相反手指确认”的状态规则，但明确它只是最近确认方向。
- 不调整金银识别阈值、事件日期、确认结果或回测数据。

## 方案

### 图表悬停

`TimingChart` 接收 `timing_series`，根据十字线日期关联 K 线与当日状态。图表顶部
设置一行固定高度的行情摘要，默认显示最新交易日，悬停时切换为鼠标所指交易日：

```text
2026-07-02  开 3990.12  高 4001.34  低 3950.20  收 3962.18  涨跌 -0.70%
候选区域 中性  最近确认 金未反转  确认结果 7月1日金候选已否决
```

具体规则：

- 日期固定为 `YYYY-MM-DD`。
- 涨跌幅使用前一根 K 线收盘计算；第一根没有前收时显示 `--`。
- `zone_direction` 显示“金候选区 / 银候选区 / 中性”。
- `active_direction` 显示“金未反转 / 银未反转 / 尚无确认”，标签为“最近确认”。
- 当日 `event` 显示候选方向和 `PENDING/CONFIRMED/INVALIDATED` 状态。
- 另按 `confirm_date` 反向索引事件；候选在悬停日完成确认或否决时，显示
  “7月1日金候选已否决”等结果。
- 鼠标离开图表后恢复最新交易日摘要。

Lightweight Charts 增加：

- `localization.locale="zh-CN"`。
- `localization.timeFormatter` 输出完整 `YYYY-MM-DD`，用于十字线日期标签。
- `timeScale.tickMarkFormatter` 使用紧凑中文日线刻度，不显示英文月份。

### 页面术语

- 主指环小标题由“当前行情”改为“最近确认”。
- 本轮说明改为“最近确认金手指 · 2026-06-12 确认 · 尚无银手指反转”。
- 最近交易日表的“行情状态”改为“最近确认”，单元格改为
  “金未反转 / 银未反转 / 尚无确认”。
- “候选区域”继续只读取 `zone_direction`，不得用 `active_direction` 覆盖。

## 数据流

```text
chart.bars + timing_series
          |
          +-> date -> K 线、zone、active、event
          +-> confirm_date -> 当日确认/否决结果
          |
          +-> 十字线悬停摘要
```

后端 API 不新增字段；前端复用现有 `chart.bars`、`timing_series[].active_direction`、
`zone_direction` 和 `event.confirm_date`。

## 边界处理

- 悬停时间找不到对应 K 线或状态时，恢复最新交易日摘要。
- 行情有当天实时 K 线但因子滞后时，候选区域显示“因子未就绪”，不得沿用前一日。
- 同一确认日若存在多个结果，按候选日期顺序全部展示，不静默覆盖。
- 手机端摘要允许按字段换行，但日期、数值和状态词组不得拆成孤立单字。

## 验收

- 十字线移动到 `2026-07-02` 时，日期显示 `2026-07-02`，候选区域显示“中性”。
- 同一悬停摘要显示“7月1日金候选已否决”，不显示“7月2日金手指区域”。
- 最近确认方向可显示“金未反转”，但视觉和文案上与“候选区域”分列。
- 时间轴和十字线日期不再出现英文月份。
- 鼠标移动时日期、OHLC、涨跌幅和状态同步更新；移出后恢复最新日。
- 桌面和手机无整体横向溢出，控制台无错误或警告。
- 前端测试和生产构建通过；后端事件载荷保持不变。
