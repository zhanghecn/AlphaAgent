# AlphaAgent 金银手指悬停与方向语义设计

## 问题

市场择时页面已经区分三类数据，但展示仍容易混淆：

- `active_direction`：最近一次已确认手指形成的持续方向，直到相反手指确认。
- `zone_direction`：当日因子是否进入金手指或银手指候选区域。
- `event`：当日产生的候选事件及其确认、否决或待确认状态。

上一版把 `zone_direction=NEUTRAL` 放进 K 线悬停主结果，导致用户在
`2026-07-02` 看到“中性”。这不符合产品定义：`2026-06-11` 金手指确认后，
用户结果应持续为金，直到银手指确认反转。`zone_direction` 只是内部候选诊断，
不能覆盖 `active_direction` 的金银结果。

K 线悬停还使用 Lightweight Charts 默认日期格式，只在时间轴显示英文日期，没有
A 股软件常见的日期、开高低收、涨跌幅和当日金银状态摘要。

## 已验证事实

- `2026-07-01`：`zone_direction=GOLD`，产生 `TREND_GOLD` 候选。
- `2026-07-02`：该候选被 `INVALIDATED`；当日
  `bull_force=53.6375`、`bear_force=55.4`、`zone_direction=NEUTRAL`、无新事件。
- `2026-07-02` 的用户结果是 `active_direction=GOLD`，应显示“金手指延续”。
  这表示 6 月 11 日金手指仍有效，不表示 7 月 2 日产生了一个新的金手指事件。

## 目标

- 鼠标移动到 K 线时，按 A 股日 K 习惯显示完整中文日期和当日行情数据。
- 悬停主结果只显示金手指或银手指延续，不显示中性候选诊断。
- 明确区分“手指延续”和“当日新手指事件”，避免把每个延续日理解成新信号。
- 保留“已确认方向持续到相反手指确认”的状态规则。
- 不调整金银识别阈值、事件日期、确认结果或回测数据。

## 方案

### 图表悬停

`TimingChart` 接收 `timing_series`，根据十字线日期关联 K 线与当日状态。图表顶部
设置一行固定高度的行情摘要，默认显示最新交易日，悬停时切换为鼠标所指交易日：

```text
2026-07-02  开 3990.12  高 4001.34  低 3950.20  收 3962.18  涨跌 -0.70%
手指状态 金手指延续  当日新手指 无
```

具体规则：

- 日期固定为 `YYYY-MM-DD`。
- 涨跌幅使用前一根 K 线收盘计算；第一根没有前收时显示 `--`。
- `active_direction` 显示“金手指延续 / 银手指延续”；首个确认事件之前显示
  “尚无手指”。
- 当日只有新的 `CONFIRMED` 或 `PENDING` 相反方向事件时才显示新手指；
  `INVALIDATED` 同方向候选不改变也不干扰当前金银结果。
- `zone_direction` 保留在 API 和测试中，不在用户悬停摘要中渲染。
- 鼠标离开图表后恢复最新交易日摘要。

Lightweight Charts 增加：

- `localization.locale="zh-CN"`。
- `localization.timeFormatter` 输出完整 `YYYY-MM-DD`，用于十字线日期标签。
- `timeScale.tickMarkFormatter` 使用紧凑中文日线刻度，不显示英文月份。

### 页面术语

- 主指环小标题改为“手指状态”。
- 本轮说明改为“金手指延续 · 2026-06-12 起 · 等待银手指反转”。
- 最近交易日表只保留“手指状态”，单元格显示
  “金延续 / 银延续 / 尚无手指”。
- 删除用户表格中的“候选区域”行；`zone_direction` 仅供内部审计。

## 数据流

```text
chart.bars + timing_series.active_direction
          |
          +-> date -> K 线与持续金银状态
          +-> 最新已知 active_direction 向实时报价日延续
          |
          +-> 十字线悬停摘要
```

后端 API 不新增字段；前端复用现有 `chart.bars` 和
`timing_series[].active_direction`。`zone_direction` 与否决候选继续留在载荷中，
但不进入用户主结果。

## 边界处理

- 悬停时间找不到对应 K 线或状态时，恢复最新交易日摘要。
- 行情有当天实时 K 线但因子滞后时，继续沿用最近已确认的金银状态；不得显示中性。
- 新的相反手指只有在 `CONFIRMED` 后切换，`PENDING/INVALIDATED` 不切换。
- 手机端摘要允许按字段换行，但日期、数值和状态词组不得拆成孤立单字。

## 验收

- 十字线移动到 `2026-07-02` 时，日期显示 `2026-07-02`，主结果显示
  “金手指延续”，不显示“中性”。
- `2026-06-12` 确认日至最新行情，在没有银手指确认前始终显示金手指延续。
- 图表只在真实事件日画金银箭头；延续日不新增箭头。
- 时间轴和十字线日期不再出现英文月份。
- 鼠标移动时日期、OHLC、涨跌幅和状态同步更新；移出后恢复最新日。
- 桌面和手机无整体横向溢出，控制台无错误或警告。
- 前端测试和生产构建通过；后端事件载荷保持不变。
