## 1. 因子条件总结

### L0 可执行性硬过滤（决策时点可观测，无未来函数）

| 条件 | 依据 |
|---|---|
| 只做主板 10cm（60/00）、非 ST | 创业板成龙率 0.46%、科创板 0% vs 主板 5.29% |
| 首板：D-1 收盘未涨停（< D-2×1.098） | 首板定义本身 |
| 非一字 / 非秒板 | 买不进（回测器成交假设必须与此一致，见 Phase 1） |

注意：**时间窗不是 L0 硬条件**（v2 修正）。两只 17 板妖王（锋龙/嘉美）首板是
13-14 点封的，若把 09:30-10:00 做成准入窗口会直接滤掉妖王。时间窗降级为
L2 打分因子：09:30-10:00 满分（成龙率 9.83%、D+1 +2.02%）、10:00-14:00 中性、
14:00-15:00 大负分（封板率 75.4% 但 D+1 仅 +0.66%、胜率 53.7%——封得住没溢价，
实操上 14:00 后不打新首板）。

### L1 负向排除（分位表最差桶）

- 深跌排除：`return_20d_pct < -8.5%`（成龙率 4.91% vs 基线 8.63%）或
  `drawdown_from_126d_high_pct < -21%`（Q1 3.99%）。
  - 豁免：`concept_max_return_20d ≥ +16.5%`（Q5 板块爆发——立新能源/爱丽家居的
    「深跌+板块爆发」次路径）。
  - ⚠️ 豁免规则主要来自 2 个案例（n 极小，有过拟合风险）。v4 对照若 B 版不如
    A 版，第一步先砍豁免再裁决，不要把豁免和深跌排除一起判死刑。
- 市场高潮日：首板数 ≥69 → 停手或减半（成龙率 4.77% vs 冷日 ≤32 只时 11.54%）。
  - ⚠️ **口径修正（v2）**：阈值 69 来自全日总数，全日数盘中不可知（未来函数）。
    实盘/回测统一改用**滞后温度**（D-1 全日首板数，或近 5 日均值，盘前可知），
    阈值由 Phase 0 用滞后口径重定（原 0.5877 的反向 AUC 是全日版，含未来信息，
    会虚高，滞后版需重测）。
  - 注：温度对成龙率单调（冷→热 11.54%→4.77%），但对 D+1 收益**非单调**
    （中温 39-51 只 D+1 +1.89% 最甜，冷日反而只有 +1.70%）——温度只做
    成龙率加权和风控门，不做 D+1 预期加分。

### 封单比专段（v2 重写：实时可用，回测禁用）

- **回测禁用（主人决定，确认）**：`seal_to_turnover_ratio` 0.5736 的历史值来自
  `stock_events` 的 EOD upsert（`data_sync._run_sync_limit_up_pools` →
  `_upsert_limit_up_events`，盘中快照互相覆盖，只留收盘终值）——13 个月历史
  只有盘后封单，进回测 = 未来函数。不进回测、不进 CANDIDATE_FACTORS。
- **早盘实时可算（已存在，无需新算法）**：东财涨停池 `stock_zt_pool_em` 盘中
  实时返回「封板资金」与「成交额」，live_service 每个扫描周期都在拉取；
  候选已带 `seal_to_turnover_ratio` / `seal_to_float_market_cap_ratio`
  （live_service.py:1326-1327），相邻快照间还有 `seal_amount_retention_ratio` /
  `seal_amount_change_pct`（live_service.py:2484-2497）。封板瞬间即可观测，
  零未来函数，Phase 2 直接接入实时打分。
  - 边界：涨停池只收录已封板的票——冲板过程中没有封单数据，首封瞬间才出现。
    这与买入决策时点（封板后排队/打板）天然对齐，不构成限制。
- **回测替代（可选，无未来函数）**：用分钟线构造封板质量代理——首封后 5/15
  分钟成交量干涸度（post-seal volume decay）、分钟级炸板次数、首封时刻累计
  成交额占全日比。Phase 1 先验证代理与 EOD 封单比的相关性，相关才启用。
- **前向积累**：`limit_up_live_trace_snapshots` 已 append 持久化雷达候选的
  `seal_amount` / `seal_to_turnover_ratio`（TRACE_CANDIDATE_FIELDS 含），但只
  覆盖雷达追踪票。若要全市场首板盘中封单历史，在 sync_limit_up_pools 加一张
  append 快照表（低成本）。建议提前到 Phase 1 顺手做——数据越早积累，未来
  可精确回测实时封单比的样本越厚。

### L3 组合基准（先验设定非事后搜索，wave 验证）

- 强势位+早封+主板（near_high_early_main）：成龙率 14.00%（1.62×基线，n=1814）。
- full_setup（强势位+早封+板块>5%+市值≤120亿+前3天放量≥1.2+主板）：
  17.60%（2.04×基线，n=358）。组合阈值取自单因子方向，属轻度 in-sample，
  必须过 Phase 0 holdout 验证。

### 使用原则（妖股画像教训）

- **打分排序，不搞形态硬筛**：两只 17 板妖王（锋龙/嘉美）首板是午后 13-14 点
  封的，大有能源、立新能源首板次日低开照样成龙——因子是概率优势不是形态筛选。
- **开创型妖王启动时板块还冷**（锋龙/胜通板块 20 日 Q1）：板块动量因子会漏掉
  起爆点本身——用豁免规则，不加罚。
- **未来函数铁律**：所有因子必须在决策时点可观测。两个已识别的隐蔽违例：
  ① EOD 封单比（已禁）；② 全日市场温度（v2 改滞后口径）。
- **目标错位警示（v2 新增）**：L2 排序目标是「≥3 板成龙率」，但赚钱靠 D+1
  收益。温度因子已证实两者方向可不一致（成龙率单调、D+1 非单调）。Phase 0
  白名单要求因子对两个目标方向同时一致（温度因子例外，只用于风控门）。

### ⚠️ 与 v3 回测的冲突（v4 两版对照裁决，v2 细化）

v3 硬滤 `max_prior_return_20d ≤ 10%`（低位首板）与新数据矛盾：`return_20d < -8.5%`
最差（4.91%）、`>16.9%` 最好（11.74%）——**v3 的低位滤恰好把数据上最好的桶
砍掉了**，这可能就是 v3 错失龙头的原因之一。「低位」应重定义为「非深跌 +
非高潮」，不是「跌得多」。

裁决设计（同回测器、同 universe、同成交假设，否则无法归因）：

- **A 版**：v3 原样，保留 `max_prior_return_20d ≤ 10%` 硬滤。
- **B 版**：删低位滤，改深跌排除（`return_20d ≤ -8.5%` 或 `drawdown_126d ≤ -21%`
  排除，`concept_max_return_20d ≥ 16.5%` 豁免）。
- **裁决指标**：复利/胜率/笔数（主）+ 逐月收益分布（防单月贡献）+
  `return_20d > 16.9%` 桶的单独表现（A 版全砍 vs B 版保留，这是两版的核心分歧桶）。
- **口径警示**：v3 分钟 universe 是富集样本（封板率约为市场 5 倍），wave 研究
  是日线全量——若两版差异不显著，不能判定因子无效，可能是样本口径稀释，
  需补一个日线级粗对照再下结论。
- **若 B 版输给 A 版**：先砍豁免规则重跑（豁免 n 极小），再裁决深跌排除本身。

## 2. 后续开发计划（执行结果）

### Phase 0 因子时间稳定性门 ✅（2026-08-01 完成）

交付 `leader_first_board_factor_stability_research.py`（11 测试），train=2025-06..2026-04 /
test=2026-05..07（7475/3748 样本）。**裁决结果**：

- **白名单 6 因子**（holdout 方向一致 + test |AUC-0.5|≥0.05 + 逐月一致性≥0.7 + 双目标一致）：
  concept_max_return_20d（test 0.6151，holdout 最强）、drawdown_126d（0.5816）、
  return_20d（0.5696）、volume_ratio_5_60（0.5659）、prior_return_5d（0.5628）、position_126d（0.5614）。
- **滞后温度全部未过门**（逐月一致性 0.61-0.69 < 0.70）→「高潮日停手」缺乏稳定性支撑，
  温度只做展示不做硬门（计划的温度门取消，这正是稳定性门的价值）。
- float_market_cap 双目标翻转淘汰；prior_10d_amplitude 彻底不稳（一致性 0.21）；
  prior_4_10d_up_days / return_60d / turnover_ratio_3d 差 0.01-0.02 未达 0.55 线。
- 组合 holdout 全存活且相对优势放大：full_setup test 15.22%（3.4×基线）、
  near_high_early_main 10.34%（2.3×）。
- 族裁决：strength 族（drawdown/return_20d/position_126d 互相关 0.72-0.89）合计权重
  上限 0.40、单因子 0.25，代表 drawdown_126d。

### Phase 1 v4 分钟级回测 ✅（2026-08-01 完成，v4-B 胜）

A/B 同回测器同 universe 对照（≥600 与 ≥300 两档覆盖口径，证据
`limit_up_leader_minute_backtest_v4ab_20260801.md`）：

| 版本 | ≥600 复利/胜率 | ≥300 复利/胜率 |
|---|---|---|
| v3 基线（旧15因子+低位滤） | +5.35%/51.9% | +40.0%/62.5% |
| v4-A（白名单+低位滤） | +5.10%/51.7% | +9.1%/51.2% |
| **v4-B（白名单+深跌排除）** | **+5.81%/54.8%** | **+51.4%/60.5%** |

- **v4-B 两档唯一都赢 v3 → 成为生产配置**；低位滤被两档一致否定
  （砍掉打分因子认为最好的桶，与 wave 研究互证）。
- 深跌排除触发数更少（223/790 vs 394/1010）但均笔显著提升（+1.19→+5.95%）。
- 诚实边界：≥600 仅 9 天 31 笔；≥300 的 6 月贡献大部分利润；v4-B 回撤更大
  （-16.6% vs -10.2%），冲板失败（no_limit）大亏笔是 Phase 3 重点观察项。
- 成交假设检查：一字开盘/触发瞬间已封均不成交（既有测试守护，与 L0 一致）。
- 落地：`eod_backtest_2200` 调度（cron 0 22 * * 1-5）→ `leader_minute_backtest_rerun`
  （v4 因子 + deep_drop_exclusion，start=end-150 天）每晚写库；
  `limit_up_pool_snapshots` append 表上线（zt+zbgc 池盘中封单快照，
  source_updated_at 去重），开始积累全市场盘中封单历史。

## 3. 风险与边界

- 样本仅 13 个月单边环境，跨牛熊不足；所有阈值为 in-sample 分位，须经 Phase 0/3 验证。
- 板块归属为当前快照，历史归属可能漂移。
- 分钟数据覆盖富集（1m ≥600 口径封板率约为市场 5 倍），回测绝对胜率偏乐观，
  方向性结论（因子排序、排除项）比绝对数字更可信。
- 深跌豁免规则样本极小（2 案例），是全部因子条件里过拟合风险最高的一条。
- 温度因子回测/实时统一滞后口径后，盘中突发高潮（早盘 1 小时涨停潮）无法被
  温度门捕获——这是用可回测性换覆盖面的有意取舍，由 Phase 3 前向台账观察
  是否需要补盘中实时规则。
