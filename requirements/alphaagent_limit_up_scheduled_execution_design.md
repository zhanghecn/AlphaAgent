# AlphaAgent 综合首板连续盘中执行设计

## 状态

本设计由已上线的固定窄窗口方案升级而来。产品仍只保留一个综合首板策略，
不向用户暴露时间、板位或阈值开关。

策略版本升级为 `limit-up-scheduled-v2`。Tick/L2、真实委托回报和冻结后
前向证据未达标前，执行权限继续保持 `research_only`。

## 要解决的问题

旧版只在 `10:00-10:15`、`10:30-10:45` 接受买点。601 个历史交易日中，
完整首板事件池有 12,475 个候选，全天结构硬门仅通过 196 个；窄窗口进一步
只留下 54 个信号、46 笔闭合交易和 40 个买入日。账户平均资金利用率只有
9.54%。2026-07-14 的盘中修复直到 13:00 后确认，旧时钟已经关闭，即使候选
仍在演化，用户也只能看到“观察”。

本次只解决时间覆盖和可解释性，不为了增加交易次数降低涨停基因、低位/回调、
财务、盘中承接、市场、板块、资金、换手或封单门槛。

## 执行时钟

| 时间 | 系统行为 |
|---|---|
| 09:55 | 提醒 10:00 开始连续盘中评估 |
| 10:00-11:30 | 候选逐快照评估，通过全部门时触发 |
| 11:30-13:00 | 午间休市，只保留上午状态，不新增买入 |
| 13:00-14:25 | 恢复逐快照评估 |
| 14:25-14:30 | 继续评估新买点，同时提醒准备卖出 D+1 持仓 |
| 14:30 | 停止新增买入，卖出全部满足 T+1 的本策略持仓 |
| 14:30 后 | 只记录轨迹和次交易时段观察，不追板 |

时间边界使用上海时区，买入窗口左闭右开：`[10:00:00, 11:30:00)` 和
`[13:00:00, 14:30:00)`。窗口代表“允许评估”，不是到点自动买入。

## 买入合同

候选必须同时满足：

- 沪深主板非 ST，排除创业板、科创板和北交所。
- 属于完整综合首板候选池，通过涨停基因、低位或冷却回调、点时财报、
  D-1 分歧修复结构和盘中承接硬门。
- 当前市场门通过；弱情绪日必须由盘中封板增加、炸板减少和炸板率健康确认修复。
- 是所属板块龙一或龙二并进入市场 Top5；板块热度、触板扩散、板块资金、
  个股资金、换手和封单稳定性按信号时点通过。
- 距涨停不超过 1%，且系统在封板前已经观察到候选；已经封死且无法证明成交的
  股票只能记录为 `missed`。
- 当前行情日期正确，快照年龄不超过 20 秒，账户有现金且未持有同一股票。

账户初始 100,000 元，最多两仓，每仓目标为上一交易日权益的 50%，数量向下取
100 股整数手。只有一只合格票时只买一仓；没有合格票时保持现金，不用杂毛补位。

## 实时组合与轨迹

实时主区固定显示最多两只综合首板：

- `接近买点`：结构硬门已过，但市场或盘中执行项仍未全部通过；逐项显示还差什么。
- `买点触发`：同一快照内结构、市场、盘中执行和时间门全部通过。
- `已失效/已错过`：快照陈旧、条件转弱或未触发便封板；不得事后补记买点。

候选即使掉出当前 Top5，也必须保留在两交易日追加式轨迹中。轨迹按日返回首板
漏斗：进入雷达、曾进 Top5、接近买点、买点触发、未触发已封板、结构排除，
并按股票去重汇总市场门、板块热度、扩散、资金、换手等主要阻断项。

## 历史回放的两种口径

历史数据不能伪造盘中板块资金或 Tick/L2，因此必须同时区分：

1. `candidate_proxy`：读取完整 `candidate_pool.first_board`，只使用信号时刻已经
   保存的结构硬门和时间，估算扩大时间覆盖后的账户上界。
2. `live_equivalent`：只使用真实保存的逐次快照，重放与实时完全相同的市场、
   板块、资金和盘口门。缺少字段的历史日期记为不可验证，不默认通过。

页面可以展示 `candidate_proxy` 的复利，但必须紧邻显示“盘中执行门历史覆盖不足，
不是实盘等价结果”。只有 `live_equivalent` 积累足够 D+1 闭合样本后，才可作为
晋升依据。

## 卖出与现金

- D 日买入受 T+1 约束，当天不能卖出。
- D+1 14:30 发出卖出动作；14:30 缺价不得用后来价格伪装当时成交。
- 跌停锁死或委托未成交时保留持仓，15:00 及后续交易日开盘继续重试。
- 卖单确认成交后才释放现金。由于 v2 买入窗口在 14:30 结束，当天 14:30 才
  释放的现金不能倒灌给当天更早的买单。

## 无未来数据约束

时刻 `T` 的动作只能读取时间戳不晚于 `T` 的数据。最终封板、最终炸板、收盘价、
D+1 结果和当天稍后排名只能用于结果与复盘。修改 `T` 之后的数据不得改变
`T` 及以前的动作。

## 已有研究证据

保持原结构硬门、两仓和 D+1 14:30，仅改变历史信号时间覆盖的候选代理实验：

| 买入覆盖 | 闭合交易 | 复利 | 最大回撤 |
|---|---:|---:|---:|
| 旧两个窄窗口 | 46 | +65.62% | -6.84% |
| 连续 10:00-10:45 | 59 | +73.07% | -5.48% |
| 10:00-11:30 | 84 | +102.00% | -12.54% |
| 10:00-14:30 | 114 | +123.54% | -8.75% |

`10:00-14:30` 代理在后段时间验证为 `+33.98% / -5.81%`，双倍成本为
`+95.88% / -9.82%`；但“只成交最终炸板”压力为 `-20.06% / -27.11%`。
这些结果只支持扩大观察时段，不证明公共行情下能按涨停价成交，也不验证额外的
实时板块资金门。

## 验收

- 时钟边界覆盖 09:59:59、10:00、11:29:59、11:30、12:59:59、13:00、
  14:24:59、14:25、14:29:59 和 14:30。
- 观察候选不能被时钟函数错误提升为买点；只有原始研究动作已经是 `buy_now` 才能触发。
- 快照超过 20 秒、市场门关闭或任一执行检查未过时不能触发。
- 两日轨迹漏斗按股票去重，并能解释 2026-07-14 为什么是 0 买点。
- 历史报告明确返回代理口径、盘中执行证据缺口和不可实盘等价状态。
- 重跑完整样本、后段时间验证、双倍成本和只成交炸板压力；未通过收益为正、
  最大回撤不差于 -10% 的候选代理门则不替换产品默认时钟。
- 后端、前端测试和生产构建通过；桌面与手机页面无重叠和横向溢出。

## 晋升条件

保持 `research_only`，直到同时具备至少 60 个冻结后有效交易日、30 笔
`live_equivalent` 闭合交易、真实委托/未成交记录、正收益、不低于 55% 胜率、
优于 -10% 最大回撤、双倍成本为正，以及 Tick/L2 或券商真实成交队列证据。
