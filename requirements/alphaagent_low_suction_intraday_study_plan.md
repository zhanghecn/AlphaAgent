- 日期：2026-07-23

- 红线：**零未来函数 + 防过拟合**
- 目标：找出可执行、无未来函数、经开发/验证段确认的盘中低吸算法

## 背景（已确立的事实）

1. 转强确认 alpha 真实，但收盘确认（≥8% 接近前高）= 涨停时点 → 买不到。
2. 执行容差日线先导发现：**169 笔成交中 141 笔（83%）开盘未涨停**
   （open 中位 -0.1%），即绝大多数信号当天从低位拉起，盘中存在可成交低价。
3. 方向①证伪：放宽阈值（<8%）掺入假信号，alpha 边界硬卡 8%。
4. 结论：alpha 在"≥8% 转强"内成立，需在**该宇宙内**用分钟线定位盘中可买低价点。

## 阶段B：盘中低吸算法研究（预登记，回填后执行）

### 红线检查清单（每条规则必须全过）

- [ ] 触发判定只用决策时点 T 及之前的 5m K 线 + trailing 指标
- [ ] MA/前高/量比均为截至 T 的 trailing 值，禁用当日收盘/未来
- [ ] 入场价 = 触发那根 5m 的收盘（T 时刻已知）
- [ ] 退出沿用现行因果规则（D+1 止损 / 创新高确认 / 结构破坏）
- [ ] 规则参数预登记，不在验证段微调
- [ ] 开发段(block1-3) 发现 → 验证段(block4-5) 只许否决
- [ ] Wilson 95% 下界 ≥ 60% + 前向 300 笔账本 双重确认才冻结

### 预登记规则（只测有经济学解释的）

1. **MA5 盘中收复**：首次 5m 收盘 ≥ trailing MA5（截至该根）→ 买
2. **前高盘中突破**：首次 5m 收盘 > D-1 可见前高 → 买
3. **量价确认收复**：MA5 收复 + 该 5m 量 > 前 5 根中位 ×1.2 → 买
4. **早盘窗口限定**：上述规则仅在 09:35-10:30 或 13:00-14:00 触发（避开尾盘涨停区）

### 评估口径

- 主指标：盘中触发点买入的真实胜率 / PF / Wilson 下界
- 对照 A：现行收盘买入（同宇宙）
- 对照 B：触发时点是否已涨停（可执行性）
- 开发/验证段一致性 + 5 时间块稳定性
- 成交可行性：触发那根 5m 时，股价是否 < 涨停（可挂单）

### 不做（YAGNI + 防过拟合）

- 不在历史结果上事后加过滤条件
- 不搜参（阈值用预登记固定值）
- 不融合多规则集成模型（除非单一规则验证段失败后才考虑，且须独立留出）
- 不在回填数据上反复试不同 MA 周期找最优

## 验收门（冻结为正式规则前）

1. 开发段：胜率 > 60%、PF > 1.5、≥3/5 块稳定
2. 验证段：胜率 > 55%、PF > 1.3（只许否决不许调）
3. 全段 Wilson 95% 下界 ≥ 55%
4. 成交可行性：触发时点 ≥80% 未涨停
5. 前向纸面账本 300 笔复核通过

任一不过 = 规则不冻结，诚实记录为"盘中低吸在日线 alpha 边界外不可执行"。
