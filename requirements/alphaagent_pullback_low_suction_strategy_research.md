# AlphaAgent 回踩低吸策略优化研究

日期：2026-06-16  
对象：`mainline_leader_pullback` 及相关短线/游资型低吸打法  
范围：云南锗业、江海股份、剑桥科技、合肥城建、金安国纪、亨通光电六只样本股  
结论性质：系统研究与策略设计，不构成投资建议；任何回测收益都不能直接推导为未来收益。

## 摘要

本研究的核心结论是：AlphaAgent 当前的“主线强势回踩低吸”不是一个完整的“龙回头/回踩低吸”状态机，而是一个单日 MA5 附近触发器。它能在部分强趋势股票上给出可解释买点，但存在四个结构性问题：

1. 买点只看当天收盘价距离 MA5 是否处于 `[-1.5%, +2.0%]`，不能识别“先回踩 MA10，再多日慢慢收回 MA5”的龙回头结构。
2. D 日收盘产生 BUY 后，D+1 14:30 仍以信号日 MA5 为执行锚，容易出现大量“买拒”。其中一部分是正确拒绝追高，另一部分是因为信号生成太晚、没有同日尾盘预判。
3. 现有逻辑不区分“强势回踩后弱转强”和“MA5 已在 MA10 下方且继续发散的弱反抽”，导致合肥城建 2025-11-03/11-04 这类错误买点。
4. 卖出规则使用固定 `18%` 全仓止盈、`8%` 移动止盈、`7%` 止损和时间止损，不能适配强趋势龙头。云南锗业 2026-04-20 的卖出就是固定止盈触发，不是策略判断趋势结束。

建议把当前四个买点策略收敛为一个统一的 `mainline_dragon_pullback_v1` 研究方向：保留“主线强势 + 回踩低吸”作为唯一主策略，但把它改造成多阶段状态机。该状态机应覆盖第一波启动、3-8 日回踩、MA10/MA20 承接、缩量、重新收回 MA5、尾盘弱转强、分批止盈和趋势持有。突破、涨停后回踩和趋势加速不再作为独立自动策略抢入口，而应降级为同一状态机中的“第一波强势确认”或“候选加分项”。

## 1. 研究问题

用户提出的目标是只保留一个回踩低吸策略，并把它优化成更接近高赔率、高收益形态的策略。本文把目标拆成四个可验证问题：

1. 现有策略为什么错过肉眼看到的低吸点？
2. 现有策略为什么在某些弱反抽位置错误买入？
3. 现有策略为什么收益被卖出规则压低或变成负数？
4. 著名游资/新生代游资常见打法中，哪些能转成可观测量化特征，哪些只能作为人工经验，不应进入硬规则？

本文不承诺“确定盈利”。量化系统能做的是提高胜率、盈亏比、风控一致性和复盘效率，不能保证收益。

## 3. 当前 AlphaAgent 策略真实状态

### 3.1 当前已注册策略

本项目当前注册了四个策略：

| 策略 ID | 名称 | 版本 | 默认买入分 | 当前定位 |
| --- | --- | --- | ---: | --- |
| `mainline_leader_pullback` | 主线强势回踩低吸 | `0.1.1` | 68 | 当前低吸主策略 |
| `breakout_confirmation` | 平台放量突破确认 | `0.1.0` | 70 | 突破买点 |
| `limit_up_after_pullback` | 涨停后回踩确认 | `0.1.0` | 72 | 涨停后回踩买点 |
| `trend_acceleration` | 趋势加速确认 | `0.1.0` | 73 | 趋势加速买点 |

如果产品目标是“只保留一个回踩低吸策略”，不建议简单删除其他策略的经验，而应把它们的有用部分合并为一个多阶段低吸状态机：

- 突破确认：用于识别第一波启动和主线地位。
- 涨停后回踩：用于识别情绪资金强度和龙回头候选。
- 趋势加速：用于识别容量趋势票是否已进入主升。
- 回踩低吸：用于决定真正买点和风控。

### 3.2 当前低吸买点条件

当前 `mainline_leader_pullback / 0.1.1` 的买入硬条件为：

```text
total_score >= 68
and -1.5% <= ma5_distance_pct <= +2.0%
and risk_score >= 35
and liquidity_score >= 25
```

评分权重为：

| 因子 | 权重 |
| --- | ---: |
| 相对强弱 | 25% |
| 洗盘/回踩结构 | 20% |
| 趋势质量 | 15% |
| 板块主线 | 12% |
| 财务改善 | 10% |
| 资金/热度/龙虎榜代理 | 8% |
| 流动性 | 10% |
| 风险分 | 0% |

关键缺陷是：风险分只是硬过滤，不进入总分；低吸位置只是一条 MA5 距离带，没有“回踩过程”和“承接质量”的状态。

### 3.3 当前执行模型

组合回测默认执行模型为 `strict_1430`：

```text
D 日收盘可见数据生成 BUY/SELL 计划
D+1 14:30 使用 1m 分钟快照执行
若执行价距离信号日 MA5 超过 tail_entry_ma5_tolerance_pct，买入拒绝
默认 tail_entry_ma5_tolerance_pct = 1.5
```

这一设计能避免“信号日收盘后才知道结果，却假装当天买入”的未来函数问题。但对低吸策略来说，它也带来一个现实问题：低吸点通常发生在当日盘中或尾盘，D 收盘后才发信号，D+1 经常已经不是低吸价格。

因此新策略需要区分两种模式：

1. 日线研究模式：D 收盘识别，D+1 只做不追高的等待单。
2. 真实低吸模式：D 日 14:30 前用分钟数据预估当日收盘条件，D 日尾盘执行。

### 3.4 当前卖出规则

当前卖出优先级：

```text
stop_loss > take_profit > trailing_stop > time_stop
```

默认参数：

| 参数 | 默认值 |
| --- | ---: |
| 止损 | 7% |
| 止盈 | 18% |
| 移动止盈/回撤 | 8% |
| 时间止损 | 15 个交易日左右 |

固定 `18%` 全仓止盈适合短波段，不适合强主线龙头。对于“龙回头后主升”的股票，收益往往来自少数持仓的趋势延伸；太早全卖会显著降低盈亏比。

## 5. 个股审计

### 5.1 云南锗业

用户问题：

- 2026-04-20 为什么提早卖掉？
- 2026-04-29 回踩 10 日线，2026-04-30 到 2026-05-06 慢慢回踩回 5 日线，为什么没有买入信号？

本地结论：

1. 2026-04-20 卖出不是因为策略判断趋势变坏，而是固定 `take_profit` 触发。回测 `#74` 显示：2026-04-01 买入，2026-04-17 产生 `take_profit` 卖出计划，2026-04-20 卖出，卖出价约 68.13。该回测大量使用 `daily_close_proxy`，不能作为严格收益结论，但足以解释卖出原因。
2. 2026-04-29 与 2026-04-30 没有 BUY，核心是 MA5 距离不满足当前硬规则：
   - 2026-04-29 收盘距 MA5 约 `-5.36%`。
   - 2026-04-30 收盘距 MA5 约 `-2.45%`。
   - 当前允许区间只有 `[-1.5%, +2.0%]`。
3. 从形态上看，这正是当前策略无法表达的结构：先急速上攻，随后跌到 MA10 附近，缩量/承接后再慢慢回到 MA5。这不是“单日贴 MA5”，而是“回踩 MA10 后收回 MA5”的多日状态。

关键数据片段：

| 日期 | 收盘 | 距 MA5 | 距 MA10 | BUY | 评分 | 解释 |
| --- | ---: | ---: | ---: | --- | ---: | --- |
| 2026-04-27 | 72.80 | -1.74% | 8.17% | 否 | 79.38 | 差一点触发，但低于 -1.5% |
| 2026-04-29 | 69.22 | -5.36% | -0.53% | 否 | 77.38 | 回踩 MA10，现模型不认 |
| 2026-04-30 | 70.01 | -2.45% | -1.33% | 否 | 81.56 | 正在收回，但仍不在 MA5 带 |
| 2026-05-06 | 77.01 | 7.34% | 6.29% | 否 | 79.36 | 已弹离低吸区 |

优化推断：

- 新策略必须允许“MA10 承接型龙回头”：当第一波强度足够、MA5 仍在 MA10 上方或刚被回踩压弯但未破坏，价格允许短暂低于 MA5 `-1.5%`。
- 不能简单把 MA5 距离放宽到 `-6%`，否则会误买弱股。必须同时要求：前一波强度、回踩天数、MA10/MA20 支撑、缩量、收回动作。
- 卖出应改为“部分止盈 + 趋势持有”。例如 15%-20% 先卖 1/3，剩余仓位用 MA5/MA10 趋势和高位派发信号退出。

### 5.2 江海股份

用户问题：

- 很多关键信号都是买拒，具体原因是什么，策略是否能继续优化？

本地结论：

江海股份的 BUY 拒绝集中体现为 `tail_entry_not_triggered`。例如：

| 回测 | 执行日 | 信号日 | 执行价距信号日 MA5 | 状态 |
| --- | --- | --- | ---: | --- |
| `#62/#70/#74` | 2026-05-13 | 2026-05-12 | 9.13% | 买拒 |
| `#62/#70/#74` | 2026-05-22 | 2026-05-21 | 10.35% | 买拒 |

这类买拒不一定是坏事。低吸策略在 D 日发出信号后，如果 D+1 14:30 已经大幅远离信号日 MA5，继续买就是追高。拒绝能保护买点质量。

真正的问题是：

1. 信号生成太慢：低吸发生在 D 日盘中或尾盘，系统 D 收盘后才确认，D+1 可能已脱离低吸区。
2. 执行锚过于单一：所有形态都锚定信号日 MA5，没有区分 MA5 低吸、MA10 承接、收回 MA5、强趋势趋势内低吸。
3. 缺少“计划类型”：买拒现在只说尾盘未触发，不能告诉用户这是“正确拒绝追高”还是“错过日内低吸”。

优化推断：

- 如果江海股份信号日在 D 日已经贴近 MA5，D+1 远离 MA5，应该拒绝，不应放宽追高。
- 若想捕捉 D 日低吸，必须引入 D 日 14:30 预信号：用当天截至 14:30 的分钟价、当日估算成交量和昨日均线，在尾盘判断是否已经满足弱转强。
- 新策略应把拒绝原因拆成：
  - `rejected_chasing_after_signal`：信号正确，但执行日涨离买点。
  - `rejected_no_support_reclaim`：尚未收回关键均线。
  - `rejected_distribution_risk`：高位放量冲高回落。

### 5.3 剑桥科技

用户问题：

- 收益率甚至是负的。
- 2026-04-14 附近肉眼看有低吸点，存在 5 日线低吸逐步小额度上涨，后面拉高，为什么没捕捉到？
- 为什么收益为负，是买点问题还是卖点问题？

本地结论：

2026-04-14 未触发当前低吸，原因是当前模型不认为那一天是“低吸”：

| 日期 | 收盘 | 距 MA5 | 距 MA10 | BUY | 评分 | 相对强弱 |
| --- | ---: | ---: | ---: | --- | ---: | ---: |
| 2026-04-14 | 120.62 | 3.53% | 10.05% | 否 | 57.08 | 32.7 |
| 2026-04-15 | 125.80 | 5.40% | 12.30% | 否 | 61.95 | 52.1 |
| 2026-04-20 | 152.30 | 12.63% | 22.88% | 否 | 70.70 | 81.2 |
| 2026-05-12 | 189.42 | 0.72% | 8.34% | 是 | 83.96 | 100 |
| 2026-05-13 | 191.64 | 0.57% | 7.27% | 是 | 83.96 | 100 |

也就是说，现模型捕捉的是 2026-05-12/05-13 的“已强势后的 MA5 回踩”，不是 2026-04-14 的“启动初期慢推”。用户肉眼看到的 2026-04-14 更像“第一波启动中的沿 5 日线慢推”，它应属于新状态机的 `INIT_STRONG_LEG` 或 `EARLY_TREND_BUILD`，不是传统回踩低吸。

剑桥科技收益为负的可能原因分三层：

1. 买点层：现策略错过了早期启动段，只在后期高位回踩才给信号，赔率变差。
2. 执行层：2026-05-12/05-13 的 BUY 在组合回测中 D+1 14:30 被拒，原因是执行价距离信号日 MA5 超过容忍度；这说明 D 收盘信号已经滞后。
3. 卖点层：如果后续追到高位，固定止损/移动止盈容易在高波动中被扫出；如果固定 18% 全卖，则又会卖飞强趋势。

优化推断：

- 剑桥科技要求新增“慢推启动识别”：连续 3-6 日小阳/小涨、低点抬高、价格沿 MA5 上移、量能温和而非爆量、MA5 上穿或拉开 MA10。
- 但慢推启动不能直接等同低吸买点。它更适合作为“候选状态”，真正买入仍要等第一次分歧回踩或尾盘收回 MA5。
- 对这类高波动趋势股，卖出要从固定止盈改为趋势化退出，否则单笔盈亏比被截断。

## 6. 六股共性问题

### 6.1 当前策略把“价格靠近 MA5”误认为“低吸结构”

低吸不是一个价格点，而是一个过程：

```text
强势启动 -> 分歧回落 -> 缩量承接 -> 关键均线不破或快速收回 -> 弱转强确认
```

当前策略只实现了最后的“价格在 MA5 附近”，缺少前后文。

### 6.2 当前策略错过“先回踩 MA10，再收回 MA5”

云南锗业 2026-04-29/04-30 是典型案例。价格已经回踩到 MA10 附近，之后重新向 MA5 修复。当前 MA5 硬带过窄，无法识别这类龙回头。

### 6.3 当前策略误买“MA5 下降中的弱反抽”

合肥城建 2025-11-03/11-04 是典型案例。价格贴近 MA5，但 MA5 明显在 MA10 下方，且弱势结构没有真正修复。

### 6.4 当前执行模型会把低吸变成追高等待

D 日收盘发信号，D+1 14:30 执行。如果 D+1 已经上涨 5%-10%，低吸逻辑应拒绝。江海股份的很多买拒就是这种情况。

解决方案不是简单放宽容忍度，而是前移信号生成时间，引入同日 14:30 预信号。

### 6.5 当前卖出规则截断强趋势

云南锗业、金安国纪、亨通光电都说明：强趋势票的收益往往来自少数大波段。固定 18% 全卖可能提高短期胜率，但会降低长期盈亏比。

### 6.6 缺少高位派发过滤

合肥城建 2026-05-21 说明：高位大幅拉升后的贴 MA5，不一定是低吸，可能是派发后的第一段回落。新策略必须识别：

- 高位放量滞涨。
- 大阴线或长上影。
- 成交额/换手处于 60 日高分位。
- 近 3-5 日涨幅过大后突然破 MA5。
- 次日无法收回高位支撑。

## 7. 游资打法对照与量化映射

### 7.1 研究态度

公开市场经常把营业部席位与游资名字绑定，例如“炒股养家”“赵老哥”“作手新一”“方新侠”“小鳄鱼”“陈小群”“涅槃重升”等。但这些标签有两个问题：

1. 席位标签不等于真实交易主体。券商 App 和市场数据服务可能把营业部标签化，存在造神和跟风风险。
2. 即使席位真实，个股上涨也不是因为名字，而是因为市场主线、筹码结构、情绪周期、资金容量和买卖点共振。

因此 AlphaAgent 不应把“某游资出现”当作硬买入条件。正确做法是把公开打法拆成可观测代理。

### 7.2 常见短线打法与可量化代理

| 市场经验打法 | 核心思想 | 可量化代理 | 不可直接量化部分 |
| --- | --- | --- | --- |
| 龙头主线 | 只做市场最强方向和最强股 | 板块涨幅排名、板块成交额占比、个股相对强度、20/60 日新高 | “市场认可度”的语义判断 |
| 分歧低吸 | 强势股第一次明显分歧时低吸 | 从高点回撤 4%-15%、回踩 MA5/MA10、缩量、尾盘收回 | 是否是真分歧还是出货 |
| 龙回头 | 第一波大涨后回踩关键均线再二波 | 近 20 日大阳/涨停、3-8 日回调、MA10/MA20 承接、重新站回 MA5 | 龙头地位变化 |
| 弱转强 | 前一日分歧，次日重新转强 | 高开/尾盘重新站上 MA5、放量但不过热、收盘接近高位 | 情绪强弱的盘感 |
| 打板/接力 | 涨停确认强度 | 涨停次数、封板时间、炸板率、次日溢价 | 封单质量、盘口细节 |
| 趋势容量 | 大成交额趋势票沿均线推升 | 成交额 20 日均值、MA5/MA10/MA20 多头、回撤小、板块容量 | 大资金真实意图 |
| 反核/修复 | 极端分歧后快速修复 | 大跌后不再创新低、放量收回关键位 | 情绪拐点真假 |

### 7.3 对 AlphaAgent 的启发

著名游资打法可以归纳为一句工程规则：

```text
不要量化“游资是谁”，要量化“强势从哪里来、分歧是否可控、承接是否真实、再转强是否发生”。
```

在 AlphaAgent 中应落为这些字段：

- 主线：`sector_mainline_score`、板块涨幅、板块成交额、板块内涨停/大阳数量。
- 龙头：个股相对板块排名、20/60 日收益、成交额容量、涨停/大阳历史。
- 分歧：距阶段高点回撤、回撤天数、阴线数量、是否破 MA20。
- 承接：MA5/MA10/MA20 距离、盘中低点是否守住、缩量程度。
- 弱转强：收盘/14:30 重新站上 MA5、当日涨跌幅、尾盘成交额变化。
- 风险：高位派发、长上影、爆量阴线、换手异常、涨幅过热。

## 8. 新统一策略设计：`mainline_dragon_pullback_v1`

### 8.1 设计目标

新策略只保留一个自动买入策略，名称建议为：

```text
mainline_dragon_pullback_v1
主线龙回头回踩低吸
```

目标不是覆盖所有上涨形态，而是只做一种最清晰的交易：

```text
主线强势股第一波上涨后，出现可控分歧回踩，在 MA5/MA10/MA20 获得承接，并在尾盘或收盘重新弱转强。
```

### 8.2 状态机

新策略不应按单日规则直接 BUY，而应按状态推进：

| 状态 | 含义 | 进入条件 | 退出/失败 |
| --- | --- | --- | --- |
| `COLD` | 无有效主线强势 | 默认状态 | 第一波强势确认 |
| `STRONG_LEG_CONFIRMED` | 第一波启动已成立 | 20/60 日强度、板块强、放量大阳/涨停/新高 | 过热派发或回撤破坏 |
| `PULLBACK_OBSERVE` | 等待分歧回踩 | 从高点回撤 3-8 日，回撤幅度合理 | 回撤过深、破 MA20、放量大阴 |
| `SUPPORT_ACCEPTED` | 关键均线承接成立 | MA5/MA10/MA20 附近缩量承接，低点抬高 | MA5<MA10 发散、跌破支撑 |
| `TAIL_BUY_READY` | 尾盘弱转强可买 | 14:30/收盘重新站回关键均线，不追高 | 尾盘冲高回落、涨离买点 |
| `HOLD_TREND` | 持仓趋势跟踪 | 买入后不破趋势 | 止损、派发、趋势破坏 |
| `DISTRIBUTION_RISK` | 高位派发风险 | 高位放量滞涨/大阴/长上影 | 等待重新构造，不低吸 |
| `INVALIDATED` | 结构失效 | 破 MA20 或回撤过深 | 回到 COLD |

### 8.3 必要输入字段

日线字段：

- `open/high/low/close`
- `volume`
- `turnover`
- `change_pct`
- MA5/MA10/MA20/MA60
- 5/10/20/60 日涨跌幅
- 20/60 日新高和距高点回撤
- 5 日/20 日量比
- 20 日平均成交额
- 60 日成交额分位
- 上影线、下影线、实体长度、振幅

分钟字段：

- 执行日 `14:30` 价格。
- 可选扩展：`14:30-14:57` 尾盘区间高低价、成交量、VWAP。

辅助字段：

- 板块强度。
- 财报可见性评分。
- 资金流/热度/龙虎榜代理。
- 指数 20 日收益和市场环境。

### 8.4 硬过滤

新策略先过滤，不满足则不评分：

```text
非 ST / 非退市风险 / 非停牌
20 日平均成交额 >= 1 亿，优先 >= 3 亿
上市交易足够久，至少 120 根日线
最新收盘不处于明显一字涨停买不到状态
最近 60 日最大回撤不能超过策略上限，除非进入修复型小仓状态
```

MA 结构硬过滤：

```text
普通强势回踩：
  MA5 >= MA10 * 0.995
  MA10 >= MA20 * 0.98
  close >= MA20 * 0.97

深回踩修复：
  允许 MA5 < MA10
  但必须 close 重新站上 MA10
  且 MA5/MA10 负向差距连续收敛
  且最近 2 日不再创新低

禁止：
  MA5 < MA10 且 MA5/MA10 < -2%
  同时 close 仍低于 MA10
  或 MA5/MA10 负向差距继续扩大
```

派发过滤：

```text
近 5 日涨幅 >= 25% 且当日放量长上影
或近 3 日成交额处于 60 日 90% 分位以上且价格滞涨
或高位大阴线跌破 MA5 且成交额高于 20 日均额 1.5 倍
或从阶段高点回撤第一天就爆量下跌
=> 进入 DISTRIBUTION_RISK，不允许低吸。
```

### 8.5 第一波强势确认

第一波强势不等同买点，它只是候选资格。

建议条件：

```text
return_20d >= 12%
or return_60d >= 25%
or 20 日内出现涨停/接近涨停/大阳线
or close 接近 60 日新高
```

并要求至少满足两个辅助条件：

```text
板块强度 >= 60
20 日成交额均值 >= 3 亿
个股 20 日收益跑赢指数 >= 8%
MA20 >= MA60 * 0.98
近 20 日至少一次成交额显著放大
```

### 8.6 回踩结构识别

回踩不是越深越好。主板普通股票建议：

```text
从 pivot_high 回撤：4% 到 18%
回踩天数：3 到 8 个交易日，最多 12 日
最低价不有效跌破 MA20
回踩期间至少 2 日缩量
回踩期间不能连续大阴破位
```

不同类型：

| 类型 | 支撑带 | 适用场景 |
| --- | --- | --- |
| MA5 低吸 | close 距 MA5 `[-1.5%, +2.0%]` | 强趋势第一分歧 |
| MA10 承接 | close 距 MA10 `[-2.0%, +2.5%]`，并开始收回 MA5 | 云南锗业 2026-04-29/04-30 类型 |
| MA20 深回踩 | low/close 接近 MA20，之后 1-2 日收回 MA10 | 更低仓位，只做强主线 |
| 慢推蓄势 | 3-6 日小涨、低点抬高、量能温和 | 剑桥科技/合肥城建启动初期候选 |

### 8.7 弱转强确认

弱转强是买点确认，不是单纯缩量。

日线确认：

```text
close >= MA5
或 close 从 MA10/MA20 支撑后重新回到 MA5 下方 1% 以内
当日涨跌幅在 -1% 到 +5% 之间，避免追大阳
收盘价位于当日振幅上半区
当日成交量不低于前一日的 70%，但不超过 20 日均量 2.0 倍
```

分钟确认：

```text
14:30 价格在支撑带内或刚收回 MA5
14:30 不应距离支撑位过远
14:30 后若有 14:57 数据，不能明显跳水破支撑
涨停买不到或大幅追高时拒绝
```

### 8.8 买入分层

同一个策略可以分仓位，不必所有 BUY 等价。

| 买入等级 | 条件 | 建议仓位 |
| --- | --- | ---: |
| A 级 | 主线强、第一波明确、MA10/MA5 承接、尾盘弱转强、无派发 | 标准仓 |
| B 级 | 慢推蓄势刚确认，尚未完全主升 | 半仓 |
| C 级 | 深回踩修复，MA5/MA10 刚收敛 | 试错仓 |
| 禁止 | 高位派发、弱反抽、MA5<MA10 发散 | 0 |

### 8.9 卖出规则

新策略必须改变固定全仓止盈。

建议卖出状态机：

```text
硬止损：
  买入后跌破入场支撑位 3%-5%
  或收盘跌破 MA20
  或单日大阴且无法收回 MA10

部分止盈：
  盈利 15%-20% 卖出 1/3
  盈利 30%-40% 再卖出 1/3
  剩余仓位进入趋势持有

趋势持有：
  close >= MA5 或 close >= MA10 且趋势未坏，继续持有
  强主升阶段不因固定 18% 全卖

派发退出：
  高位放量长上影
  高位爆量阴线跌破 MA5
  连续两日无法收回 MA5
  跌破 MA10 且成交额不缩

时间退出：
  买入后 8-12 个交易日仍未脱离成本区，降低仓位
  但强趋势不使用机械 15 日清仓
```

## 9. 新策略评分框架

建议总分 100 分，硬过滤优先：

| 模块 | 权重 | 说明 |
| --- | ---: | --- |
| 主线/龙头强度 | 20 | 板块、相对强弱、成交额容量 |
| 第一波强势 | 15 | 涨停/大阳/新高/趋势斜率 |
| 回踩结构 | 20 | 回撤幅度、天数、MA5/MA10/MA20 支撑 |
| 缩量承接 | 15 | 量比、成交额分位、低点抬高 |
| 弱转强确认 | 15 | 收回 MA5、尾盘位置、收盘区间 |
| 风险扣分 | -20 到 0 | 派发、高位过热、MA 破坏 |
| 基本面/财报辅助 | 5 | 只加分，不做短线硬门槛 |
| 资金/热度/LHB 代理 | 10 | 只做可观察代理 |

买入门槛建议：

```text

B 级 BUY：score >= 72 且支撑确认，仓位减半

REJECT：任何硬过滤失败
```

## 10. 伪代码

```python
def score_mainline_dragon_pullback(symbol, bars, minute_1430=None, context=None):
    features = build_features(bars, context)

    if not pass_universe_filters(features):
        return reject("universe_filter")

    if detect_distribution_risk(features):
        return reject("distribution_risk", state="DISTRIBUTION_RISK")

    strong_leg = score_strong_leg(features)
    if strong_leg < STRONG_LEG_MIN:
        return watch_or_reject("no_strong_leg")

    pullback = classify_pullback(features)
    if pullback.state not in {"PULLBACK_OBSERVE", "SUPPORT_ACCEPTED"}:
        return watch("waiting_pullback")

    if is_weak_rebound_after_breakdown(features):
        return reject("weak_rebound_ma5_below_ma10")

    support = score_support_acceptance(features, pullback)
    reclaim = score_reclaim_confirmation(features, minute_1430)
    risk = score_risk_penalty(features)

    total = (
        0.20 * strong_leg
        + 0.20 * pullback.score
        + 0.15 * support
        + 0.15 * reclaim
        + 0.10 * features.smart_money_proxy
        + 0.05 * features.financial_score
        + 0.15 * features.liquidity_and_capacity
        - risk
    )

    if total >= 78 and reclaim >= 70 and support >= 70:
        return buy("A", state="TAIL_BUY_READY")
    if total >= 72 and support >= 75 and not features.overheated:
        return buy("B", state="SUPPORT_ACCEPTED")
    if total >= 65:
        return watch(pullback.state)
    return reject("score_below_threshold")
```

```python
def evaluate_dragon_pullback_exit(position, bar, features):
    if bar.close <= position.support_stop:
        return sell_all("support_broken")

    if detect_distribution_risk(features):
        return sell_all_or_half("distribution_risk")

    if position.return_pct >= 0.18 and not position.first_take_profit_done:
        return sell_fraction(1/3, "first_take_profit")

    if position.return_pct >= 0.35 and not position.second_take_profit_done:
        return sell_fraction(1/3, "second_take_profit")

    if bar.close < features.ma10 and features.ma5_slope < 0:
        return sell_rest("trend_break")

    if position.days_held >= 12 and abs(position.return_pct) < 0.03:
        return reduce_or_exit("time_efficiency")

    return hold()
```

## 14. 结论

本轮研究建议不要继续在现有 MA5 单日触发器上微调阈值。正确方向是把“回踩低吸”升级成一个多阶段状态机：

```text
主线/强势确认
-> 第一波启动
-> 3-8 日分歧回踩
-> MA5/MA10/MA20 缩量承接
-> 尾盘弱转强
-> 分批止盈 + 趋势持有 + 派发退出
```

对用户点名问题的最终判断：

- 云南锗业：卖早是固定止盈；漏买是 MA5 区间太窄，未支持 MA10 承接型龙回头。
- 江海股份：很多买拒是 D+1 已涨离低吸点，部分拒绝是正确的；真正要优化的是同日尾盘预信号和拒绝原因解释。
- 剑桥科技：2026-04-14 属于启动慢推候选，不是现模型定义下的 MA5 回踩；收益为负主要是买点滞后和卖点机械共同作用。
- 合肥城建：2025-11-03/11-04 是明确错误买点；2026-04-24 到 05-11 是新策略应识别的蓄势慢推；2026-05-21 应由派发风险过滤掉。
- 金安国纪、亨通光电：买点框架基本可保留，放大收益主要靠卖出状态机和趋势持有。

下一步应先实现 `mainline_dragon_pullback_v1` 并行策略，不直接删除旧策略。等六股审计、严格 14:30 基线、长区间分层验证都通过后，再把它设为唯一默认策略。
