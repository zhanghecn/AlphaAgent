# 高位接力打板 · 产品设计（v1.0 草案，待主人拍板）

研究定稿 = `量化因子研究/高位接力/高位接力规则.md`（v1.3，2026-09-19）。
产品形态参照 `weak_to_strong_v2_design.md`（N型补涨打板），页面、表结构、调度全部同构。
本文只设计页面和功能，不含实施计划；拍板后再出实施计划。

## 一、定位

短线研究第 4 个页签：潜龙首板 / N型补涨打板 / 低吸 / **高位接力**。

一句话：昨天恰好 2 连板或 3 连板的票，今天冲第 N+1 板时按涨停价打板买入，
五种形态（方案点 A1/A2/B1/B2/B3）才出手，炸板当天收盘走，封住拿到断板。

与 N型补涨打板的区别：N型买「连板→挖坑→再板」的再启动首板（全天可打）；
高位接力买「连板途中」的第 3/4 板（只在早盘 15 分钟打，要过竞价关）。

## 三、每日数据流（调度）

```
盘后（EOD 批次，跟在 w2s_eod_finalize 后面）
  hpr_eod_finalize:
    1. 定版本日信号（炸板当日卖/断板卖/15日兜底，见第六节）
    2. 用最新日线算次日池：昨日恰好2/3连板全量 + 五方案点静态条件打标
       + 板型链 + 静态回避标记 → hpr_pool_entries（整覆写）

竞价~盘中（每分钟 cron，与 w2s 同一窗口 09:30~15:00）
  hpr_live_scan_tick:
    1. 首跳取到开盘价 → 算竞价涨幅 → 落在本点回避区的标记「竞价回避」终态
    2. 只对命中方案点（A/B 级）的票开触发；雷达票只展示
    3. 09:30~09:45 内首次触涨停价 → 模拟买入（买入价=涨停价）
    4. 09:45 之后才首次触板 → 「迟到·放弃」终态
    5. 开盘=涨停（一字开）：不判死刑，转「T字观察」——盘中打开后回封可买；
       全天不开 → 收盘判「一字·买不进」

 nightly（回测批次）
  hpr_backtest_rerun: 全历史日线回放 → hpr_backtest_runs 物化（幂等；
    版本号漂移 worker 启动自检自动补，照 Container Image Version Lag 纪律）
```

## 四、池计算（T-1 收盘口径，无未来函数）

基础件直接复用 w2s pool 的 derive_daily（涨停判定/连板 streak 同一口径）。

池入选：`streak == 2`（二接三）或 `streak == 3`（三接四），主板非ST，上市>5日。
四组框架：二接三/三接四 × 地基日（首板前一天）阴阳。

五方案点打标（全部静态字段，精确阈值=研究定稿，边界含下不含上）：

| 点 | 条件（精确数字） | 级别 |
|---|---|---|
| A1 修复启动（三接四阳） | -15≤地基日收盘/60日最高价-1<-8% × 均线态∉{全多头,两种纠缠} × 前60日无连板 | 出手 |
| A2 老龙缩量（三接四阴） | 前120日最大连板≥3 × 二板换手率-首板换手率<-5pt | 出手 |
| B1 竞价确认（二接三阴） | 6≤二板开盘涨幅<9.5% × 0≤二板换手-首板换手<2pt | 轻仓 |
| B2 低开转强（二接三阳） | -9≤地基日距60日新高<-2% × 二板开盘涨幅<0 × （竞价 4~7% 盘中复核） | 轻仓 |
| B3 二波贴线（三接四阳） | 前60日有过≥2连板的前波 × 地基日收盘距MA10<5% | 轻仓 |

B2 的「竞价 4~7%」是唯一盘中复核条件：池里先打 B2 标记（静态部分满足），
9:30 首跳竞价涨幅落在 4~7% 才允许触发，落在外 → 竞价回避终态。

静态回避（池计算时直接打「回避」标，命中也不买）：三接四阳地基日距新高<3%；
二接三阴链=实体→实体；三接四阴链=实体→下影 / 实体→下影→下影；
二接三阳链=一字→一字；二接三阴链=实体→一字；二接三阳前 60 日无前波。

## 五、盘中触发（与 N型的六处口径差异）

| # | 口径 | N型补涨打板 | 高位接力 |
|---|---|---|---|
| 1 | 竞价过滤 | 无 | **有**：A2 竞价<0 或≥9.5% 回避；B2 竞价须 4~7%；三接四阴最优 0~6% 提示 |
| 2 | 触发时间窗 | 09:30~15:00 全天 | **首刻 09:30~09:45**；之后才首触=放弃；14:30 后首触一律不追（首刻已覆盖） |
| 3 | 一字处理 | 开盘≥涨停→终态买不进 | **T字可买**：一字开后打开再回封→买；全天不开→买不进 |
| 4 | 炸板卖出 | 次日收盘卖 | **当天收盘卖**（E3 口径） |
| 5 | 兜底持有 | 20 日 | **15 日** |
| 6 | 池 | 触发池全量(数百)+白名单出手 | 昨日2/3连板全量(数十)+五点命中出手 |

## 六、卖出定版（EOD）

对每个未了结信号从日线重放（幂等，同 w2s 思路）：

1. 买入日当天未封板 → **当天收盘价卖**，原因「炸板当日走」
2. 封住了 → 从次日起首个未涨停日收盘卖
3. 一路涨停到第 15 个交易日 → 当日收盘卖（兜底）
4. 数据还没到退出日 → holding（在持，streak_h=买入日起连板数）

## 十、待主人拍板的决策点

1. **阴地基午后放宽窗**（13:00~14:00 才首触的阴地基票，研究说「可放宽」54%/+2.1）：
   建议首版**只标记不买入**（状态「午后放宽·观察」），因为研究执行口径 90 笔不含它，
   买入口径动了回测就对不上账。要做也是单独的放宽口径实验。
2. **T字回封买入**：建议跟研究口径（回封即买、全天一字买不进）。
   研究回测里 T字票首触记 09:25 竞价=首刻，买入价=涨停价；
   实盘回封时刻可能晚于 09:45，这是回测与实盘的固有差异，风险声明里写明。
3. **B 级观察票盘中是否模拟买入**：建议模拟（badge 区分轻仓），
   因为研究 171 笔合计口径含 B 级，交割单可对账；只想看 A 级就在页面过滤。
4. **雷达范围**：建议池=昨日2/3连板全量（未命中也展示，就是研究的对照组），
   不额外加「昨日涨停但未连板」等更宽的雷达。
