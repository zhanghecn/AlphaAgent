# D-2 涨停、D-1 续涨事件研究设计

## 状态与目标

- 用户于 2026-07-12 确认采用推荐口径，并授权后续细节按推荐方案执行。
- 目标不是直接增加公开策略，而是先验证一个独立事件形态是否具有可重复的隔日收益优势。
- 研究结果必须包含样本数、D 日胜率、开高低收路径、毛/净收益、同日等权组合复利和最大回撤。

## 研究口径

股票池固定为沪深主板非 ST、非退市、非新股状态股票：

1. `D-2` 收盘价达到按前收盘价和 10cm 规则计算的涨停价；盘中触板但收盘未封板不算。
2. `D-1` 收盘价高于 `D-2` 收盘价，但未达到 `D-1` 涨停价。
3. 信号在 `D-1` 收盘后成立，理论买入价为 `D-1` 收盘价。
4. 主退出价为 `D` 收盘价；同时记录 `D` 开盘、最高、最低收益路径。
5. `D-2`、`D-1`、`D` 必须是连续市场交易日，停牌造成的跳日样本不进入。
6. 真实研究只使用当日全市场日线覆盖不少于 3,000 只的完整交易日；本地更早的零散个股历史不进入复利。

涨停价按前收盘价乘以 `1.10` 后使用 Decimal `ROUND_HALF_UP` 保留两位小数。判定只使用原始不复权日线；当前数据无法恢复逐日历史 ST 名称，因此报告必须披露当前名称过滤带来的幸存者偏差风险。

D 日开高低收相对 D-1 收盘若任一超出主板对称合法数据区间 `[-11.5%, 11.5%]`，保留 D-1 已成立的信号，但把该条标为价格断点并排除收益统计。这样数据质量清洗不会反向改变历史信号。

## 收益与复利

报告同时给出两套收益：

- 毛收益：`D 价格 / D-1 收盘价 - 1`。
- 净收益：毛收益扣除双边佣金、卖出印花税和双边滑点。默认佣金每边 `0.03%`、印花税 `0.05%`、滑点每边 `0.10%`，合计往返成本 `0.31%`。

同一 `D-1` 可能出现多只股票。复利不按单笔逐条连乘，而是：

1. 同一信号日所有股票等权，得到当日组合收益。
2. 没有信号时保持现金，收益为零。
3. 按交易日顺序连乘每日组合收益。
4. 同时报告期末净值倍数、累计复利、最大回撤、盈利信号日比例、平均和最大同日持仓数。

这是一套理论满仓等权事件组合，不代表尾盘集合竞价真实成交。结果不能在缺少分钟/Tick 成交证据时直接升级为可执行策略。

## 实现边界

采用独立模块 `alphaagent/server/services/quant/d2_limit_up_d1_rise_research.py`：

- 从 `stock_daily_bars` 和 `stocks` 只读加载本地全部可用日线。
- 纯函数负责股票池过滤、连续交易日检查、形态识别、收益标签和统计。
- CLI 生成 Markdown 证据报告到 `memory/06_backtests/`。
- 不修改 `vnpy/`、官方 examples、现有公开策略、策略注册表、API 或前端。

没有采用的方案：

- 直接扩展 `d1_event_feature_research.py`：文件当前有未提交改动，且职责已经较大。
- 只使用 `stock_events` 涨停事件表：封板证据更严格，但当前历史覆盖约 252 日，不足以替代全量日线初筛。

## 测试与验收

单元测试必须证明：

- 只选中“D-2 收盘涨停、D-1 正收益且未涨停”的主板非 ST 样本。
- D 日价格变化只改变结果标签，不改变 D-1 已成立的信号，防止未来函数。
- 停牌跳日样本被排除。
- 涨停价使用半入舍入。
- 同日多标的先等权、再逐日复利，并正确扣除 `0.31%` 成本。

最终验收包括目标单测、相关量化测试、代码编译和一次真实数据库全样本研究。真实报告必须注明数据范围、样本量和全部限制。
