# AlphaAgent 单一综合首板产品设计

## 产品目标

`/limit-up` 面向用户只保留一个“综合首板”策略。用户不需要理解预热准入、质量门、延续通道、轮动通道或代理基线，只需要看到综合结论、买卖规则、真实现金回测和历史交割单。

## 用户界面

- 回测页只展示现有正式“综合首板”四仓共享现金账户，不再渲染板块预热五组因子表、四组影子账户、旧留出诊断和轮动前向统计。
- 实时首板候选只显示一条“综合判断”，合并板块、资金、龙头、涨停基因、量能、换手、封板状态和风险原因。
- 不分别显示“板块预热研究”和“轮动影子”，也不增加研究开关、策略选择器或详情卡片。
- 没有合格候选时统一显示“综合首板暂无买点”，不展示各内部通道为何空仓。

## 内部算法

- 现有正式首板硬门、排序、TBOX、共享现金账户和交割单继续作为唯一产品结果。
- 板块预热、延续质量门和日内轮动继续在后端积累点时证据，保留研究 API 和审计字段，但不作为用户可选择的独立策略。
- 未通过真实前向门槛的研究因子不得改变正式 `action`。达到冻结后的样本数、收益、胜率和回撤门槛后，只能通过版本升级合入综合策略，不能在产品中新增第二套策略。
- 创业板、科创板、北交所和 ST 继续排除。

## 数据与错误处理

- 综合首板回测继续使用 100,000 元、最多四仓、100 股整数手、共享现金、T+1 和实际费用滑点。
- 研究接口失败不得影响正式综合首板回测和实时推荐页面。
- 内部轮动快照缺失或尚无 D+1 闭合时保持研究状态，不在用户界面显示零样本噪声。

## 验收标准

- `/limit-up -> 回测 -> 综合首板` 只出现一个综合策略结果，不出现预热、质量门、双通道或影子账户比较。
- 实时首板每只股票最多出现一条综合判断，不同时出现预热和轮动两条说明。
- 后端研究数据和测试仍保留，正式动作、排名和回测交易不因界面精简而改变。
- 前端测试、生产构建、桌面和移动端浏览器验证通过。
