# AlphaAgent 逐日行业成员回补设计

## 目标

用带纳入/剔除日期的申万行业成员记录重建逐交易日主行业，替换历史打板账本中“拿当前行业覆盖过去”的幸存者偏差。范围仍为沪深主板非 ST，不改变概念题材和 L2 门禁。

## 口径

- 输入支持 Tushare `index_classify + index_member_all` 和同字段 CSV。
- 每只股票每个交易日只保存一个申万二级行业；重叠区间按最新 `in_date` 取值并记录冲突数。
- 成员在 `in_date <= trade_date < out_date` 时有效；空 `out_date` 表示仍有效。
- 每日行业成员覆盖本地当日主板非 ST 日线股票至少 90% 才允许写入。
- 历史导入的 `captured_at` 记录导入时间，`raw` 保留 `in_date/out_date` 和供应商来源。
- 写入只替换当日 `sector_type=industry`，不得删除已经存在的概念成员快照。

## 产品与回测

数据管理“打板证据”页增加逐日行业成员区，支持日期范围、每批交易日、预检查、Tushare 和 CSV。数据质量门禁只统计达到每日覆盖门槛的行业快照日，并同时展示原始快照日和概念快照日。

历史账本重建优先按 `snapshot_date + vt_symbol` 选择当日二级行业；没有快照的日期才回退当前行业并明确标记 mixed/current proxy。只有覆盖目标达到门禁后，模型才可移除行业幸存者偏差阻断。

## 验收

- 无 token 时 Tushare 明确不可用，CSV 仍可预检查。
- 非主板、ST、无二级行业、错误/重叠区间均有审计结果。
- 覆盖不足、空响应和供应商错误不写库；重复导入幂等。
- 行业范围替换不删除同日概念快照。
- 历史账本测试证明同一股票在两个日期读取不同的点时行业，未来区间修改不改变更早日期。
