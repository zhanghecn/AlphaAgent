# AlphaAgent 打板动态退出与实时缓存设计

## 目标

第一版把 `/limit-up` 从“用户选择 D+1 开盘或收盘”改为系统按点时可见信息决定每笔退出方式，并让实时推荐提前给出观察、买入、取消和 D+1 卖出纪律。回测仍以 10 万元、最多四仓、100 股整数手、T+1、费用、滑点和跌停不可卖为正式口径。

## 已验证基线

- 历史账本覆盖 600 个交易日，当前组合有 275 个信号和 243 笔闭合交易。
- 固定 D+1 收盘账户为 `+203.7969% / 61.7284%`，固定 D+1 开盘账户为 `+71.0483% / 53.8168%`。
- 当前组合回测接口冷请求实测约 22.7 秒、响应约 2.9 MB。
- 历史严格竞价快照为 0；全历史只能使用 D+1 日线开盘价作为 09:25 竞价价格代理。严格竞价量和未匹配委托只从未来快照积累，不能回填历史。
- 分板位研究显示二进三大多数竞价区间继续持有更有利，高板强竞价更适合兑现，因此不能使用全市场统一阈值。

## 动态退出

正式模式为 `dynamic`。每个信号在 D+1 竞价时生成只读决策：

- `auction_exit`：按 D+1 开盘代理价卖出。
- `tail_exit`：持有到 D+1 收盘卖出。
- `retry_exit`：开盘或收盘跌停锁死时顺延到下一可成交时点。

第一版采用可解释的滚动策略，不引入小样本黑盒模型：

1. 默认沿用开发期整体更稳健的 `tail_exit`。
2. 只在同板位已有足够成熟样本、竞价兑现相对尾盘的复利和胜率优势同时为正时切换为 `auction_exit`。
3. expanding OOS 日期只使用 `result_date` 早于当前决策日的样本；locked holdout 使用开发期冻结策略，留出结果不参与阈值或规则选择。
4. 决策元数据记录训练截止日、样本数、竞价代理涨幅、选择原因和数据可信度。

旧 `next_open/next_close` 仅保留接口兼容和基准比较，产品页面不再暴露。

## 战法标签

战法标签从点时可见日线、历史涨停、分时路径、板块和情绪字段识别。标签本身不改变排名，只有独立 OOS 结果为正后才能成为推荐加分项。

- `sandwich_board`（夹板）：近期涨停后 1-3 个交易日压缩整理，再次突破区间。
- `return_board`（回马板）：半年内有涨停基因，前次涨停后充分回调但未破结构，再次封板。
- `weak_to_strong_breakout`（弱转强突破）：前日弱势或分歧，当前竞价和突破结构转强。
- `dragon_first_negative_relay`（龙首阴接力板）：高辨识度连板股首次阴线后重新封板。
- `dragon_weak_to_strong`（龙头弱转强）：龙头前日分歧，次日竞价、板块和承接共同转强。
- `anti_nuclear_board`（反核板）：前日大幅负反馈后反包涨停，默认研究观察。

无法由当前字段严格证明的标签必须带 `proxy` 可信度，不能显示成严格识别。

## 实时状态机

每只股票只显示一行，保留状态轨迹而不是按三通道简单去重：

`watch -> waiting -> actionable -> cancelled`

信号必须包含：

- 战法标签和板位。
- 选择原因。
- 买入触发条件。
- D+1 卖出条件。
- 取消条件。
- 最新状态时间和数据可信度。

盘后历史候选形成次日观察池；09:20 后按竞价和实时行情更新状态；首板继续依赖盘中接近涨停和封单稳定性。

## 缓存与接口

- 历史重建后生成紧凑研究数据集，避免每个请求反复读取 769 MB 回放 JSON。
- 进程内单飞 TTL 缓存负责任意日期区间；最新全历史五个 scope 在历史重建后预热。
- 回测响应仅返回页面需要的摘要、权益曲线、交割单和跳过订单，不重复返回完整嵌套信号。
- 实时 GET 只读取进程缓存或已保存快照；外部行情刷新由每分钟后台任务承担。
- 缓存键必须包含历史策略版本、退出策略版本、日期范围、scope 和账户参数。

## 页面

- 删除卖出方式下拉框。
- 回测摘要显示“系统动态退出”和竞价卖/尾盘卖笔数。
- 历史交割单显示实际卖出时点、退出原因和战法标签。
- 实时行展示状态、选择理由、买入条件、卖出条件、取消条件和更新时间。
- 保持现有紧凑表格结构，不增加说明型卡片或营销内容。

## 验收

- 动态决策测试证明当前结果不会读取当日收盘标签。
- locked holdout 冻结规则测试证明留出结果不能改变决策。
- 真实现金模拟支持同日竞价卖出释放现金、尾盘卖出不提前释放现金和跌停顺延。
- API 仍兼容旧退出参数，但默认返回 `dynamic`。
- 前端无固定退出控件，类型、构建和浏览器交互通过。
- 输出动态策略相对固定开盘、固定收盘的全历史、expanding OOS 和 locked holdout 对照；不得只报告最优结果。

## 风险边界

这是研究和模拟产品，不承诺封板、D+1 溢价或稳定复利。缺失 Tick/L2、历史严格竞价和逐日板块成员时继续标记 `research_only`，不得把代理数据描述成实盘等价。
