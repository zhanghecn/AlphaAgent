# 趋势弱转强(二板弱转强打板)产品需求设计

日期：2026-08-23
状态：已实现(2026-08-23,P0~P5 完成;同花顺问财实测与线上 ghcr 发布待用户执行)
策略定稿：`量化因子研究/低吸研究/趋势低吸研究-弱转强v2.md`(2026-08-23 定稿 v2.2,十一轮全市场验证 + 位置/连跌条件增补)
参考实现：潜龙首板产品线(同构复用:盘前池/盘中扫描/EOD 定版/回测物化/交割单/同花顺复制)、低吸产品线(四页签模式)

## 1. 目标与范围

把弱转强 v2 研究产品化为短线研究第三条产品线，对齐潜龙首板的四个页签：

- **实时推荐**：盘前池(A1/A2/B 三组，全部条件取自昨日及以前收盘数据)+ 盘中状态机(竞价过滤/+7% 触发/封板确认)+ 卖出跟踪(不板必走/板留断走)
- **回测**：日线回放引擎产品化(研究口径固定为 v2),分组汇总 + 分年/月度 + 锚点对账
- **历史交割单**：每日模拟成交逐票落库，按交易日保存回看(回测物化 + 前推真实模拟双口径)
- **规则说明**：三组条件 + 买卖规则人话版 + 数据支撑 + 已删除/证伪清单(防翻案)
- **同花顺条件复制**：A1/A2/B 三串条件，一键复制粘贴进同花顺动态板块直接筛

范围确认：

- 页面位置：`/short-term` 短线研究新增第三页签「趋势弱转强」(`?research=weak-to-strong`),
  与「潜龙首板」「低吸」并列
- **架构选择：整体复用潜龙首板产品线，不并入低吸产品线**。原因：弱转强 v2 全部池条件
  取自昨日收盘、买入靠盘中 +7% 触发/封板确认、卖出靠连板状态机——与潜龙首板同构
  (打板触发型)；低吸产品线是收盘评分制(无盘中触发、无封板/断板概念、D+1/3/5 标签),
  机制不同构，并入会破坏两条产品线的口径
- 与低吸页的关系：低吸页规则说明加一行交叉指引(“打板反包打法见趋势弱转强”);
  注意低吸趋势族已有规则「B 涨停弱转强 P1.5」——那是低吸持有打法，与本产品的
  二板反包打板不是同一打法，两边规则说明互相点名区分，避免混淆
- 不做：自动下单、券商对接；三板组(组 C 已被数据否定)；板块效应增强因子
  (研究待办，`stocks.industry` 填充率 0%,需改接 `sector_memberships`)

## 2. 策略规则(产品口径 = 定稿 v2.2,一字不改)

### 基本条件(入池硬门槛,T-1 收盘数据)

```
1. 主板  2. 非ST非退  3. 前十日内出现过连板(≥2连板)  4. 昨日未涨停
5. 昨日换手 3% ~ 60%(排雷:<3% 没人气 -1.21%/39%;≥60% 对倒假板 -1.02%/37%)
```

### 分组条件

```
A1 恐慌出清型(+7% 直接打,主力):
   基本条件 + 前段恰好 2 连板 + 昨日跌幅 > 3% + 昨日下影线 < 2%
   + 出清确认(昨日量比 0.7~1.2 或 昨日振幅 ≥ 12%)
   + 昨日换手 8% ~ 20% + 底座(20日涨幅) < 30%
   + 首板未创60日新高(二板首板日收盘 < 其前60日最高价,突破过顶不做)   [v2.1]
   + 前日也下跌(连跌两天再反包;同花顺: 前日涨幅小于0%)   [v2.2]

A2 强势整理型(只做封板确认,不打提前量):
   基本条件 + 前段恰好 2 连板 + 昨日上影线 < 2% + 底座(20日涨幅) < 30%

B 高位弱转强(+7% 直接打):
   基本条件 + 前段连板 ≥ 4板 + 距连板末日 ≥ 3个交易日(4天以上最佳)
   + 昨日跌幅 > 3% + 昨日下影线 < 2%
   + 出清确认(量比0.7~1.2 或 振幅≥12%) + 昨日换手 5% ~ 25%
```

组划分互斥规则：最近一次 ≥2 连板的高度 = 2 → A 组；≥ 4 且距连板末日 ≥ 3 天 → B 组;
= 3 → 组 C 已删除(无过滤 +0.62%/52%,加条件后 +0.31%/49% 更差,2026 年 -0.02),不做。

### 盘中买入

```
A1: 竞价 0% ~ +4% 才出手(9:25 可知,范围外放弃);
    盘中涨幅首次触及 +7%(价 = 昨收 × 1.07)直接打,不等确认
B:  无竞价过滤(见下方口径决定);+7% 触及直接打
A2: 不打提前量;盘中触及涨停价且扫描时现价仍封在涨停价 → 按涨停价模拟买入
全组: 昨日大盘(主板非ST)涨停 > 110 家 → 当天整池停手(情绪高潮日 -2.12%/35%)
```

### 卖出(统一,盘后日线定版)

```
买入日 T;从 T+1 起,首个未涨停日收盘卖(不板必走);
T+1 涨停则继续持有(板留),断板日收盘卖(断走);
T+15 仍未断板 → T+15 收盘卖(兜底,研究统计窗口即 15 日)
```

### 终版效果锚点(验收对账基准)

修正锚点(v2.2,2026-08-23 晚:A1 新增「首板未创60日新高」(v2.1)+「前日也下跌」(v2.2),
`量化因子研究/低吸研究/scripts/w2s_replay.py anchors` 可重现)。v2.1 根因:
主人提出「二板首板不该从新高位置启动(突破过顶)」假设,验证成立——
v2 池内过顶票封板率仅 36%/+1.00%,未过顶 63%/+2.32%;前日下跌与位置近似独立,

### 关键口径决定(与研究一致性)

- **组划分**:从 stock_limit_up_daily 重放每只票的连板序列,取最近一次 ≥2 连板的
  高度(last_streak)与距该段末日的交易日数(gap_days)。=2 → A 组;≥4 且 gap ≥3 → B 组;
  =3 → 不入池(组 C 已删除)
- **触发(A1/B)= 触及即买,不做收住确认**:研究口径即"盘中涨幅达 +7% 时以 +7% 价买入",
  与潜龙的"触及+次分钟收住+次分钟买"不同。产品前推:现价 ≥ 昨收×1.07(保留两位)
  → 买入,买价 = 触发价,**无滑点**(与研究锚点一致,规则说明披露)
- **A2 = 封板确认**:盘中触及涨停价且扫描时现价 = 涨停价(封板状态)→ 按涨停价买入;
  历史回测:收盘封板才视为买入(买价=涨停价),盘中摸板未封不算——保守下限口径
- **上影线口径(A2,重要)**:研究文档中"昨日上影线 < 2%"的实际计算口径是
  **(最高 − 收盘) ÷ 昨收 < 2%**(冲高回落幅度;阳线时与标准上影线定义相同,
  阴线时更严,隐含收在日内高位)。产品池按研究口径实现;
  同花顺条件串用原生"上影线"字段(标准定义),阴线日会有少量出入,Phase 0 问财实测对账
- **竞价 0~4% 过滤只挂 A1**:研究证据仅来自 A1 池(+0.32~0.57% 正区、≥+4% -1.58% 弃);
  B 组同库实测应用后样本 145→77 且收益不升(+1.93%→+1.64%,板留 +2.84%→+2.02%),
  故 B 不做竞价过滤;A2 本就等封板确认,无竞价概念。9:30 首次扫描以现货开盘价定
  gap,范围外标记 skipped_gap 不再触发
- **大盘停手**:昨日主板非 ST 涨停家数 > 110(从 stock_limit_up_daily 汇总,
  与研究同口径)→ 当日整池 halted,页面条幅提示;同库实测该规则在竞价后样本上
  额外剔除极少(139→139),保留是因为研究已证明高潮日剧毒(-2.12%/35%)
- **卖出全部盘后定版**:不做盘中退出跟踪;EOD 从 stock_limit_up_daily 逐日重放,
  T+1 起首个未涨停日收盘卖,T+15 兜底;退出原因:
  next_close_fail(T+1 未涨停)/ break_close(断板)/ max_hold_close(15日兜底)
- **除权污染**:回放剔除 |隔夜缺口| > 11% 的伪触发(潜龙先例,研究实测 ~0.09%);
  日线未复权,极端收益 ~2% 口径噪声,规则说明披露
- **版本纪律**:`W2S_RULES_VERSION = "w2s-v2.2"`,规则任何变更必须升版本并触发物化重算;
  worker 启动自检

## 4. 功能设计

### 4.1 实时推荐(live,默认页签,30s 前端轮询)

- **顶部状态条**:当前时段、今日池数量(按组拆分:A1/A2/B)、已触发/已买入/在持计数、
  最近扫描时间、回看日期下拉;**大盘停手红色横幅**(昨日涨停 >110 家时整日显示"今日停手")
- **主表「今日池 × 触发状态」**,列:名称/代码、组徽章(A1 恐慌出清/A2 强势整理/B 高位弱转强)、
  昨收、触发价(A1/B=昨收×1.07,A2=涨停价)、竞价高开(A1 列,范围外灰显 skipped)、
  现价/涨幅、状态徽章(待触发/已触发·已买入/封板持有中 N 板/未板次日卖/已了结/已跳过)、
  买入价/时间、卖出日期/原因、收益
- 排序:已买入 > 已触发 > 待触发 > 已跳过;组内按涨幅
- **复制按钮**(页头显著位):「复制同花顺条件」带组选择(A1/A2/B 三串,§4.5),
  toast 确认;旁边「盘中执行要点」折叠卡(竞价/停手/触发规则纯文本,不复制)
- 当天无池时回退最新可用池并标「非当日」徽章(stale 模式,潜龙同款)

### 4.2 回测(backtest)

- 汇总卡 ×3 组:n/封板率/D+1 平均每笔/胜率/连板率/板留断走,
  每项旁边展示锚点值,偏差超容差(n ±10%、收益 ±0.3pp)显示黄色提示(锚点门禁)
- 产品口径对照卡:A1 终版 vs A1+竞价+停手
- 分年表(每组一行四年,A1 全正/B 组 2023 负作常驻提示)+ 月度表
- 逐笔等权净值曲线(分组三条);「重新计算」按钮 + 进度条(重建轨道轮询)
- 规则版本号展示;口径标注"日线保守下限(A2 为收盘封板确认),无滑点,未复权"

### 4.3 历史交割单(ledger)

- 默认:回测物化 ledger_days——最近 60 个交易日逐笔(组徽章/买入价/卖出日期/卖出原因/
  连板高度/收益 %),按日聚合(笔数/胜率/平均收益)
- `?date=`:前推真实模拟成交(signals 表中当日有买入价的行),产品上线后逐日沉淀;
  两口径用 is_backtest 标志与文案区分(潜龙同款)
- 顶部月度汇总条:当月笔数/胜率/累计收益

### 4.4 规则说明(guide)

- 前端静态文案(低吸 guideContent 模式 + spec 防漂移测试),分组呈现:
  基本条件 5 条 / A1 条件 + 分桶证据摘要 / A2 条件 + 证据 / B 条件 + 回落天数表 /
  买入规则(竞价/停手/+7% 阈值依据)/ 卖出规则(不板必走、板留断走)
- 「已删除与证伪清单」完整收录:组 C 三板(数据否定)、回落≥2天/涨停<4次/非一字
  (组合内冗余)、换手 40% 悬崖(证伪,只是保险丝)、上影线 2% 悬崖(证伪,平坦谱)——
  文案目的:防止以后把删掉的条件加回来
- 风险声明:封板率天花板 52~60%、A1 对大赢家误杀率 67%(有意权衡)、B 组 2023 年样本少
  且最薄、2026 年反包生态走弱、除权口径噪声
- 案例锚点(策展):平潭发展 2025-10-22(A1 好票)/ 晋拓股份 2026-07-09(换手 61% 不入池)/
  汇嘉时代 2023-10-31(出清确认挡住)/ 厦门港务 2025-12-12(B 组回落 1 天禁做)/
  荣盛发展 2023-07-27(误杀代表)
- 与低吸「B 涨停弱转强 P1.5」规则的区分说明(一句话互链)

### 4.5 同花顺动态板块条件(复制内容,三串)

A1(盘后候选池):

> 主板;非ST;非退市;近10个交易日内出现过连续2个及以上涨停;昨日未涨停;前日涨幅小于0%;昨日跌幅大于3%;昨日下影线小于2%;昨日换手率8%到20%;昨日量比0.7到1.2 或 昨日振幅大于12%;近20日涨幅小于30%

A2(盘后候选池):

> 主板;非ST;非退市;近10个交易日内出现过连续2个及以上涨停;昨日未涨停;昨日换手率3%到60%;昨日上影线小于2%;近20日涨幅小于30%

B(盘后候选池):

> 主板;非ST;非退市;近20个交易日内出现过连续4个及以上涨停;近3个交易日未涨停;昨日未涨停;昨日跌幅大于3%;昨日下影线小于2%;昨日换手率5%到25%;昨日量比0.7到1.2 或 昨日振幅大于12%

- 全部字段同花顺原生;A2 的"上影线"是标准定义,与产品池口径(冲高回落幅度)
  在阴线日有少量出入,§3 已披露
- B 串"近3个交易日未涨停" ≈ 距连板末日 ≥3 天
- 竞价 0~4%、大盘停手、+7% 触发、封板确认都是盘中条件,同花顺表达不了,
  按定稿先例注明"盘中执行,不在盘后筛选"
- 实施期必须做问财解析实测(Phase 0):粘贴建板块,与同日本产品池名单对账
