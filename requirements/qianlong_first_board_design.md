## 1. 目标与范围

把潜龙首板从「无状态实时榜」升级为完整短线产品线，对齐低吸的四个页签：

- **实时推荐**:盘前池(昨日 8 条硬条件)+ 盘中 +8% 触发/收住确认状态机 + 卖出跟踪
- **回测**:日线回放引擎产品化(研究脚本口径固定为 v4),月度表 + 净值 + 分段统计
- **历史交割单**:每日模拟成交逐票落库，按交易日保存回看(对齐低吸 ledger)
- **规则说明**:18 条死规则人话版 + 数据支撑 + 已证伪清单(防翻案)
- **同花顺复制按钮**:一键复制盘前池条件串，粘贴进同花顺动态板块直接筛

范围确认：

- 页面位置：`/short-term` 默认 tab「潜龙首板」内重构(现为 FirstBoardLeaderPage 单榜)
- 现有东财涨停池「已封板首板榜」保留为实时推荐页的一个辅助区(复盘对照用),
  主表改为「今日池 × 触发状态」
- 不做：自动下单、券商对接；弱转强/缩量另立研究(已证伪清单见定稿第七节),
  不进本产品
- ≥50×多头高价口袋(研究副产物)归趋势低吸体系，不进本产品

## 2. 策略规则(产品口径 = 定稿 v4,一字不改)

### 盘前池(T-1 收盘数据，8 条硬条件)

```
1. 主板  2. 非ST  3. 昨日涨幅 0%~+5%(收阳,蕴含昨日未涨停)
4. 昨日最低价在 20 日线上方  5. 距 20 日线不超过 +12%
6. 昨日换手率 < 8%  7. 总市值 < 1200 亿  8. 股价 < 12 元
```

### 盘中买入(6 条死规则)

```
9.  只在 09:30~11:30 做,午后一律不做
10. 高开 ≥ +8% 不做
11. 触发:涨幅首次触及 +8%(价 = 昨收 × 1.08)
12. 确认:该 1 分钟 K 线收盘仍 ≥ +8%(收住)
13. 进场:下一分钟开盘价买入
14. 同日多信号排序:高开 2%~6% 的先做
```

### 卖出(3 条)+ 风控(1 条)

```
15. 当日未封板 → 次日开盘卖
16. 封板但未封二板 → 次日开盘卖
17. 连板 → 持有,断板日卖
18. 当月累计亏损达 -5% → 当月停止交易(产品内为熔断提示条)
```

### 终版效果锚点(验收对账基准)

| 口径 | 样本 | 平均每笔 | 胜率 |
|---|---|---|---|
| 8 条池全信号(日线保守下限,含 0.5% 滑点) | 6,351 笔/41 月 | +2.39% | 50.6% |
| 池内只做高开 2~6% | 1,705 笔 | +5.69% | 73.3% |

> 锚点修正(2026-08-23 产品化对账时发现):`stock_daily_bars.change_pct` 列存在约 20 个
> 交易日的历史缺口(覆盖率 <50%),研究期条件在这些日静默失效。产品口径用收盘对收盘
> 推导回填,池从 6,205 修正为 6,351;高开 2~6% 子集旧锚点 2,014/+5.12/69.6% 来自
> 旧变体脚本,规范管线现为 1,705/+5.69/73.3%。定稿文档第五节已同步修正。

### 直接复用的实现模式

- 快照持久化:`low_suction_live_snapshots`(每交易日一行 JSONB)+
  `live_snapshot_repository.py` save/load/list_dates 三件套
- 盘中每分钟扫描:`low_suction_live_scan` 批次(`* 9-15 * * 1-5`)+
  `refresh_live_recommendations` + `_merge_spot_bars`(现货合并虚拟 K)
- 回测物化:`low_suction_daily_backtest_runs`(单行 JSONB)+
  `POST /backtest/rebuild`(后台线程 + 409 去重)+ `GET /backtest/status` 轮询
- 交割单口径:`daily_picks_backtest.py` 的 `_position_simulation` / `_recent_ledger`
- 规则说明:低吸 `guide/guideContent.ts` 静态文案 + `guideContent.spec.ts`
  完整性断言防漂移(案例可后接 API)
- 复制按钮:`AppShell.tsx:52 copyText()`(clipboard API + 降级)+ useToast
- 调度注册四处同步:`DEFAULT_JOBS` / `JOB_CADENCES` / `JOB_RUNNERS` /
  `DEFAULT_BATCH_SCHEDULES`(见 `lianban_review_implementation_plan.md` 关键既有事实)

### 关键口径决定(与研究一致性)

- **触发检测(盘中)**:每分钟扫池内现货;首次 现价 ≥ 昨收×1.08 记 `touched`;
  下一分钟扫描时该分钟收盘价仍 ≥ 触发价记 `confirmed`(可买),模拟买入价 =
  确认时刻现价 ×(1+0.5% 滑点)。与研究分钟口径(触板分钟收住→下一分钟开盘买)
  等价近似,规则说明里注明
- **回测(历史)**:日线保守下限口径——最高价 ≥ 触发价即视为触发
  (无法回放分钟级收住),与研究 41 个月报表一致;页面标注"保守下限"
- **历史分钟数据只覆盖 2026-06 起**,不回溯用于回测,只用于实时检测
- **卖出/退出价**:全部在盘后 EOD 用日线补(次日开盘价/断板日开盘价),
  不做盘中退出跟踪;连板持有期每日 EOD 检查断板
- **除权污染**:回放剔除 |隔夜缺口|>11% 的伪触发(研究实测 0.09%);
  日线未复权,规则说明注明
- **版本纪律**:`QIANLONG_RULES_VERSION="qianlong-v4"`,规则任何变更必须升版本
  并触发物化重算(参照 SCORE/BACKTEST_VERSION 漂移事故教训);worker 启动自检

## 4. 功能设计

### 4.1 实时推荐(live,默认页签,30s 前端轮询)

- **顶部状态条**:当前时段(盘前/上午可交易/午休/已过时段)、今日池数量、
  已触发/已收住/已买入计数、当月模拟盈亏 + 熔断提示(达 -5% 显示"当月停止")
- **主表「今日池 × 触发状态」**,列:名称/代码、昨收、触发价(昨收×1.08)、
  高开幅度、现价/涨幅、状态徽章(待触发/已触及/已收住·可买/已买入/禁做·高开≥8%/
  已封板/炸板)、触发时间、连板跟踪(持有中 N 板/断板卖出)
- 排序:可买 > 已触及 > 待触发;同状态内高开 2%~6% 标记「先做」徽章(规则 14)
- 高开 ≥8% 的票灰显禁做(规则 10),不混在可交易列表里
- **辅助区「已封板首板榜」**:迁移现有 FirstBoardLeaderPage 表格(东财涨停池
  limit_up_count==1,封单成比排序),用于对照"池外封板/池内漏网"复盘
- **复制按钮**(页头显著位):「复制同花顺条件」→ 复制 §4.5 条件串,toast 确认;
  旁边「盘中执行要点」折叠卡(规则 9~14 纯文本,不复制)

### 4.2 回测(backtest)

- 汇总卡:全样本触发数/封板率/连板率/平均每笔/胜率/月均信号数
- 月度表(41 个月):每月笔数/平均每笔/胜率/正收益月标记
- 分段卡:训练段(2023-01~2025-06)vs 验证段(2025-07 起)对照 + 衰减提示
- 模拟仓口径:每日最多 3 笔、高开 2~6% 优先、等权、0.5% 滑点,净值曲线;
  熔断叠加层(当月 -5% 停手)单列一行对照
- 「重新计算」按钮 + 进度条(复用低吸 rebuild 模式),规则版本号展示

### 4.3 历史交割单(ledger)

- 按交易日归档,日期可切换回看;最近 60 个交易日默认
- 每行:名称/代码、触发时间、买入价、卖出价、卖出日期、收益 %、
  结果徽章(连板 N 高度/次日卖/断板卖/炸板止损)
- 顶部月度汇总条:当月笔数/胜率/累计收益/熔断状态

### 4.4 规则说明(guide)

- 前端静态文案(低吸 guideContent 模式 + spec 防漂移测试),四组呈现:
  盘前池 8 条 / 盘中买入 6 条 / 卖出 3 条 / 风控 1 条
- 每条附数据支撑摘要(t 检验 p 值,摘自定稿第六节)
- 「已证伪清单」完整收录(定稿第七节),文案目的:防止以后把删掉的条件加回来
- 风险声明:验证段衰减(+2.31→+0.60)、仓位按近 3 月实盘调、连续 3 月恶化停用

### 4.5 同花顺动态板块条件(复制内容)

> 主板;非ST;非退市;昨日涨幅0%到5%;昨日最低价大于20日均线;昨日20日乖离率小于12%;昨日换手率小于8%;总市值小于1200亿;昨日收盘价小于12元

- 全部字段同花顺原生;「昨日涨幅 0~5% 收阳」已蕴含昨日未涨停,无需另写
- 实施期必须做问财解析实测(Phase 0):粘贴建板块,与同日本产品池名单对账,
  允许 ST/退市口径微差,其余必须 100% 一致;不通过的字段换同义表达
  (备选:「昨日收盘价大于20日均线」+「昨日20日乖离率0到12%」两条件替代第 4/5 条)
- 盘中规则(9~14)同花顺表达不了,按先例(弱转强 v2)注明"盘中执行,不在盘后筛选"

## 8. 验收标准(案例门禁)

1. **池对账**:产品池 vs `scripts/fb_current_pool.py` 研究脚本,随机 5 个交易日,
  名单 100% 一致
2. **回测对账**:产品回测全样本口径 = 修正锚点(6,351 笔/+2.39%/50.6%,
  高开 2~6% 子集 1,705 笔/+5.69%/73.3%),容差仅来自新增交易日
3. **信号对账**:分钟覆盖期内(2026-06 起)产品信号 vs `fb_final_binary.py`
  分钟口径,触发/收住/买入价一致率 ≥ 98%
4. **同花顺对账**:§4.5 条件串问财实测,与产品池名单一致(ST/退市口径除外)
5. **案例抽查**:智光电气 2025-10-17(秒板炸板→未封板次日卖)、
  雪龙集团 2026-07-13(午后脉冲→不做)、天安新材 2024-06-06(除权→剔除)
  三个研究期核查过的案例,产品行为与研究结论一致
6. 熔断:模拟当月 -5% 后 live 页出现停止提示且不再给「可买」徽章
7. Docker Compose 全链路验证(不经 5173),线上走 ghcr 镜像发布纪律

## 9. 风险与边界

- 验证段收益约为训练段 1/4(首板生态变薄)——页面常驻提示,仓位建议按近 3 月;
  连续 3 个月恶化应在产品上停用(人工动作,规则说明写明)
- 盘中触发检测依赖腾讯现货每分钟扫描,极端行情 tick 漏检可能;
  收住确认为分钟级近似,与研究口径的差异已在 §3 注明
- 历史回测是日线保守下限(上影线触发),真实分钟收住口径略优;
  两个口径都在页面标注,不混用
- 除权未复权数据的残余污染 < 0.1%,规则说明披露
