## 一句话设计

**挖掘机找格, 动态组管时代, 体检仪报警。**

主人担心的「2年后口诀全变」拆开是两件事:
1. **提前看见变化** → 层1 体检仪(全自动监控, 无争议, 必做)
2. **变化发生后有替补** → 层2 挖掘机(半自动: 机器出候选+纪律过滤, **主人拍板
   形态故事才立规**)

组与组之间谁来接班的问题, 动态组机制(近12月均值高者, 七年全切对)已经解决了,
不重造。本计划只补口诀层。

## 三层架构与边界

| 层 | 做什么 | 自动化程度 | 为什么 |
|---|---|---|---|
| L1 体检仪 | 每条口诀滚动成绩+三色预警 | **全自动**(纯监控只报警不动手) | 监控无风险, 直接回应「实时跟踪」 |
| L2 挖掘机 | 词汇表内穷举候选→七条纪律机器化过滤→人审清单 | **半自动**(机器出候选人拍板) | 形态故事是口诀的灵魂, 机器只配当苦力 |
| L3 全自动换口诀 | — | **不做** | 口诀级滚动筛选已证伪(+6.74 vs +9.78); 机器不该有换口诀的权力 |

### 为什么不全自动(写给2年后的自己)

- 证据1: 口诀级滚动筛选(近12/24月成绩好的口诀才启用)全面差于现状整组启用
  ——「用近期成绩挑旧口诀」都不成立, 「用近期成绩立新口诀」只会更不稳。
- 证据2: 大肉漏网 446 笔与死票同格, 形态层自动挖掘收不到新肉(二三接审计定论)。
- 证据3: 现有 13 条编号口诀 = 人工形态故事(信隆穿线/神雾掉线/保华瓷强开链)
  + 数据验证的结合产物, 故事层是防过拟合的最后一道闸。
- 但注意边界: 上述证据否决的是「机器自己定口诀」, **不否决**「机器穷举+人审」
  ——挖掘机 MVP 的价值是把生产线先架好, 等 2 年后旧格真死时有替补产能。

## S1 体检仪(1天, 先做, 纯赚)

脚本: `量化因子研究/高位接力/scripts/koujue_health.py`(宿主机
`uv run python` 直跑, 形态对齐 relay23_*.py 研究脚本惯例)。

### S1.1 冷重建打标表

- 从 CSV 读全量 → `tag_both()`(抄 relay23_leakguard.py)打 `s_no`/`w_no` 列
  → 落 `代码/买入日/年/月/E3%/s_no/w_no` 精简表(内部缓存 /tmp, 可重建)。
- 验收: N=2/3 子集 4466 笔、强市命中 269 / 弱市 104 / 双命中 27——
  与 P7 审计数字对上(±6笔 CSV 与产品库微差已在 P7 声明)。

### S1.2 口诀×滚动窗成绩表

- 对每条编号(强市 A1..C3 按子分支合并、弱市 K2..K9):
  逐月末 t 计算 3 个滚动窗指标(窗内不含当月, 口径对齐 DYN_GROUP_WINDOW):
  - 近12月: n / E3均值 / 胜率 / 剔Top3均值
  - 近6月: n / E3均值
  - 全时段(累计): n / E3均值 / 胜率
- 产出长表: (口诀, 截止月, 窗, n, avg, win, trim3)。

### S1.3 三色预警规则(默认值, 主人可改)

| 色 | 条件(全部满足) | 含义 |
|---|---|---|
| 绿 | 近12月均值 ≥ 全时段均值×0.5 | 健康 |
| 黄 | 近12月均值 < 全时段×0.5; 或 近6月≥5笔且均值<0 | 观察 |
| 红 | 连续 2 个年末快照都是黄, 且近12月均值 < 全时段×0.25 | 衰退, 触发 L2 |

- 小样本防抖: 近12月 n<8 不判色(挂「样本不足」, 与 DYN_GROUP_MIN_N 一致)。
- 设计原则: 报警是**信息层**, 不自动改判定层——与动态组「状态」不同,
  口诀生死必须走人审。

### S1.4 历史回放验证(本计划的杀手锏验收)

- 已知的真漂移只有一次: 弱市→强市组切换 2023-09。
- 用 S1.2 长表回放: 2023-06/07/08 三个月末, 弱市 K 系各条分别是什么颜色?
  强市组各条又是什么颜色?
- **验收判据**: 切换前 K 系至少 3 条报黄(及以上)且强市组无红 → 体检仪真的
  能提前 ~3 个月看见漂移, 检测器有效。
- 若回放不报警 → 回调阈值(腰斩线 0.5→0.7 / 6月笔数 5→3)重放, 直到能;
  若怎么调都只能在切换当月才报 → 诚实记录「检测滞后=1个月, 提前量不存在」,
  这本身是重要结论。

### S1.5 当前体检报告(立即交付)

- 14 条编号 × 当前颜色 + 近12月数字 + 与全时段对照, 一张表在对话交付。
- 顺带输出: 当前动态组状态(强市)下, 哪几条强市口诀其实是「吃老本的」
  (近12月均值显著低于自身全时段)。

## S2 挖掘机 MVP(1~2天, 待主人拍板后做)

脚本: `量化因子研究/高位接力/scripts/koujue_mining.py`。

### S2.0 复刻实验(rediscovery test, 半天, 先于一切挖掘跑)

主人验收问题: 「能不能提取出对应的口诀, 起码跟目前的差距不是很大吧」——
不用猜, 量出来:

- **做法**: 假装机器不知道现有 13 条口诀的存在。词汇表内穷举(S2.2 漏斗)+
  纪律过滤(S2.3, 全时段口径)+对照审计(S2.5), 看幸存候选能撞回多少现有口诀:
  - 指标1 **召回率**: 现有口诀命中票(346笔)中被幸存候选覆盖的比例
  - 指标2 **逼近度**: 每条现有编号找最接近的幸存候选(逐条 Jaccard+数字对照)
  - 指标3 **信噪比**: 幸存候选总数 vs 其中「旧口诀近亲」数——假阳性格有多少
- **判读**:
  - 召回 ≥70% 且每条现有编号都有近亲候选 → 挖掘机搜索空间可信,
    「跟目前差距不大」成立, 2年后挖新口诀有底气
  - 召回 <70% → 有格在词汇表外(人工形态故事的独有价值), 诚实列出
    机器挖不回的口诀和它们的票——这就是「机器版与目前的真实差距」
  - 信噪比差(几百个候选淹死真口诀) → 证明人审/形态故事不可省,
    印证 L2 半自动边界
- 这个实验同时是「S2 做不做」的最硬决策依据, 排在 S1 之后立即跑(半天)。

### S2.1 词汇表物化

从 SCHEMES/WEAK_SCHEMES 抽条件维度, 固化为挖掘词汇表(约10维, 每维离散窗格):

| 维度 | 取值来源 | 说明 |
|---|---|---|
| 板位×阴阳 | group4(二接三阴/阳, 三接四阴/阳) | 4 池 |
| b1/b2/b3开盘% | 现有窗格体系离散化(贴零/温开/强开/一字…) | 复用口诀卡语言 |
| 买入开盘%(today) | 5~9.5 现行窗 + 候选扩窗格 | ≥9.5 顶格永久排除 |
| b2/b3换手% | 5~10/10~20/20~30 格 | 换手接力语言 |
| 地基涨跌% | <1 / 1~3 / ≥3 | C2 先手小阳语言 |
| 首10日涨幅 | <20 / ≥20 | A2 透支语言 |
| 地基姿态 | 站线上/骑线/贴线/掉线下 | 姿态尺语言 |
| 锚位%+锚距 | 贴锚/断锚/大超 | C2 锚语言 |
| 前10日窗口衍生 | 现有列直接用 | 不造新特征(YAGNI) |
| 前波60日最高板 | ≤2 / ≥3 | 阴阳判别器语言 |

- 硬约束: 只用 T-1 收盘 + 9:25 竞价已知列(七条纪律第7条), 词汇表入表时
  逐维标注信息时点, 不明时点的一律不入。

### S2.2 候选生成(三层漏斗, 控计算量)

1. **单腿扫描**: 每维每窗格在全池的 n/均值/胜率 → 均值≥+3 且 n≥30 的窗格入池。
2. **双腿穷举**: 入池窗格×入池窗格(跨维组合) → 逐组合过纪律初筛。
3. **三腿收口**: 只对「双腿已过纪律且第三腿能再提胜率≥5pct」的做, 不全搜。
- 计算量预估: 单腿 ~200 格、双腿 ~2万组合×4池 → pandas 向量化分钟级, 无需引擎。

### S2.3 纪律机器化(七条里六条可代码化)

| 纪律 | 机器化 |
|---|---|
| n≥10 | 近窗 n≥10(全时段另算) |
| 胜率≥60% | 直接算 |
| 剔Top3正 | 直接算 |
| 分年一致性 | 近24月逐年同号 + 全时段不出现 -10 级毒年 |
| 边界洞±1 | 数值窗自动 ±1 扰动重算, 均值降幅>50% 判孤峰 |
| 无未来函数 | S2.1 时点标注保证 |
| 逐票点名 | 候选清单必须带全部票的 代码/日期/E3(主人审) |

### S2.4 双窗口验证(防「强市段局部」, P4 教训写死)

每个幸存候选两本账都要过:
- **近24月窗**(证明「现在有效」): n≥10 / 胜率≥60% / 剔Top3正 / 逐年同号。
- **全时段**(证明「不是时代彩票」): 不要求全正, 但 2020-2022 任一年不得
  ≤ -10(与旧时代剧烈冲突的格=强市段局部, P4 扩窗四项全灭的直接教训)。
- 时代管理交给动态组: 新口诀按其 group4 归入强市/弱市组, 切换由既有机制管。

### S2.5 对照审计(防重新发明旧口诀)

- 每个候选与 13 条现有编号的命中率重叠: Jaccard≥0.7 → 标注「旧口诀近亲」
  降级为旧口诀的扩窗/收缩建议, 不占新编号。
- 增量票(候选命中且现有全不命中)单列——这才是真新增产能。


## 执行结果(2026-10-10, S1+S2.0 完毕)

### S1 体检仪(koujue_health.py)——能看见「谁在死」, 看不见「谁登基」

- 打标验收对齐 P7: 强市269/弱市104/双命中27。滚动表 1022 行(13编号×月末)。
- 首版教训: 组级「近12月≥8笔」门槛在口诀级全屏失明(单条口诀月均仅0.5~0.9笔),
  改主窗=近24月+门槛5笔+累计≥12笔。
- **S1.4 回放考卷(关键发现)**: 2023-06/07/08 弱市K系黄/红=0条——不是检测器瞎,
  是信号本身不存在: 诊断矩阵显示切换前K系近24月/累计比值全部健康(0.62~1.49),
  强市组当时反而半死(SA2 比值-0.08红, SB1/SC2 黄)。
  **2023-09 的组切换是「新王登基」型(强市组近12月爆发反超), 不是「旧王衰退」型
  (弱市口诀当时没死, 真正衰退在 2024-12 之后: KK2 2025红/KK4 2026红/KK9 2025红,
  比组切换晚1.5~2年)。体检仪只盯旧口诀腰斩, 天然看不见登基——登基归动态组管
  (七年全切对), 三层分工恰好互补无死角。**
- S1.5 当前体检: 强市8条全绿(比值1.48~3.21, SB1 近24月+20.64 胜89%),
  弱市 KK4红(5笔-6.04 胜20%)/KK9红(11笔-0.37 胜18%)/KK2黄(剔3-2.37),
  KK5 逆势肥(6笔+16.76 胜83%)——「弱市组整体死」不等于「每条都死」。

### S2.0 复刻实验(koujue_mining.py)——「跟目前差距不大」不成立, 差距很大

三窗对答案(词汇表=现有口诀窗格语言, 漏斗: 基础网格初筛→附加腿0~2→全纪律):

| 窗口 | 窗内笔数 | 幸存候选 | 对照 | 召回率 | J≥0.5候选 |
|---|---|---|---|---|---|
| 全时段 2020-2026 | 4466 | 52 | 13条/346笔 | **21%** | **0个** |
| 弱市时代窗 2020-08~2023-08 | 1852 | 4 | K系/37笔 | **0%** | 0个 |
| 强市时代窗 2023-09~2026-10 | 2207 | 30 | 强市8条/137笔 | **32%** | 0个 |

- 逼近度天花板: SB1 J=0.44(全时段)——最强也重叠不到一半; A2/B2/B3/K4/K9 零重叠。
- 差距的三个来源(与现有口诀对比): ①**精修窗**: 现有口诀窗是手调的(b2开(-99,1)
  跨两档、今开(6,9.5)跨三档), 4~6档粗格要么稀释(混毒票过不了纪律)要么切掉肥票;

两个根因(比结果本身更重要):
1. **信息边界**(场景1): 新时代的有效形态在旧时代末段还没有成绩——强市口诀

   旧成绩并不好。**新时代口诀的验证数据在切换前不存在, 这是信息的边界,
   不是脚本的缺陷。**
2. **选择偏差**(场景2): 即便切换后新形态已有成绩, 「每类分数Top1」= 5839 个
   幸存格里运气最好的格=过拟合最重的格, 样本外必回撤(训练29笔+8.9 → 样本外
   -1.1)。人工13条能活, 因为挑选依据是形态故事(行为学解释)而非分数——
   信噪比 450:1 的最终实证。

**2 年后口诀真全变时的真实方案(终版)**:
1. 体检仪看见旧口诀死(已验证: K系2024-12后转红) → 知道该动了
2. 动态组在现有两组间切(已验证七年全切对) → 若两组全死才是真剧变
3. 真剧变时: 锻造炉切换后跑, 端出每类 TopN 候选卡(几十张, 不是分数Top1)
4. **主人看票挑+讲形态故事** → 新口诀立规。机器把搜索空间从全市场压到几十张卡,
   最后一步选择权在人——这是把选择偏差过滤掉的唯一手段。
**机器挖得出格、挑不出王; 挑选依据必须是故事不是分数。全自动换代被双场景证伪。**
