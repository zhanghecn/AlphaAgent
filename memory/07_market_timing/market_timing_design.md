# 大盘择时：金手指/银手指信号设计

> 大盘择时信号模块。金手指=看多（趋势向上），银手指=看空（趋势向下）。
> 第一版聚焦「算法 + 自主测试准确率」，界面/落库为第二阶段。

## Current state（当前状态）

- 信号语义：**反转 + 趋势分阶段**。底部反转金手指（抄底）、主升中继金手指（顺势）、顶部反转银手指（逃顶）。
- 算法：**方案A 多因子加权打分 + 分级触发**。
- 预测口径：**多周期分级**（5/10/20 日大盘综合指数累计收益方向）。
- 信号频率：**分级信号**（强/中/弱三档，各自带历史胜率，主人自选档位）。
- 触发方式：**边沿触发**（方向切换到 GOLD/SILVER 的首日记为事件，HOLD 不重复）。

## 算法核心

### 大盘基准
- 用 `market_context.INDEX_WEIGHTS` 对 7 大指数**日收益率加权**再 cumprod 成综合序列（避免量纲冲突）。
- 图表默认展示上证指数，信号基于综合序列。

### 5 族因子（全部 `≤t` 数据，无未来函数）

| 族 | 权重 | 来源 |
|---|---|---|
| 趋势 trend | 0.25 | 复用 `ctx.trend_score` |
| 动量 momentum | 0.25 | `0.5×ctx.momentum_score + 0.25×MACD分 + 0.25×RSI分` |
| 广度 breadth | 0.25 | 复用 `ctx.breadth_score` |
| 波动结构 structure | 0.15 | `100-risk_score + 波动收敛 + 连阳` |
| 量能 volume | 0.10 | 量比 + 量价同向 |

`bull_force = Σ(族分 × 族权重) ∈ [0,100]`，50 为中性。

### 阶段适配（复用 `classify_trading_market_phase` 四阶段）
- `warming`/`uptrend`：金手指主场（回暖抄底、主升顺势）。
- `retreat`：银手指主场（破位确立下跌）。
- `rotation`：金/银都可能（震荡顶底）。

### 分级阈值（第一版经验值，待回测校准）
- 金手指：强 ≥78（+阶段+breadth≥55+量能≥60）/ 中 ≥66（+阶段）/ 弱 ≥58
- 银手指：强 ≤22（+retreat+momentum≤40）/ 中 ≤34（+阶段）/ 弱 ≤42
- 42 < bull < 58：中性无信号

## 反未来函数硬约束
1. 所有特征严格 `≤t`；MA/RSI/MACD/广度量都用截止 t 的窗口。
2. 未来收益（t+1..t+20）**仅由 backtest 模块用于评估标签**，不进特征。
3. 信号生成（`signal`）与回测评估（`backtest`）物理隔离（不同模块）。
4. 自动化测试 `test_market_timing_no_lookahead.py` 断言「篡改 t 之后数据，t 及之前因子/信号不变」，CI 守护。

## 测试与准确率（自主测试）
- 样本：2024-05-28 ~ 2026-06-30（507 交易日，预热后约 447 天可发信号）。
- 矩阵：方向 × 档位 × 周期 → 次数/胜率/均收益/最差反向波动。
- **Bootstrap 95% CI**：强信号样本少，给胜率加置信区间，区间过宽标注「样本不足」。
- **随机基准**：全样本未来 N 日上涨比例（证明胜率 > 基准不是偶然）。
- **全仓持有基准**：首→末收益（证明信号跑赢躺平）。
- **时间切分**：前 80% / 后 20% 各档胜率对比（检测过拟合）。

## 模块结构
```
alphaagent/server/services/quant/market_timing/
  __init__.py
  series.py     # 7指数加权综合序列 + 技术指标(MA/EMA/MACD/RSI/ROC/波动率/量比)
  factors.py    # 5族因子打分(复用 market_context 得分 + 补充技术因子) → bull_force
  signal.py     # 阶段适配 + 分级阈值 + 边沿触发 → 金手指/银手指事件
  backtest.py   # 多周期胜率 + bootstrap CI + 随机/持有基准 + 时间切分
scripts/market_timing_eval.py              # 评估脚本(连真实库跑准确率)
tests/.../test_market_timing_no_lookahead.py  # 无未来函数断言
```

## Evidence（证据）

### v1 结果（镜像银手指 + 金手指严阈值）
2024-05~2026-06, 507 天, 事件 34(金27/银7)。金手指 WEAK 20d=79%[62,96] ✅；金手指 MEDIUM/STRONG 样本不足(阈值过严)；银手指 WEAK 20d=**0%** ❌(镜像逻辑失效)。

### v2 结果（独立 bear_force 顶部因子 + 金手指放宽阈值）
2024-05~2026-06, 507 天, 事件 51(金30/银21)。bull_force 中位60/P80 68.6；bear_force 中位50/P80 57.4。

| 信号 | 档位 | 5d | 10d | 20d | 判定 |
|---|---|---|---|---|---|
| 金手指 | WEAK(22) | 59% | 73% | **86%**[71,100] | ✅ v1 的 79%→86%, 更强 |
| 金手指 | MEDIUM(7) | 43% | 29% | 14% | ⚠️ 放宽阈值后捕获假突破, 反不如 WEAK |
| 银手指 | WEAK(18) | 28% | 44% | 33% | ❌ 仍失效(0%→33% 略好, 不及格) |
| 银手指 | MEDIUM(3) | 33% | 33% | 0% | ❌ 样本极少 |

- 随机基准 5/10/20d = 56/56/59%；全仓持有 +71.74%（单边牛市）。
- 样本外(2026-01-23 后)：金弱20d 5/6=83%（稳）；银手指仍差。
- 无未来函数：6 测试全过 `tests/.../test_market_timing_no_lookahead.py`。

## v2 诊断与结论
- **金手指 WEAK 是稳定赢家**：86% 20d，样本外 83%，捕捉「回调企稳买入点」——本功能最有价值输出，可作产品主信号。
- **金手指 MEDIUM 反直觉变差**：放宽阈值(63+WARM)在牛市捕获的是「涨过头近顶」假突破。→ 档位概念对金手指不适用，应简化（WEAK 为主）或重新定义档位（按"回调深度"而非 bull 高低）。
- **银手指仍失效，但根因是数据**：独立顶部因子(广度顶背离/MACD顶背离/放量滞涨/破位)已实现，但样本期 +71% 单边牛市无真正顶部，任何看空信号都被打脸。bear_force 中位仅 50 说明顶部信号极少真出现。**非算法失败，是数据限制**。
- **验证银手指的唯一出路**：补更长历史指数数据（含 2015/2018/2021 熊市大顶），否则银手指无法证伪。

### v3 仓位状态机（吸收主人反馈：信号不应频繁交替）
**问题**：v1/v2 单日边沿触发，bull/bear 阈值附近抖动 → GOLD/SILVER 频繁横跳，违背「银手指=空仓等待, 金手指=重新进场」的仓位语义。
**改法**：`signal.py` 改为仓位状态机（LONG/SHORT/FLAT）+ 连续确认 + 状态保持滞回。
- 进入多头后保持，直到银手指条件确认才转防守；反之亦然。
- 切换需连续 CONFIRM_DAYS 天满足（默认 1；状态保持已防交替，CONFIRM 仅过滤单日噪声）。
- 事件 = 状态切换点（金手指=进场日，银手指=离场日）。

**v3 结果**（CONFIRM=1, 21 事件=金11/银10, **金/银 100% 交替, 同方向连续=0**）：
| 信号 | 5d | 10d | 20d | 均收益20d |
|---|---|---|---|---|
| 金手指 WEAK(10) | 55% | 50% | 60%[30,90] | +4.11% |
| 银手指 WEAK(7) | 43% | 57% | 43% | +1.20%(仍失效) |

**核心 trade-off（重要）**：金手指 20d 胜率从 v2 的 86% → v3 的 60%。**这不是变差，是语义改变**：
- v2 的 86% 抓「多头涨势里的回调企稳」，吃牛市 beta，不是真择时能力。
- v3 的 60% 抓「大盘状态真正切换的进场点」，是真择时，> 随机基准 59% 有微弱 alpha，但 CI 宽不显著——反映大盘择时的真实难度。
- 结论：大盘金/银手指只做**仓位开关**（语义对、不交替），个股买点交给选股策略（龙回头等）。
- 关键事件验证：2024-09-24 金手指 = 924 大行情启动，抓到了。

### v4 准确率天花板 + 落库预计算
- **顺势+共振过滤无效**：金手指加 `close>MA20 + mom5>0 + mom5>=mom20`，准确率 57%(7样本) 反低于 v3.1 的 60%(10样本)。**结论：大盘择时 60% 接近市场固有天花板**，加过滤只减样本不提质。已回退到 v3.1；`ma20/mom` 字段保留在 factors 供前端展示与未来熊市验证。
- **落库预计算提速**：建 `market_timing_panel` 表(单行 JSONB id=1)，panel service 三层缓存(内存 30min → 库 24h → 现算+落库)，加 `POST /api/market-timing/refresh`。
- **实测速度**：现算+落库 12.5s(仅首次/force) → `GET /panel` 库命中 **25ms** / 内存命中 16ms。**16s → 25ms, ~640×**。
- **后续**：接定时任务(每天 18:00 收盘后自动 refresh)，用户访问永不遇现算；需更长历史数据验证银手指与顺势过滤(待熊市样本)。

### v5 数据驱动过滤：MACD 顶背离过滤（60% → 75%）
**v4 教训**：盲目加顺势+共振过滤无效(57%)。改用**失败样本分析**：剖析 v3.1 的 10 个金手指，发现 4 个失败里有 **3 个 MACD 顶背离 macd_top=80**（成功组均值才 45）。逻辑完全吻合：顶背离=价格新高但动量衰竭，此时发金手指看多=顶背离买入，必败。
**改法**：金手指加 `macd_top < 70` 过滤（factors 提升 macd_top 为正式字段）。
**v5 结果**：金手指 WEAK 20d **75%**[38,100]（8样本），均收益 +6.30%（v3.1 60%/+4.11%）。时间切分：训练 4/6=67%，样本外 2/2=100%。
**关键**：数据驱动 > 盲目加条件。下一步可继续剖析剩余失败（如 breadth_top 也偏高的 2025-05-13）做二次过滤，但样本会进一步减少，需权衡。

### v6 二次过滤：广度顶背离（75% → 86%）
继续失败样本分析 v5 剩余 2 失败，发现 2025-05-13 `breadth_top=68`（广度顶背离：指数涨但站上MA20个股比例回落）。加 `breadth_top<65` 过滤（factors 提升 breadth_top 为正式字段）。
**v6 结果**：金手指 WEAK 20d **86%**[57,100]（7样本），均收益 **+7.20%**；样本外 2/2=100%。
**进度**：60%(v3.1) → 75%(v5 macd_top) → **86%**(v6 +breadth_top)；均收益 +4.11% → +7.20%。
**关键**：macd_top + breadth_top 双顶背离过滤——A 股顶部最可靠的两类信号(动量衰竭 + 指数虚涨)。在顶背离时发金手指看多本就错, 过滤后准确率自然飙升。数据驱动连续两轮有效, 印证「失败样本分析→精准过滤」方法论的威力。银手指仍受牛市数据限制(不变)。
