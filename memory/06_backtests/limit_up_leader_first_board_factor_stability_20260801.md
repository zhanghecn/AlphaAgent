## Evidence Boundary

- eventual_peak / d1_* 是未来标签，仅用于对照分组，绝不作为可交易因子。
- 全日口径温度（market_*_count_d）含未来信息，只用于量化虚高，不进白名单。
- 滞后温度 = D-1 全日首板/封板数（盘前可知），ma5 = 近 5 个交易日均值。
- 白名单裁决为确定性规则：holdout 方向一致 + test |AUC-0.5|>=0.05 + 逐月一致性>=0.7 + 双目标一致（风控门豁免）。
- 阈值稳定性的 spearman 为 test 期分桶成龙率与分位序的秩相关，方向为 lower 的因子期望显著负相关。
