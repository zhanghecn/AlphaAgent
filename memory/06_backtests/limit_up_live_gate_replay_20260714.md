- `rejected` 仅表示结构硬门失败，页面显示“硬性排除”。
- 市场未修复显示“等待市场修复”；动态条件显示“接近买点，还差 N 项”，并展示第一项缺口。

- 午间优先展示当日 11:30 快照并把 lane、portfolio、watchlist 全部降为 `pass`；盘前和收盘后继续显示次交易时段计划。
