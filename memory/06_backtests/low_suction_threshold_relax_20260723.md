# 方向①：放宽转强阈值研究（2026-07-23）— 否决

## 问题

非涨停可成交信号仅 54 个（8-9.8%），喂不饱两仓。能否把"强转强"收益阈值从 8%
下探到 7/6/5%，在保住 alpha 的同时撑大可成交池？

## 设计

保留 close ≥ 95% 前高 + GOLD/NORMAL + gap∈[1,2] 不变，只动 `signal_daily_return_pct`
阈值。同 pipeline execute_prepared_close_trades + 两仓现金模拟。"可成交"= 信号日
收盘涨幅 < 9.8%（尾盘未涨停）。2024-08..2026-07。

## 结论

1. **放宽阈值是陷阱**：可成交池确实越撑越大（54→330），但**新增的每个区段都是负 alpha**
   （PF 全 <1，胜率 33~43%）。整体复利被稀释（+344%→+210%）。
2. **8% 是 alpha 的硬边界**：8-9.8% 非涨停区段是真 alpha（66.7% 胜率，见
   `low_suction_non_limit_reclaim_20260723.md`），但 <8% 的"温和转强"是噪音——
   涨不到 8% 说明多头力度不足，收复前高不可信。现行 8% 阈值已是边界最优。
3. **否决方向①**：不能靠放宽信号质量来换可成交性。

## 对方向②的强化意义

既然真信号（≥8%）里非涨停的只有 54 个喂不饱、又不能往下放宽，唯一出路是在
**≥8% 的真信号**内部解决成交问题——用分钟线在盘中尚未涨停时找到转强成型点买入
（方向②），把 302 个涨停信号的成交死结解开，而不是稀释信号质量。
