## Cross-Symbol Findings

1. **低吸和龙回头确实不能简单相加。**
   - 浙江龙盛、盛新锂能、亨通光电显示：低吸确认后如果没有承接，BUY 仍会变成失败启动。
   - 东山精密、合肥城建显示：低吸启动可以被识别，但组合满仓或理论持有层会导致真实没买。

2. **“有信号但没买”至少分成四类。**
   - 满仓无换仓：东山精密 `2026-04-01`、合肥城建 `2026-05-21`。
   - 排名不进执行前 20：中国西电 `2026-02-25`、红星发展 `2026-03-12`、盛新锂能 `2026-03-09`。
   - 理论持有层不重复计划但真实组合未持有：东山精密 `2026-06-09`、利通电子 `2026-01-19`、合肥城建 `2026-04-29`。
   - 当前信号定义未识别：贵州三力、云南锗业、剑桥科技。

3. **亏损降低更像卖点/回撤和假启动问题，不只是买点问题。**
   - 金洲管道 MFE `+11.82%` 最终 `-4.86%`，是高浮盈回吐。
   - 浙江龙盛、盛新锂能是低吸确认后无承接。
   - 亨通光电是龙回头叠加低吸蓄势未启动且替换更差。

4. **候选链路仍要统一。**
   - 埃斯顿类样本已通过 `candidate-trace.not_planned_context.signal_snapshot` 补出“单股评分 BUY 但组合候选/理论计划不重复写 BUY”的解释；`2026-04-16` 被归为理论持有层已持有但真实组合未持有。
   - 后续 UI 必须继续明确区分：候选信号、理论计划、下单、成交、理论持有、真实持有。
