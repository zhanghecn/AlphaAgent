# 银状态恢复金研究验证

## 结论

- 预注册的 `R1_REPAIR / R2_BULL_CROSS / R3_MA20` 全部未通过决策门槛，不能进入
  前向影子，更不能进入生产。
- 三个版本都只改变了 `2025-10-20..2025-12-22` 这一段银状态。R1 的恢复确认
  后 5 日仅上涨 `+0.18%`；R2/R3 确认后 5 日下跌 `-1.01%`，属于误恢复。
- 缩短银状态没有修复长期方向：银 10 日命中率由 v9 的 `41.9%` 降到
  `31.1%..31.8%`，平均收益由 `+0.82%` 恶化到 `+1.38%..+1.39%`。
- 银状态未来 5 日 `3%` 不利比例由 v9 的 `20.9%` 升到 `30.0%..30.6%`。
  研究版本只是删掉了部分后段银日，没有识别出更通用的反转边界。
- 生产 v9、`signal.py`、panel API 和前端均未修改。`2026-07-15` 最新状态继续
  为银手指，R1 在 `2026-07-09` 的恢复候选也于 `2026-07-10` 被否决。

## 数据与固定规则

- 样本：`2024-05-28..2026-07-15`，518 个交易日，市场上下文覆盖 `518/518`。
- 基础 v9：65 个候选，55 金、10 银；42 个确认、23 个否决、0 个待确认。
- 时间切分：`EARLY < 2025-07-01 <= LATE`。
- 状态日从当日收盘起算未来 `1/3/5/10/20` 日，`executable=false`。
- R1：`close>MA5 + up_ratio>=0.50 + bear_force<65`。
- R2：`close>MA5 + up_ratio>=0.50 + mom_5d>0 + bull_force>=bear_force`。
- R3：`close>MA20 + up_ratio>=0.50 + mom_5d>0 + bull_force>=bear_force`。
- 统一确认：下一交易日上涨、`up_ratio>=0.50` 且多头不低于空头；基础 v9 事件
  优先。没有做阈值网格、日期例外或候选组合。

## 历史起点稳定性

本轮先做了只读起点实验。七大指数价格前缀扩展到 2019 年，但仍从
`2024-05-28` 才允许产生事件时：

- v9 仍为 65 个候选和 42 个确认。
- 所有候选签名和逐日活动方向完全一致，状态差异为 0 天。
- 最新方向仍为银。

如果允许正式样本前的事件参与状态，前 23 个样本日会继承更早金状态并受反转金
冷却影响；2024-09 以后 bull 差异小于 0.1 分、bear 差异为 0，最新状态不变。
这属于事件起点口径，不是未来函数。

本地完整全市场横截面从 `2024-01-15` 开始。公共源虽能返回 2015 年当前股票的
日线，但缺少完整退市股票历史，存在幸存者偏差，本轮没有使用它调恢复规则。

## 因果与限制

- 研究状态按日先应用基础 v9 已确认事件，再处理恢复确认，最后只在银状态使用
  当日及以前数据判断新候选。
- 候选末日为 `PENDING`；下一交易日只改变 status 和活动方向，不回写候选日期。
- 基础银事件优先；恢复区连续停留不重复；未来 bar、factor 和参与度污染不改变
  历史前缀。
- 日级状态高度重叠，真正独立单位只有 5 个基础银区间。逐区间结果已经否定这三种
  恢复结构，不能再把日级样本数解释为几百次交易。
- 本轮结果说明“简单缩短银”会留下风险更集中的早段银日，并不说明银状态长期
  方向问题已经解决。下一步只能等待新独立银区间，或取得无幸存者偏差的更长
  全市场广度；不得继续组合 R1/R2/R3 调历史曲线。
