## Reality Boundary

- 账户按当时已出现的信号时间排序并受两仓现金限制，没有按 D+1 结果挑当天赢家，
  也没有全天事后 Top1。
- 历史账户缺完整逐时点市场修复、板块/个股资金、板块扩散帧和 Tick/L2 排队证据，
  API 明确返回 `live_equivalent=false`；结果是候选代理，不是实盘等价回放。
- 官方收盘退出是计入滑点的收盘集合竞价成交假设。涨跌停、停牌、排队和流动性仍可能
  使真实委托无法按该价格成交。
