## Implemented Factor Changes

- 新增内部超跌反弹子型：`deep_low_absorption_reversal`。
- 核心定义：
  - `return_20d <= -20%` 或 `ma20_distance_pct <= -10%`
  - D 日 `latest_change_pct <= -5%`
  - D 日 `close_location_in_range <= 0.25`
  - D 日量比 `latest_volume_ratio_20d` 在 `0.50..1.80`
  - `near_limit_up_count_20d == 0`
  - 剔除成交/换手极端失控：`latest_turnover_ratio_20d > 2.20` 或 `turnover_percentile_60d > 0.94`
- 融合方式：不新增用户可选策略；在默认策略的 `oversold_rebound_start` lane 内部评分，并通过统一执行池排序。
- 加分方式：`deep_low_absorption_reversal` 只给正向机会分；弱窗口不扣分。已知失败桶 `after_silver_late + retreat + nearest_timing_days <= 25` 不给该机会分，并将执行机会分 cap 到 `82.0`。
- 风险压制：新增 `overheated_crowded_high_turnover_decay`，只压制非超跌 lane 的“高位 + 高换手代理 + 多/拥挤活跃源 + 弱/回落”组合。
