# Strategy Optimization Ledger

这个台账用于每次策略优化后的全局对比。它只记录已落库或已写入证据文件的结果；不能把单股肉眼判断或未完成实验写成当前基线。

## Current Product Baseline

- Public strategy: `mainline_dragon_pullback / 0.1.21`.
- Product path: one candidate observation list plus portfolio trade replay/backtest review.
- Candidate observation display: top `100`, paged `20` per page, sorted by score/rank with no forced low-suction reservation.
- Portfolio execution: BUY candidates top `20`, max positions `10`.
- Historical execution model: `legacy_next_open` (`D` close-visible signal, `D+1` daily open execution).
- Main range used below: `2025-03-26` to `2026-06-18`, main board, `max_symbols=5000`.
- Current product baseline endpoint returns `#203/#194 / 0.1.21`: return `+82.99%`, max drawdown `-15.59%`, buy/sell/open `224 / 214 / 10`.
- 2026-06-19 baseline drift fix: `baseline_only=true` now uses `baseline_policy.select_product_baselines()`. When a longer same-end-date default run such as `#213` exists, the API returns the most common complete product start date (`#203/#194`, `2025-03-26`) and attaches `baseline_warning` instead of silently promoting `#213`.
- Diagnostic run `#204` is excluded from product baseline because it mixed a local `2026-06-12` candidate refresh into a cached full-history backtest; do not use it as the strategy return baseline.
- Stock-detail candidate markers are read-side aggregated: low-suction buildup rows can be shown as cluster evidence, but the K-line marker is only the executable/key launch row; pure buildup without launch is not drawn as BUY.
- Backtest review now treats yearly split, market-regime split, top-10 candidate audit, and dynamic market-context buckets as first-screen evidence. The key overfit check is whether the top-10 candidate result still works after excluding strong-market windows; this is a diagnostic/product visibility change, not a new strategy return claim.
- Low-suction / dragon-pullback boundary diagnostics are read-only. They expose whether a row is `低吸蓄势等待上拉`, `低吸确认后无承接`, `低吸确认且买后承接`, `龙回头偏早缺低吸蓄势`, `龙回头叠加低吸蓄势未启动`, or `标准龙回头`. These fields explain conflicts between low-suction buildup and dragon-pullback, but they do not alter default score, action, sell rule, rank, or portfolio execution.

Conclusion: even a narrow daily-entry-day stop mainly improves optics and slightly trims drawdown, but the freed slots and missed winners hurt return too much. Future work should improve entry risk ranking and replacement quality before adding more daily stop rules.

## Return Drop Attribution For `0.1.15 / #165`

The return drop is primarily an entry ranking / opportunity-cost problem, not a worse drawdown problem.

- `#165` max drawdown improved to `-21.17%` from `#164` `-24.24%`; the worst drawdown date moved from `2025-12-17` to `2025-12-23`, and the drawdown depth was smaller.
