## Root Cause

1. 实时报价的 `quote_observed_at` 是 UTC 时间，分钟缓冲却直接按其小时判断 A 股交易时段，
   例如 UTC `01:56` 被当成非交易时间，而不是上海 `09:56`。
2. 板前质量门把财报缺失、D-1 修复结构缺失、触板基因弱等固定正式阻断错误降级为可等待，
   因而页面出现了触板后仍不可能通过正式门的观察股票。
3. 模型输入不合格且双概率为空时仍被统一发布为“观察”。
4. 特征投影已构造交易日和决策时间，但返回时丢失两字段，生产落库持续报
   `decision_at is required`，历史特征表没有写入有效行。
