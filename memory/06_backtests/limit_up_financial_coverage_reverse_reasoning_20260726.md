# AlphaAgent 财报覆盖反向推理与动态资金角色边界

## Current state

- 财报补齐后胜率下降，不是因为正确财务质量因子变成负因子，而是旧财报同步造成的
  非随机缺失被消除，正式候选样本从原来偏向高成交额、大市值股票的子集扩展到全市场。
- 在其他首板结构门一致的同候选消融中，正确归母净利润同比 `>=10%` 仍明显优于
  `<10%`；不能恢复“本地没有财报就拒绝”的旧错误硬门。
- 旧覆盖很可能混合代理了资金承载、市场关注度、行业前排和公司规模，但旧覆盖使用回放
  时的当前成交额/市值，不是历史 D-1 值。该代理只能解释旧结果，不能作为合法新因子。
- 动态概念波段中的趋势龙、容量龙和扩散角色是对上述经济含义的点时重建方向；目前缺少
  可持久复核的旧逐笔覆盖身份，不能报告“旧覆盖 x 动态角色”的逐笔交叉胜率。

## Same-candidate financial ablation

以下 1,231 个候选保持其他首板结构门一致，只消融财报层并使用 D+1 正式净收益：

| 分组 | 样本 | 胜率 | 平均净收益 |
|---|---:|---:|---:|
| 不使用利润增长门 | 1,231 | 46.55% | -0.1480% |
| 正确归母同比 `>=10%` | 556 | 50.90% | +0.2576% |
| 正确归母同比 `<10%` | 675 | 42.96% | -0.4821% |
| 修复前已有覆盖，不看增长值 | 657 | 52.66% | +0.3746% |
| 本次新补覆盖，不看增长值 | 574 | 39.55% | -0.7461% |
| 旧覆盖且正确同比 `>=10%` | 359 | 57.38% | +0.8485% |
| 新补覆盖且正确同比 `>=10%` | 197 | 39.09% | -0.8192% |
| 旧覆盖且旧错误环比代理 `>=10%` | 367 | 56.68% | +0.7122% |

正确同比通过组相对未通过组提高 `7.94` 个胜率百分点，平均收益提高约 `0.7397` 个百分点；
在旧覆盖内部，正确同比也优于旧错误环比代理。因此字段纠正不是胜率下降的根因，样本覆盖
扩张才是主因。

时间拆分同样支持覆盖偏差解释：

| 正确同比通过后的覆盖组 | expanding OOS | locked holdout |
|---|---:|---:|
| 修复前已有覆盖 | 59.40% / +1.2981% | 56.19% / +0.5840% |
| 本次新补覆盖 | 41.54% / -0.5680% | 34.33% / -1.3067% |

差异跨阶段存在，不是单一近期行情造成。

## Why missing reports looked profitable

旧同步每天先按当时数据库中的**当前** `stocks.turnover`、`stocks.market_cap` 倒序，只取
100 只股票；已有 4 期报告后又停止更新。随后正式质量门把本地财报缺失当拒绝条件。
于是“有本地财报”实际变成以下混合选择器：

1. 更高的当前成交额和更大的当前市值，更容易被同步覆盖；
2. 长期处于关注度和资金承载前排的股票，更容易持续留在覆盖池；
3. 财报本身再叠加正确或错误的利润质量条件；
4. 两仓容量和到达顺序进一步删掉部分后排信号。

正确同比通过后，旧覆盖组的当前成交额中位数约为新覆盖组 `8.85` 倍，当前市值中位数约
为 `3.95` 倍。由于这些是回放时的当前快照，它们带有未来信息和幸存者偏差，只能用于
根因解释。

## Point-in-time counterfactual

用合法 D-1 历史成交额尝试重建旧覆盖经济含义，在 locked holdout 没有复现：

| D-1 流动性门 | locked holdout 胜率 | 平均净收益 |
|---|---:|---:|
| D-1 成交额 `>=8亿` | 50.00% | -0.5275% |
| D-1 成交额 `>=10亿` | 49.35% | -0.5528% |
| 20 日中位成交额 `>=10亿` | 48.19% | -0.6774% |

较宽的 D-1 成交额 `>=2亿` 只把 806 日全量正式胜率从 `54.8117%` 提高到
`55.4502%`；locked holdout 从 `51.9553%` 变为 `51.9231%`，没有增量。单个静态
流动性阈值不能合法恢复旧全量 `62%`，更不能恢复两仓约 `70%`。

## Relation to dynamic concept leaders

旧覆盖偏差与用户观察到的科技趋势/容量龙有合理经济联系，但当前证据只支持以下假设：

- 容量龙更可能拥有高 D-1 成交额、持续成交额扩张和较强相对趋势；
- 引导龙形成后，同概念指数、成交额和响应成员共同增强，可能区分资金扩散与单股集中；
- 旧覆盖恰好偏向这些股票，因此在部分历史风格中表现较高；当风格切换后，静态成交额门
  立即失效。

上述联系不能写成已验证交叉结论。旧报告只保留聚合分组，未保存每条候选的旧覆盖身份与
动态波段席位；而当前 `stocks.turnover/market_cap` 又不能回填历史。后续只能用合法 D-1
数据显式构造“市场风险容量 + 概念成交额持续/加速 + 成员扩散/集中 + 动态领导角色”，
不能继续使用“本地财报有无”。

动态波段 v3 的正式候选交叉进一步缩小了原因范围：同波段成交额强度前 20% 加低位跟随
为 `33/43=76.7442%`，3-5 月 `72.2222%`、6-7 月 `80.0000%`；但同窗静态成交额
参考为 `33/42=78.5714%`，动态龙头没有证明额外增益。结合静态参考在发现前历史只有
`55.1724%`，最合理的解释仍是旧财报覆盖、容量关注度和特定风格阶段共同形成选择偏差，
而不是存在一个可恢复的固定成交额门或“见龙就打”规则。

## Validation boundary

- 3-7 月和既有 806 日已经用于假设生成与历史否决，不再作为未见晋级集。
- 任何动态波段资金因子必须先冻结规则和哈希，再进入 `2026-07-27` 起的自然前向。
- 最低晋级口径继续使用全部正式推荐：至少 30 笔闭合、覆盖至少 3 个月、全量胜率
  `>=60%`，并报告均值、复利、回撤、硬亏和情绪阶段覆盖；两仓结果不参与因子晋级。
- 本报告的根因结论已被 `limit-up-core-ab-v1` 接收；自然前向达标前不得恢复旧财报缺失门、
  放宽 A+B 或使用动态概念 C 级扩容。
