# 弱转强前置特征反向归纳研究（2026-07-23）

## 问题

正向试错（回踩日入场）被全量回测否决后，反向归纳：那些 1-2 个交易日后出现
强转强（≥8% 且收盘接近前高）的支撑触碰，**触碰日当天**有什么可识别特征？
若有稳定分离特征，可做"预筛选回踩日入场 v2"；若无，封死该方向。

## 设计（预登记，不做事后增补）

- 母集合：动态 Top3 龙头 MA5/MA10 首次回踩（漏斗 parent 定义）+ GOLD/NORMAL +
  非退潮相位 → **6309 次触碰**，其中 **55 次（0.87%）**后续出现官方强度转强。
- 标签为**市场事实**（非策略门结果）：1-2 个交易日内 ≥8% 且收盘 ≥95% 可见前高。
- 预登记 11 个触碰日因果特征：daily_return_pct、close_location、close_holds_support、
  undercut_depth_pct、volume_ratio_prior5、turnover_expansion、peak_distance_pct、
  leg_gain_pct、sessions_since_ignition、wave_number、dynamic_rank。
- 指标：rank AUC（全段/开发段/验证段）+ 5 时间块稳定性（≥0.55 计稳定）+
  中位数对比。采纳门槛：|AUC-0.5|≥0.05 且开发/验证同向且 ≥4/5 块稳定。
- 复现：研究 `support_touch_reclaim_feature_study.py`
  （版本 `support-touch-reclaim-feature-v1`，测试 13 个）。

## 结论

1. **没有任何触碰日特征能稳定预判转强**：最佳 sessions_since_ignition（启动日久）
   AUC 仅 0.60 且 3/5 块；全部 11 个特征无一过采纳门槛。方向上"启动日久、
   波段涨幅大、缩量回踩"弱正向，与直觉一致但强度不足以做预筛选器。
2. 官方转强是 **0.87% 的尾部事件**（55/6309），日线粒度的触碰日特征
   无法预测尾部——**确认事件本身就是信号，前置预判不可行**。这从另一侧
   解释了现行策略为什么必须等转强日。
3. 关联发现：6309 次首次回踩中只有 55 次长成官方转强，而官方信号有 204 个——
   说明**官方信号的支撑测试日大多不是"首次回踩日"**（多为二次/更深触碰），
   漏斗 parent 定义比策略实际测试定义窄；变体回测（2484 交易）覆盖的是
   首次回踩宇宙，结论（裸买回踩=亏损）在该宇宙成立，外推到全部触碰需谨慎。
4. **"预筛选回踩日入场 v2"正式封死**：无可靠预筛选器 + 裸回踩入场本身
   PF 0.75（见 `low_suction_support_day_entry_variant_20260722.md`），
   两条路都不通。低吸方向剩余唯一活路：转强日入场 + 前向账本测量真实成交。
