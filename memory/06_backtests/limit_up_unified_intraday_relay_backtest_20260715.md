# 打板统一盘中接力组合正式回测

## 结论

- 一进二已从活跃板位、候选生成、实时推荐、回测范围、缓存预热、API 和前端合同中移除，
  不受收益结果影响，也不再保留当前内部负样本入口。
- 二进三与首板合入同一个综合推荐、同一个两仓现金账户和同一个买入时钟；高板未通过
  收益/回撤门，只保留独立研究。
- 正式产品组合为 `first_board + two_to_three`：307 个候选信号、149 笔闭合交易，胜率
  `63.0872%`，复利 `+266.4491%`，最大回撤 `-8.0275%`，利润因子 `2.4961`。
- 同口径首板基线为 `+224.0076% / -7.9408%`。加入二进三后复利提高
  `42.4415` 个百分点，回撤增加 `0.0867` 个百分点；时间验证和双倍成本门均通过。
- 结果仍是历史候选成交代理，不是实盘等价收益。冻结后前向段当前为 0 笔，产品继续标记
  `research_only / simulation_eligible=false`。

## 冻结规则

- 数据截止：`2026-07-15`；`limit-up-history-v15` 覆盖
  `2024-01-15..2026-07-15` 共 603 个交易日。
- 买入窗口统一为 `10:00-11:30 / 13:00-14:30`，竞价只形成观察资格，不产生买单。
- 二进三、高板只有在窗口内首次触板，或 10 点前触板后在窗口内首次可观察回封时，
  才形成候选；缺事件、缺可证明回封或窗口外触板一律跳过。
- 所有候选按真实触发时间处理；同一时刻接力优先于首板，不同时间严格先到先买。
  不为稍后接力预留仓位，仓满不换仓。
- 账户初始资金 100,000 元，最多两仓，每仓目标 50%，D+1 14:30 退出；跌停锁死时按
  现金账户保守规则延后到下一可成交时点。
- 历史入场价使用涨停价代理，不允许回退到 09:30 开盘价、日线收盘价或最终封板状态。

## 价格与数据边界

- 产品 307 个退出价格请求中，98 个使用精确 14:30 分钟价，209 个使用
  `daily_close_proxy`，缺价为 0。该计数覆盖所有候选请求，不等于 149 笔实际成交。

- 冻结后真实前向交易仍为 0，不能用设计段或时间验证段替代上线后前向验收。
