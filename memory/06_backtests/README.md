# Backtest Evidence Index

这个目录保存回测报告、缺口清单、参数网格和验证证据。目录中的日期文件是证据，不是长期状态；判断当前状态时先读本文件，再按链接打开具体报告。

每次策略优化的统一对比台账见 `strategy_optimization_ledger.md`。新增版本或实验后必须同步记录版本、回测编号、收益、回撤、交易数、结论、未来函数/过拟合风险和证据文件。

## Reading Rules

- 先看回测的 `strategy_version` 和执行模型。当前默认历史研究口径是 `legacy_next_open`；当前公开策略代码是 `mainline_dragon_pullback / 0.1.21`，当前产品基线证据是 `#203/#194`，`#190` 保留为年度/市场/Top10/路径/四因子审计证据。性能参考仍需同时看 `#137 / 0.1.3`、`#157 / 0.1.9`、`#164 / 0.1.14`、`#169/#172 / 0.1.18` 和失败边界 `#165/#167/#168/#173/#174`。
- 普通 `/quant` 和股票详情页通过 `GET /api/backtests?...&baseline_only=true` 读取产品基线回测；该参数会保留当前公开策略版本里结束到最新本地交易日、起点最早、参数为产品默认且未标记 `exclude_from_product_baseline` 的组合回测，所以短区间实验、同区间研究参数实验 `#195/#196/#197/#198/#199/#200/#201/#207/#208` 和诊断回测 `#204/#206` 不会顶掉默认展示的 `#203/#194`。
- `/quant` 回测首屏必须直接展示年度分段、市场环境分段和前10候选审计，不能只藏在“验证”页。前10候选审计要同时看强势、弱势、震荡桶和“排除强势行情”汇总。当前保留两种口径：真实组合成交并闭仓的候选胜率，以及固定 20 个交易日的候选观察胜率。后者按 `D+1` 开盘观察买入、持有到第 20 个交易日收盘，只用于候选质量事后审计，不参与策略交易。
- 普通产品路径只看公开策略 `mainline_dragon_pullback`；旧策略只作为内部兼容/对比材料。
- 历史主流程看 `legacy_next_open` 的买入/卖出路径、收益率、最大回撤、候选排名、持仓上限、现金/仓位拒单和涨跌停约束。

- 单股低吸排查优先用 `GET /api/quant/symbols/{vt_symbol}/signal-history` 看逐日评分，再用 `GET /api/backtests/{id}/candidate-trace?vt_symbol=&signal_date=` 看组合排名、持仓和没买原因；二者分别回答“有没有形态信号”和“组合为什么没买”。
- 当前目标历史日期缺少同版本 `quant_recommendations` 落库候选，不能仅凭候选页历史记录判断策略是否识别低吸；单股逐日评分和组合 candidate-trace 仍是主验证口径。

- 单股有 BUY 信号不等于组合会买入，还要看排名、资金、持仓上限、执行日开盘价、涨跌停和订单拒单原因。

## Open Risks

- 当前策略仍需按日线 D+1 新主流程重做多年全 A、walk-forward、参数敏感性、市场分层、基准超额和高摩擦验证。
- 本轮发现历史候选缓存完整性问题：`quant_signal_runs` 覆盖可早于 `quant_stock_signals` 完整覆盖，2025-08 至 2025-09 上旬存在每天仅 `1..45` 条的稀疏候选缓存。当前回测已按日期混合复用缓存：完整日期保留，缺失或稀疏日期移出 `score_cache` 并现场重算，避免收益失真；后续应补齐或重建早期完整候选缓存，再跑 `2025-03-26..2026-06-18` 的实验全区间对比。
- `#195/#196/#197/#198/#199/#200/#201/#207/#208/#211` 已证明几个直觉方向不能粗暴默认化：低吸启动确认和低吸启动质量适合做排序/解释，不适合硬门槛；纯低吸蓄势应作为展示簇证据，不应硬过滤组合执行池；中段浮盈回撤止盈适合继续做更窄的上下文卖点，不适合作为单纯高点回撤阈值；重复龙回头风险适合作为诊断/排序上下文，不适合硬拒；启动质量宽泛加分和启动风险窄处罚都会显著牺牲趋势大肉；三日失败启动早退会改变组合路径并错过趋势大赢家；替换质量保护版失败启动早退虽然保住趋势赢家且小幅降回撤，但触发太少且收益未提升，仍不能默认开启。

- 当前公开代码 `0.1.21` 的最新全历史 `#194` 收益约 `+82.99%`、最大回撤约 `-15.59%`；此前同规则 `#190/#189/#177/#175` 覆盖至 `2026-06-17`，收益约 `+81.32%` 到 `+81.36%`。它较 `#172/#169` 同策略上一版明显改善，但仍不能宣称最终策略优化完成；多年全 A、walk-forward、参数敏感性、市场分层和高摩擦压力测试仍是必要验证。`#194` 三维路径审计显示：`support_stop` 125 笔合计约 `-886,040`，但同时有 `81` 笔卖后反弹、`48` 笔浮盈回吐、`58` 笔买后无承接和 `87` 笔启动后立即失败。新增 `support_stop_context_audit` 进一步拆分：真失败启动止损 `49` 笔、止损后反弹 `41` 笔、有承接但后续破支撑 `14` 笔、干净浮盈回吐后破位 `13` 笔、高浮盈后止损又反弹 `7` 笔。下一步不能只改单一买点或单一止损。
