## Candidate Quality Logic

- 当前候选质量主逻辑是每日候选独立买卖：每条 D 日 BUY 候选，D+1 开盘独立买入，随后按当前卖点卖出，统计收益、胜率、平均回撤和最差回撤。
- 候选质量报告不读取组合成交约束；真实组合成交只是交易层事实，不能用来解释“这个候选本身好不好”。
- 候选 Top20 质量现在按执行候选口径统计：`rank_limit <= candidate_limit` 时使用 `candidate_execution.execution_candidate_selected` 和 `execution_candidate_rank`；Top50/Top100 研究视图仍使用原始 rank，以便分析未入选候选池。
- 当前默认候选执行池先正常选出 Top20，再删除 `stale_active_weak_decay_pullback`、`old_low_suction_strong_leg_normal_volume`、`large_bull_no_limit_ma20_stretch`、`old_ma10_support_no_limit_normal_volume_decay`、`old_ma10_support_ma5_stretch_decay`、`strong_leg_long_pullback_ma10_far_decay`、`core_active_strong_leg_shrink_ma10_upper_decay`、`wide_ma10_high_turnover_normal_volume_decay`、`wide_ma_no_low_suction_high_close_volume_decay`、`overheated_ma5_reclaim_ma10_far_decay`、`crowded_large_bull_no_limit_high_close_decay` 和 `core_active_short_pullback_strong_leg_lift_decay` 弱买点且不回填；这属于候选买点质量门槛，不是仓位或组合容量解释。`core_active_ma10_flat_mid_high_turnover_decay` 已从默认过滤中删除。
- 当前默认卖点包含 `guarded_highclose_giveback_stop`，用于处理高位高收盘候选的可见冲高回落；它只读取持仓后已经发生的 MFE/回撤路径和 D 日候选证据，不使用未来函数。
- `0.1.24` 已把候选层质量调整并入默认评分排序，不提供用户手动开关：保护成熟低吸首启和近端活跃右尾来源，降权 MA5 过远、放量滞涨、低吸蓄势无首启、多次大阳但无涨停且收盘拥挤、弱行情无 5 日线转强、MA20 未收回；并加入买点位置修正，轻加分“近端活跃 + 可交易 MA5 距离 + 低/中位可控收盘”和“缩量启动收盘可控”，更强降权“无涨停来源高位启动、成熟低吸无涨停高位确认不足、活跃后低吸陈旧无首启、后段高位启动、活跃后段高位确认、活跃高收盘偏离 MA5”。

## Open Risks

- 当前基线仍不能证明熊市、震荡市和非科技主线下稳定有效。
- 历史资金流和主线板块覆盖不足，不能宣称已经稳定量化科技主线或新主线轮动。
- 当前最重要的问题不是再加宽泛因子，而是候选自身买点质量、卖点质量和趋势赢家路径保护。
- 最新本地行情上下文截至 `2026-06-18` 为 `假强势`：指数 5 日/20 日收益为正，但广度弱、资金恐慌流出、风险等级 `4`。真实交易前必须先更新本地日线和板块资金；在该上下文下不应扩大未确认低吸买入频率。
- 回测实验基线已收紧：默认组合回测不复用候选缓存；显式缓存回测必须绑定当前 `signal_evidence_schema_version` 且不能进入产品基线。
- 策略更新流程已有 acceptance 测试通道，但全市场完整通道仍是慢测；日常快速通道只能证明链路和小样本没有明显崩坏，不能作为策略变更证据。当前完整候选质量 gate 要求 Top20 平均收益、胜率、平均回撤和最差回撤均不弱于产品基线。
- `0.1.24` 目前已有 `2026-01-01..2026-06-18` quick 500 候选/组合验证和 `2024-05-28..2026-06-26` 完整日期窗口 500 股票池组合验证；更大股票池/全市场、弱市和复权数据验证仍需补跑，不能据此宣称稳定 alpha。
