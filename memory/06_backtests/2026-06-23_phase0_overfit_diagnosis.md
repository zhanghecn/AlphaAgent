# 阶段 0 过拟合诊断（mainline_dragon_pullback / 0.1.21）

## 背景
主人想结合游资情绪流派提收益、降过拟合。阶段 0 先量出 0.1.21 的过拟合/有效性现状。
CPCV 因单次回测 11 分钟（逐日全市场评分 5000 股）跑全量要 13 小时不现实，改用**轻量诊断**：
基准 alpha + 参数敏感性。CPCV/PBO/DSR 框架（`overfit_validation.py` + 17 单测）已实现保留，供未来回测加速后或最终候选使用。

## 诊断 1：基准 alpha（2025-03-26 ~ 2026-06-23，no cache）
- 0.1.21：+60.6%, sharpe 1.76, max_dd -23.0%, win_rate 30.8%, 195 笔
- vs 上证 +21.9% → alpha **+38.7%**
- vs 沪深300 +25.5% → alpha **+35.1%**
- vs 中证500 +46.1% → alpha **+14.5%**
- vs 创业板 +95.9% → alpha **−35.3%（跑输！）**

**结论**：0.1.21 收益主要来自 2025-2026 科技/创业板牛市 beta。最相关基准（中小盘/创业板）下 alpha 不足甚至跑输——同期买创业板 ETF 不动比 0.1.21 多赚 35%。

## 诊断 2：参数敏感性（6 变体，no cache，2026-06-23）
| 变体 | ret% | sharpe | max_dd | win_rate | trades |
|---|---|---|---|---|---|
| base 默认 | 60.62 | 1.763 | -22.99 | 0.308 | 195 |
| min_score 64 | 60.62 | 1.763 | -22.99 | 0.308 | 195 |
| min_score 72 | 60.62 | 1.763 | -22.99 | 0.308 | 195 |
| stop_loss 0.05 | 50.95 | 1.475 | -21.20 | 0.288 | 215 |
| stop_loss 0.09 | 70.93 | 1.956 | -22.41 | 0.312 | 192 |
| take_profit 0.22 | 60.62 | 1.763 | -22.99 | 0.308 | 195 |

**关键发现**：
- `min_entry_score`（64/68/72）**完全无变化** → 死参数（候选评分都 > 72，门槛没卡住任何候选）
- `take_profit`（0.18/0.22）**完全无变化** → 死参数（被 support_stop 等覆盖，极少触发）
- `stop_loss`（0.05/0.07/0.09）有影响：50.95% / 60.62% / 70.93%（中等敏感，极差 20%）

**结论**：不算严重参数过拟合（参数不剧变），但暴露 **min_entry_score / take_profit 是死参数**（隐患）——0.1.21 实际只靠少数活跃参数（stop_loss 等）。

## 综合判断
0.1.21 的问题**不是参数过拟合**，而是：
1. **alpha 不足**（牛市跑输创业板 ETF 35%）
2. **死参数隐患**（min_entry_score/take_profit 调了无效，参数空间比看上去窄）

所以"降过拟合"不是核心矛盾，**"提 alpha"才是**——游资情绪因子方向正确（目的是提 alpha 跑赢指数）。
