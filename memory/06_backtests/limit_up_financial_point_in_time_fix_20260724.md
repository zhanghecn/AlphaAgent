- 财报写入后清空实时质量上下文，避免 15:05 初步计划复用旧的“财报缺失”缓存。

## Root Cause

1. 原季度任务每天只处理 100 只，大量主板股票长期没有本地报告。
2. 已有 4 期报告的股票不再更新新季度。
3. 逐股接口的 `NETPROFIT_QOQ` 被误写成同比，且净利润使用含少数股东损益口径。
4. 第一版批量修复只映射核心业绩，未读取同一响应已有的扣非利润和每股经营现金流；旧现金
   流比率还可能保留以含少数股东净利润为分母的值。
5. 15:05 和 19:00 计划运行于同一工作进程，财报更新后没有失效日内质量缓存。

## Financial Factor Attribution

为区分“财报因子失效”和“旧覆盖样本偏差”，在其他首板结构门一致的候选中，
对 D+1 收盘净收益做财报边际消融。该表不叠加后续的同股历史盈利门，用于只看财报层的
边际贡献：

| 分组 | 样本 | 胜率 | 平均净收益 |
|---|---:|---:|---:|
| 不用利润增长门 | 1,231 | 46.55% | -0.1480% |
| 正确归母同比 `>=10%` | 556 | 50.90% | +0.2576% |
| 正确归母同比 `<10%` | 675 | 42.96% | -0.4821% |
| 修复前已覆盖，不看增长值 | 657 | 52.66% | +0.3746% |
| 本次新补覆盖，不看增长值 | 574 | 39.55% | -0.7461% |
| 修复前已覆盖 + 正确同比 `>=10%` | 359 | 57.38% | +0.8485% |
| 本次新覆盖 + 正确同比 `>=10%` | 197 | 39.09% | -0.8192% |
| 修复前覆盖 + 旧错误环比代理 `>=10%` | 367 | 56.68% | +0.7122% |

这证明归母同比因子在全体样本上有正边际贡献，而且在旧覆盖子集上比误用的季度环比
更好。因此回测下降的主因不是字段纠正，而是全量补齐消除了旧的隐性样本筛选。

旧同步每次按当前 `stocks.turnover` 和 `stocks.market_cap` 倒序只取 100 只，且已有 4 期的
股票不再更新。财报“有/无”因此实际上变成了一个由当前成交额和市值决定的隐性筛选，
不是随机缺失。在正确同比通过的候选中，旧覆盖组的当前成交额中位数是新覆盖组的
约 8.85 倍，市值中位数约 3.95 倍。这个选股条件又使用了回放时的当前快照，不是
历史 D-1 点时值，所以不能作为可信回测因子保留。

分阶段后结论不变：正确同比通过的旧覆盖/新覆盖组在 `expanding_oos` 分别是
59.40% / +1.2981% 与 41.54% / -0.5680%；在 `locked_holdout` 分别是
56.19% / +0.5840% 与 34.33% / -1.3067%。差异不是由单一近期行情造成。

正确的后续方向是保留财报风险/利润证据，但只能用历史 D-1 可见的成交额、流通市值和
活跃度显式重建旧覆盖子集的经济含义，不能继续用“本地财报是否缺失”充当流动性因子。

## Parity Boundary

历史和实时已经共用主板范围、半年结构、财报点时、首板利润门和历史盈利基因。正式报告仍
标记 `candidate_proxy_only / live_equivalent=false`，因为历史账本缺少同信号时点的市场修复
帧、板块/个股资金、板块扩散和 Tick/L2 排队证据。板前概率模型仍是 `research_only`，不替换
正式触板/回封扫板链。因此可以说静态质量门同源，不能说历史回测已经证明实盘可成交等价。
