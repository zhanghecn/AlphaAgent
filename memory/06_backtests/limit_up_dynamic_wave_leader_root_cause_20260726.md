# AlphaAgent 动态科技龙头漏判与财报覆盖根因

## Current state

- 审计区间：`2026-03-01..2026-07-24`。
- 用户所称“金安国际”按科技/PCB 语境和本地证券表核实为金安国纪
  `002636.SZSE`；山金国际属于黄金股，不纳入本组科技案例。
- 金安国纪、亨通光电、东山精密、德明利、深科技并非完全没有进入旧账本。它们曾被标成
  确认龙、容量核心、龙二龙三或补涨，但没有稳定进入月度主要龙头序列。
- 根因不是单一阈值，而是旧合同把“周期龙头”近似成“一进二确认龙 + 单日涨停排序”，
  无法表达涨停点火后继续用趋势、成交额和板块共振维持领导力的科技容量龙。
- v3 全成员回放已经让五只代表股全部进入动态前三，证明上述漏判原因成立；但亨通光电
  同时落入 `64` 个波段、东山精密落入 `30` 个波段，说明多概念重叠和主传播概念选择仍是
  未解决噪声。当前修复的是“能否识别趋势/容量龙”，不是“唯一主概念已经判准”。

## Algorithm root cause

1. **研究股票宇宙受涨停事件限制。**
   `load_capital_mainline_inputs` 的 `stock_bars` 只加载研究窗内至少出现过一次涨停事件的
   `event_symbols`。这五只股票因为都曾涨停而没有完全缺数据，但从未涨停的趋势中军会被
   系统性排除，实时全成员算法不能沿用该宇宙。
2. **确认龙定义过窄。**
   `build_leader_confirmation_events` 只接受点火日一板、下一交易日二板的股票。科技趋势龙
   即使首板后连续上涨、放量并带动板块，只要没有第二板就不能成为确认龙。
3. **概念周期会粘连多轮行情。**
   旧 PCB 周期 `BK0877:2026-04-07:2` 从 4 月 7 日延续到 7 月 2 日。状态机只在主线横截面
   分位连续两日低于 `0.55` 时结束，反流又复用原 `concept_cycle_id`，导致 4、5、6 月
   的多次科技波段被当成一个周期。
4. **龙二龙三不是周期席位。**
   `rank_cycle_roles` 每日按“连板高度优先、当日成交额次之”排序；`role_order=2/3` 只表示
   当天某概念涨停事件的第 2/3 名。它没有累计点火领先、波段相对收益、成交额承载、板块
   响应或角色任期，因此不能回答某段情绪周期的动态龙一/龙二/龙三。
5. **多概念主归因会遮蔽真实带动方向。**
   同一股票只按确认时指数/成交额/梯队证据选一个主概念；亨通光电可能落在海工装备，
   东山精密可能落在小米/华为，而用户关注的 CPO、光通信、PCB、半导体传播成为次概念。
6. **报告只展示曾进每日 Top3 的概念周期。**
   股票即使存在于全量账本，如果所属子题材未进当日主线 Top3，也不会进入月度主要序列。

## Financial reverse reasoning

- 原错误财报基线为 194 笔、`61.86%`；只修同比和覆盖后为 234 笔、`57.27%`；最终修复
  扣非/现金流后为 231 笔、`56.71%`。下降首先来自样本扩张，不是正确财务值变差。
- 在其他首板结构门一致的 1,231 个候选中，不用利润门为 `46.55%`；正确归母同比
  `>=10%` 为 556 笔、`50.90%`，低于 10% 为 675 笔、`42.96%`。正确财报因子有正边际。
- 正确同比通过后，修复前已有覆盖组为 359 笔、`57.38%`，本次新补覆盖组为 197 笔、
  `39.09%`。旧同步每天按**当前** `stocks.turnover/market_cap` 倒序只取 100 只，已有
  4 期又停止更新，所以“本地有财报”实际是高成交额、大市值的非随机隐性筛选。
- 旧覆盖组当前成交额中位数约为新覆盖组 `8.85` 倍、市值约 `3.95` 倍，但这些是回放时
  当前快照，不是历史 D-1 数据，不能恢复为合法因子。
- 使用合法 D-1 成交额阈值无法复现：锁定留出中 `>=8亿`、`>=10亿`、20 日中位
  `>=10亿` 的全量胜率分别只有 `50.00%`、`49.35%`、`48.19%`。旧高胜率不是一个静态
  流动性阈值，而是财报非随机覆盖、旧市场风格、正式质量门和两仓到达顺序共同形成的
  选择偏差。

## Research consequence

- 下一算法必须把“连板龙、趋势龙、容量龙”作为并列角色分量，再在每个可重启资金波段
  中动态计算龙一/龙二/龙三。
- 月度总榜不能再按跨概念占席日简单累计后直接充当情绪主龙序列。实时层需要在每个波段
  内保留动态席位，同时按点火时序、指数/成交额确认和响应成员覆盖选择主传播概念；宽概念
  的重复席位只能作证据，不能重复计票。
- 资金承载应使用历史 D-1 成交额、滚动相对强度和同概念扩散，不能使用本地财报是否存在
  或当前市值快照。
- 3-7 月与既有 806 日已经被查看，只能生成假设；任何新规则必须冻结后使用 2026-07-27
  起的自然前向验证。
