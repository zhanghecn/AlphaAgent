# 打板概念绝对共振验证

## 结论

- `limit-up-live-v5` 已用概念内部绝对广度替换全市场前 3%/5% 状态门。
- 全市场 `strength_score / strength_rank / strength_percentile` 继续保留，只用于同状态概念排序和候选选优。
- 页面、API 字段、两仓、交易窗口、退出纪律和 `research_only` 边界均未变化。
- 历史引擎不导入或调用 `concept_state()`，且历史账本没有真实盘中概念帧；因此本次公式不能产生历史收益增量。
- 2026-07-15 是公式设计和功能重放样本，不是样本外收益验证。真实收益影响仍需冻结后的 20/60 个交易日前向证据。

## 状态公式

`launch` 要求覆盖率至少 90%、上涨占比至少 80%、中位涨幅至少 2.5%、涨超 5% 数量至少
`max(3, ceil(有效成员数 * 5%))`，并且至少一只距板 1% 内或至少两只涨超 7%。

`warming` 要求覆盖率至少 90%、上涨占比至少 65%、中位涨幅至少 1%、至少两只涨超 5%，
且 3 分钟中位涨幅加速度为正。现有退潮规则仍先于启动判定。
