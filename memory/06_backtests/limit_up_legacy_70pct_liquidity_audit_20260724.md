# 打板旧 70% 胜率来源与 D-1 流动性审计（2026-07-24）

## Current State

- 旧 `70.1031%` 来自 800 日正式两仓账户的 `68/97` 笔成交，不是 168 个推荐的
  胜率；同批全量独立推荐为 `102/164 = 62.1951%`。
- 后续 170 信号账本的两仓账户为 `69/99 = 69.6970%`，全量独立推荐为
  `103/166 = 62.0482%`。因此项目中所称“约 70%”一直是两仓成交子集口径。
- 财报点时修复并推进到 2026-07-24 后，806 日当前账本为：
  - 全量独立推荐：239 笔闭合、131 胜，胜率 `54.8117%`，平均 `+0.5687%`，
    独立槽位复利 `+101.5433%`，最大回撤 `-30.6303%`。
  - 两仓账户：127 笔闭合、74 胜，胜率 `58.2677%`，复利 `+54.7953%`，
    最大回撤 `-20.6187%`。
- 旧约 70% 不能继续作为当前全量推荐或当前两仓账户的质量承诺。

## Why The Old Account Reached 70%

1. 两仓容量改变了样本。旧时间验证段两仓成交票胜率为 `67.4419%`，仓满跳过票只有
   `47.0588%`；2026 年 7 月旧样本分别为 `77.7778%` 和 `17.8571%`。到达顺序和
   T+1 资金占用无意中挡住了大量后排弱票。
2. 旧财报同步每次按当前 `stocks.turnover/market_cap` 倒序只覆盖 100 只，财报缺失又是
   硬门。“有本地财报”实际混入当前高成交额、大市值筛选，并含历史回放偏差。
3. 旧覆盖组并非因为错误季度环比字段更有效。正确归母同比 `>=10%` 在旧覆盖组为
   `57.38% / +0.8485%`，仍优于旧错误代理的 `56.68% / +0.7122%`。回测下降主要来自
   全量补齐后移除了隐性样本筛选，不是正确财报因子本身失效。
4. 近期样本发生明显衰减。当前 expanding OOS 全量为 60 笔、`63.3333% / +1.8430%`，
   locked holdout 为 179 笔、`51.9553% / +0.1416%`。旧全期平均掩盖了后段漂移。

## D-1 Liquidity Audit

审计只使用信号日之前可见的数据：D-1 官方日线成交额、截至 D-1 的 20 日成交额中位数，
以及 D-1 主板横截面成交额分位。不使用当前 `stocks.market_cap`，也不把本地财报是否缺失
当作因子。流动性只作用于首板，二进三保持不变；费用、双窗口、同股盈利门、两仓和 D+1
官方收盘退出均沿用正式合同。

开发段看起来越高流动性越好，但锁定留出没有保持单调性：

| 开发段筛选 | 开发全量 | 锁定留出全量 | 锁定留出均值 |
|---|---:|---:|---:|
| 无流动性门 | 60 / 63.33% | 183 / 50.82% | +0.0148% |
| D-1 成交额 `>=8亿` | 37 / 70.27% | 88 / 50.00% | -0.5275% |
| D-1 成交额 `>=10亿` | 33 / 69.70% | 77 / 49.35% | -0.5528% |
| 20 日中位成交额 `>=10亿` | 37 / 70.27% | 83 / 48.19% | -0.6774% |

这组结果直接否定“选择一个高流动性阈值即可合法恢复 70%”。命中 70% 只发生在已查看的
开发段，锁定留出立即反向。

以较宽的 D-1 成交额 `>=2亿` 做固定消融，结果如下：

| 口径 | 当前财报 | 当前财报 + D-1 流动性 | 变化 |
|---|---:|---:|---:|
| 全量闭合 | 239 | 211 | -28 |
| 全量胜率 | 54.8117% | 55.4502% | +0.6385 pct |
| 全量平均收益 | +0.5687% | +0.6109% | +0.0422 pct |
| 两仓闭合 | 127 | 119 | -8 |
| 两仓胜率 | 58.2677% | 61.3445% | +3.0768 pct |
| 两仓复利 | +54.7953% | +84.3370% | +29.5417 pct |
| 两仓最大回撤 | -20.6187% | -16.6504% | +3.9683 pct |

锁定留出中，全量推荐从 `51.9553% / +0.1416%` 变为
`51.9231% / +0.1267%`，没有改善；两仓账户却从 `55.1282% / +3.5048%` 变为
`58.1081% / +16.7217%`。因此两仓提升主要来自删票后改变占仓和到达顺序，不是每条推荐
的 D+1 质量得到稳定提升。它不能支持“不限两仓的实时全量推荐”升级。

## Financial And Liquidity Ablation

四组正式链消融仅移除“财报可用且归母同比 >=10%”条件，继续保留财务风险门：

| 方案 | 全量闭合 | 胜率 | 平均收益 | 锁定留出胜率 | 锁定留出均值 |
|---|---:|---:|---:|---:|---:|
| 当前财报 | 239 | 54.8117% | +0.5687% | 51.9553% | +0.1416% |
| 当前财报 + D-1 成交额 >=2亿 | 211 | 55.4502% | +0.6109% | 51.9231% | +0.1267% |
| 移除利润增长门 | 482 | 49.1701% | -0.0033% | 47.4801% | -0.2995% |
| 移除利润增长门 + D-1 成交额 >=2亿 | 401 | 50.6234% | +0.1460% | 49.1961% | -0.1379% |

正确财报因子有明确正边际，D-1 流动性不能替代它。当前最好的研究组合仍是保留正确财报
并叠加宽流动性诊断，但其全量胜率只有 `55.45%`，远未恢复旧 62%，更不是 70%。

## Decision

- 不恢复旧财报缺失门，不使用当前市值/成交额快照回填历史，也不按已看结果把流动性阈值
  调到 70%。
- 正式 v15/v9 实时推荐、首板/二进三、两仓和退出规则本轮不变。
- D-1 流动性当前只适合作为诊断或新的独立前向排序影子，不具备硬门晋级证据。
- 下一项有效研究应针对 locked holdout 和冻结后亏损的点时市场状态、横截面轮动与占仓
  排序，并使用新的独立时间段预注册验证；必须继续分别报告全量推荐与两仓账户。

## Limitations

- 历史仍是触板成交代理，没有 Tick/L2 排队成交证明，`live_equivalent=false`。
- 主板股票池及大部分历史行业成员仍有当前成员代理和幸存者风险。
- 已查看 locked holdout 后，本报告中的所有流动性阈值只能是研究结论，不能再把该留出段
  当作下一轮未见验证集。
