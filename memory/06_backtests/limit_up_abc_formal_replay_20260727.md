## Formal rules

1. A/B 基座要求原财报点时、结构、lane、盘中执行和同股盈利门通过，并要求过去 126 个
   交易日涨停 2-6 次。D-1 行业成交额不低于前 5 日均值为 A，否则为 B。
2. C 只覆盖 A+B 的三个拒绝原因：同股 D+1 样本不足 5、同股联合率低于 30%、半年
   涨停超过 6 次。它还必须通过冻结的行业资金/回撤或动态概念扩散交叉条件。
3. C 只允许当天尚未观察到 A/B 时的第一笔。相同时点按 `A > C > B`；相同时点 A 不算
   C 的“此前 A”。跨时点严格按信号实际到达顺序，禁止日终重排。
4. A/C 首板和二进三均在 10:00 后行动；B 首板在 10:30 后首次触板或回封才行动。
   B 若 10:30 前首次触板，只有 10:30 后出现真实回封才按回封时点入队。
5. 两仓账户在尚无 A 时最多持有一个 B/C，给后续 A 保留一仓。C 每日最多一笔。
6. 入场使用正式涨停价代理并计滑点和费用；D+1 使用官方日线收盘。没有 Tick/L2 和
   委托回报时，不能证明涨停排队一定成交。

## Causal correction audit

- 早期草稿曾报告 142 条闭合、单仓 `+485.3384%`、两仓 `+234.3344%`。该数字来自
  最后一次因果排序修正前，现已作废。
- 修正后，10:30 前触板但 10:30 后回封的 B 只在回封时刻入队；同秒按 A/C/B 排序，
  同秒 A 不会被当作 C 之前已经观察到的 A。这使 C 闭合样本从 71 增至 72，其中新增
  样本为亏损，故全量胜率和账户复利小幅下降。
- 当前结果仍同时满足：全量胜率 `>=60%`、单仓复利 `>=400%`、两仓复利 `>=200%`。
