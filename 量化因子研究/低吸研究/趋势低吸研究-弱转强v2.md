# 最终方案（2026-08-23 定稿 v2.2，十一轮全市场验证 + 当晚位置/连跌条件增补）

> v2.1 变更（2026-08-23 晚）：A1 新增条件⑥「首板未创60日新高」（突破过顶不做）——封板 56→63%、+1.98→+2.32%、负月 13→9；A2/B 不挂（证据见 A1 条件⑥节）。
> v2.2 变更（2026-08-23 晚）：A1 再增条件⑦「前日也下跌」（连跌两天再反包，同花顺原生）——封板 63→64%、+2.32→+3.00%、胜率 62→64%、负月 9→6、分年全正且 2026 最强（+4.9)；断板首日即反包型被排除（赤天化型牺牲、盛视科技型正确滤除）。其余条件不变。

> 结构：**一、基本条件**（每条附数据表）→ **二、组A 二板弱转强**（A1 恐慌出清=直接打主力 / A2 强势整理=封板确认）→ **三、组B 高位弱转强** → **四、买入规则** → **五、卖出规则** → **六、组C 已删除（数据判定）** → **七、案例汇总**。所有条件只取昨日及以前已收盘数据，盘中只用竞价与实时涨幅触发，无未来函数。原"否决条件"已拆散并入各组的数据表（换手≥40%→基本条件表、竞价/大盘→买入规则表、高位短回落→组B回落天数表、高位+强势整理→A2 边界表），不再单独存在。

## 二、组A：二板弱转强（前段恰好 2 连板）

### A1 恐慌出清型（+7% 直接打，主力）

```
基本条件 + 昨日跌幅 > 3% + 昨日下影线 < 2%          (恐慌出清定义: 真跌且收在低位)
        + 出清确认: 昨日量比 0.7~1.2  或  昨日振幅 ≥ 12%
        + 昨日换手 8% ~ 20%
        + 底座(20日涨幅) < 30%
        + 首板未创60日新高(二板首板日收盘 < 其前60日最高价,突破过顶不做)   [v2.1]
        + 前日也下跌(昨日跌且前日收跌,连跌两天再反包;同花顺: 前日涨幅小于0%)   [v2.2]
```

答案：**不是 -10%~-7%**。红盘和小跌全是负的；-3% 是转折点；**-5% ~ -9.4%（接近跌停但没跌停）才是最佳区**；跌停收盘反而差（卖压没释放完）。条件保持"跌 > 3%"作门槛即可，更细的区分已由下影线和出清确认接管，不再叠加跌幅上限。

**条件② 昨日下影线 < 2%**

下影线衡量"收盘离全天最低有多近"：下影线小 = 收盘贴在最低位 = 尾盘没有承接、恐慌是真实的；跌 > 3% 但下影线长 = 尾盘被拉回去的假恐慌/诱多。分桶证据（二板+昨日跌>3%+达+7%，n=1616）：

|---|---|---|---|---|
| 0~0.5%（光脚） | 587 | 44% | -0.21% | 47% |
| **0.5~1%** | 284 | **51%** | **+0.86%** | **52%** |
| 1~2% | 389 | 42% | +0.17% | 48% |
| 2~3% | 204 | 42% | -0.68% | 43% |
| 3~5% | 129 | 40% | -0.51% | 50% |
| ≥5% | 23 | 48% | -1.00% | 39% |

读法：<2% 为正区、≥2% 全负，门槛取 2%。注意光脚（下影≈0）单独并不优——最好的恐慌票是"杀到低位后留一点承接"（0.5~1%）；光脚+缩量的一字跌停类由出清确认和换手条件负责排除。

**条件③ 出清确认 = 昨日量比 0.7~1.2 或 振幅 ≥ 12%**

量比定义 = 昨日成交量 ÷ 过去 5 日平均成交量。**与同花顺/标准量比的关系**：标准量比 = 全日成交量 ÷（过去 5 日平均每分钟成交量 × 当日交易分钟数）——对已收盘的完整交易日，分母乘满 240 分钟后正好等于"5 日平均全日成交量"，**两者完全等价，同花顺问财直接写"昨日量比 0.7 到 1.2"即可**。注意不能拿"今日盘中量比"对照这个范围（盘中量比按已交易时间归一化，早盘虚高）。

**条件⑦ 前日也下跌（v2.2 新增，主人提出"昨日比前日下跌"假设后验证定稿）**

定义：信号日（昨日）收跌 **且** 前日也收跌（前日涨幅 < 0%）——连跌两天再反包，"弱"的更纯粹定义。同花顺原生字段（前日涨幅小于0%），无未来函数。

有效性（在 v2.1 池内）：前日收跌的票 +2.82%/62%，前日红盘的票 +1.54%/60%；与位置条件近似独立（前日跌里未创新高占 64%，前日红里占 71%）——两个条件管的是两批不同的坏票。

|---|---|---|---|---|---|---|---|

结论：**封板确认入场合废**。A2 必须换成「能实际成交的价位 + 封板率 >50% 期望打平线」的结构。

## 二、补涨方向证伪（第 1~6 批，主人原始假设）

「断板后昨涨>0 的补涨形态」不成立：
- 补涨池（昨涨>0，15,915 票日）触 7/8/9 与 7~9 带直接买全线 **-0.9%~-1.3%/41%**；
- 昨涨全谱**单调「越跌越好」**（<-5% 档 +0.39 vs 昨涨 0~2% -1.07）——补涨方向正是毒药，
  深跌反抽方向才是肉（那是 A1 的地盘，主人自己预感的「跟 A1 差不多」是对的）；
- 封板率数学锁死：触 7 者当日封 +3.60%/未封 -3.55%，封板率需 >50% 才打平，日级条件最高 42%；
- 封板确认结构下「昨涨 0~8 补涨组」全部候选训验均劣于现行 A2。

**A2 的职责定名：不是补涨，是「二板断板后不深跌的强势整理，次日准封板接力」。**

## 三、A2-v3 终案（第 9~15 批迭代收敛）

死磕「可执行 + 封板率越过打平线」后的结构，全部条件用同花顺原生语言：

```
池（昨日收盘数据）：
  主板 / 非ST非退 / 上市>5日
  近10个交易日内出现过连续2天涨停，且最近一次连板高度恰为2板（4板+ 在本入场下 -2.77%/29% 大毒）
  昨日未涨停（断板中）
  昨日收阳（收盘价 > 开盘价）
  昨日上影线 < 2%（同花顺标准口径：(最高-实体顶)/昨收；收阳时实体顶=收盘，
                   即"收盘贴全日高点，摸高不回落"——强势整理非出货）
  昨日换手率 8% ~ 20%
  近20日涨幅 < 30%（低位底盘，获利盘不重）

盘中（今日执行）：
  竞价高开 0% ~ +4% 才出手（9:25 可知，范围外当日放弃）
  涨幅首次触及 +9%（昨收×1.09）限价直接买——准封板确认，封死 +10% 不追
  买入当日 14:50 仍未封板 → 尾盘卖出，当日了结；封板 → 板留断走
  昨日大盘（主板非ST）涨停 > 110 家停手
```

**为什么是 +9% 不是 +7%**：+9% = 准封板确认，触 9 者当日封板率 **65%**（越过 50% 打平线），
触 7 仅 39%（数学不可用）。+9% 限价单盘中可成交，比封板确认（买不到）便宜 1pp，比 +7%（未封
者 -3.55%）安全——这是「能买到的最优价位」。

**条件命名同花顺化**（主人要求：不再用模糊名称）：
- 旧「fade<2%」→ **「昨日收阳 + 昨日上影线小于2%」**：两口径对照实测（第 14~15 批）——
  标准上影线直接用会收进阴线假强势票（198 笔稀释到 +0.86），**加「昨日收阳」后与旧 fade 口径
  精确等价**（收阳时实体顶=收盘，差集仅 8 笔十字星，+2.68→+2.64 无损），同花顺全闭环零口径差；
- 旧「底座<30%」→ **「近20日涨幅小于30%」**（本来就是同花顺原生字段）。

**单维松动扫描**（第 12 批，每个条件放宽/收紧实测）：fade<2 是甜点（<1.5 训练段 -2.3 变味，
>2.5 稀释）；板高仅 2 板；竞价 0~4 保持；断板天数无信息不加；**唯一实质优化 = 换手下限
5→8（+1.07pp，胜率 59→67）**；量比/昨涨上限/下影加料全无益。
