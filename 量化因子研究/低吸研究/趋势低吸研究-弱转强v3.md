## 条件抽离
所以条件应该存在共用关系。
最终可能抽离出的就两种情况。

1. >=2 板后的快速接续
2. >=2 板后的缓慢重启

这种 >=2 板后 也大致分为 弱转强/补涨

弱转强就是 断板后续还是继续创新高 

补涨就是 断板后回落没多少时间 或者 横盘一段时间继续补涨

归根到底就是为了后面能够上车的 连板过程。

# 补涨阴·U型蹲 U1（2026-08-29 定稿 · 文字条件已独立核查对账）

## 条件（同花顺表达）

```
## 补涨阴·U型蹲 U1
主板 / 非ST
前20日连板 = 2
昨日未涨停 / 昨日收阴 / 昨日涨跌幅-9%~0 / 昨日上影线<4% / 前三日涨跌幅<6%
N = 昨日距上波末板的天数（上波 = 最近的≥2连板段，跳过断板期孤立夹板）
蹲深: N日内最低收盘价 / 上波段最高价 - 1 ≤ -12%
弹回: 昨收 / N日内最低收盘价 - 1 = 8%~14%        ← 命门
不贴顶: 昨收 / 上波段最高价 - 1 ≤ -4%
断板期收盘振幅 > 10%                             ← 剔缓坡假U
低点位置: 断板期最低收盘出现在前60%（公式版 BARSLAST 口径）
          或 近3日未创N日收盘新低（问财近似版）
```

公式骨架: `REF(C,1)/LLV(REF(C,1),N)-1 ∈ [0.08,0.14]`; 顶 = 上波段最高价（**不是**N+2窗最高，
含断板期会把冲高回落票的回撤算虚深）。

## 效果（触板买涨停价 · 板留断走 · 2023-2026）

|---|---|---|---|---|---|

弹回是命门: 门内外板留差6.5个点。蹲深/断板是宽容维度（缺了不掉血）。上波3板+的U型深亏率
24~36% vs 2板10% → 高板深蹲是差票画像。尾部: 25-26无-10%以下单, 2023年有一笔-16.7%。
覆盖: 月均约1笔, 63%的月份有U型 → 定位=补涨阴雷达池内的精选甜点层, 非独立策略。

核查对账(2026-08-29, w2s_u1_check.py): 文字条件独立实现与回测版 29/33=88%一致、零多余票;
4笔差异均为「20日内更早有≥3板+最近段恰好2板」边缘票(文字版更严, 分年更稳)。
三轮修正: ①20日窗→断板期锚定 ②最近涨停→最近连板段(跳夹板) ③顶=N+2窗→上波段顶。
