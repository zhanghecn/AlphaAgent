# 趋势低吸规则详解：涨停弱转强（B）与补涨涨停（A）

本文是趋势族两条主力规则的产品级详解（2026-08-17 涨停确认制定稿，v3.4/v15）。
研究全史与已证伪方向见 [趋势低吸研究.md](趋势低吸研究.md)。

## 一、共同的背景：一轮妖股行情的生命周期

两条规则盯着**同一段行情的不同时间窗**——先走出 ≥4~5 连板的妖股段（主段），
段顶破坏后：

```
连板段(≥4~5板) ──段顶──┬─ T+1~4日 刚破坏 ──→ B 涨停弱转强（情绪还热）
                        └─ T+5~30日 回落蓄势 ─→ 观察层雷达 → A 补涨涨停（二波启动）
```

核心纪律：**判别器不在行情，在票本身的涨停确认**。弱市门/强市门已被研究证伪
（好/坏票在个股六维度分布重叠），A 类强市 66.3% / 弱市 79.2% 双正是跨行情
通用因子的直接证据。

## 二、B 涨停弱转强（打板预备，P1.5 主力）

### 形态故事

五连板妖股某天炸板/大阴，第二天所有人都等着低开跌停出货——结果它低开后被
资金从水下直接拉回**封死涨停**。弱预期被强现实打脸，空头反手被收割。

### 条件逐条

| 条件 | 阈值 | 为什么 |
|---|---|---|
| ≥4 板主段 | 60 日窗口内递推最大连板段 | 没有妖股基因的普通票拉板只是随机波动 |
| 段顶后 ≤4 日 | 刚破坏窗口 | 破坏太久情绪凉透、资金已散——≤4 日是情绪余温还在的窗口 |
| 当日低开 | 开盘 ≤0% | 低开才构成「弱」的预期；平开高开没有反差 |
| **收盘涨停** | 盘中拉回封板 | **核心确认**——不涨停的水下拉起全是负边缘（37~42%） |

### 证据

- 两年全市场 n=318，胜率 **60.4%** / D+1 均值 +1.69
- 每日前五口径：半年 +38.9%、回撤仅 −2.0%
- 案例：双成药业 2024-10-14、国芳集团 2025-04-16、航天发展 2025-11-24、
  恒尚节能 2026-07-13（当日全部进前五）；开开实业 2026-08-14 实盘命中
  （交割单当日 rank#1）

### 同票对照（判别力的直接证明）

航天发展 2025-11-24 涨停拉板（放行）vs 2025-11-27 水下拉回收 −3.2% 未涨停
（研究锚点不放行）——同样震撼的形态，判别就一条：**是否收盘涨停**。

### 用法

- **可以盘中预知**（低开拉板的过程看得到），直接当天打板买入，不必等次日
- 买入价研究：信号日打板价买 60.4% 优于次日 D+1 竞价买 53.0%/+0.62
- 实时推荐盘中每分钟扫描：**封板那一刻** B 信号出现在推荐页（盘中虚拟 K 线
  的收盘价 = 最新价，封板即满足「收盘涨停」）；拉升途中不出现是设计纪律——
  未封板的同形态是负边缘
- 尾盘封板比早盘封板更稳（留下的炸板时间短）

## 三、A 补涨涨停（N 字板，P1 跨行情通用）

### 形态故事

妖股段顶破坏后回落两到六周，量能缩到地量、横盘把浮筹磨干净——然后某天
**平开直接进攻收涨停**。这是二波启动的确认板，走出 N 字（涨-回落-再涨），
接下来常创新高（创新高组 D+10 达 80.3%/+17.4，未创新高组仅 39.5%/−2.3）。

### 条件逐条

| 条件 | 阈值 | 为什么 |
|---|---|---|
| ≥5 板主段 | 比 B 门槛高 | 二波蓄势需要更强的妖股记忆 |
| 段顶后 5~30 日 | 回落蓄势期 | 与 B 的 ≤4 日窗互补；>30 日行情被遗忘 |
| D 日收盘涨停 | 二波确认板 | 信号日本身就是涨停（产品层专门豁免涨停剔除） |
| **平开直接进攻** | 开盘 0~3% | **与 B 性格相反**：低开抢跑是 B 的领地；高开 >3% 追高死（50.8%） |
| 换手 <20% | 10~20% 甜点 | ≥20% 过热桶次日崩到 45.3%——二波启动日换手要温和 |
| 量能恢复 >30% 主段峰值 | 30~60% 健康 | **地量走不出新高**（地量新高率 3.3% vs 放量 18.4%）——缩量反抽只是反抽 |

### 证据

- 两年 n=157，胜率 **70.7%** / D+1 均值 +3.00（全系统单规则最高）
- 强市 66.3% / 弱市 79.2% **双正**——跨行情通用因子
- 案例：华电辽能 2026-04-22（D+1 +9.96）、福达合金 2026-06-15（+10.01，
  交割单当日 rank#1）、九牧王 2025-12-18（+9.97）

### 用法

- 同样打板价买（70.7% > 次日竞价 57.9%/+1.02）
- 错过打板时**次日竞价 gap 2~5% 是唯一备用窗**（76.9%/+2.58）；
  gap ≥5% 追高死（35.3%）、低开走坏（B 池低开子集 38.9%）——竞价只做备用
  入场与确认，不作主口径
- 回测保持 D 日收盘（涨停价）买入、D+1 收盘结算

## 四、两条的性格对照

| 维度 | B 弱转强 | A 补涨涨停 |
|---|---|---|
| 时间窗 | 段顶后 ≤4 日（刚破坏） | 段顶后 5~30 日（蓄势完） |
| 开盘方式 | **低开越深越好**（≤-3% 组件满分） | **平开最甜**（0~3%） |
| 换手 | 越高越好（妖股 20-38% 常态） | 10~20% 甜点，≥20% 崩 |
| 量能 | 不看（拉板力度才是证据） | 必须恢复主段 >30%（地量只是反抽） |
| 逻辑本质 | 情绪余温里的反手收割 | 蓄势出清后的二波启动 |
| 胜率/均值 | 60.4% / +1.69 | 70.7% / +3.00 |

## 五、配套的两层（不占仓位）

- **观察层**（连板回落低吸观察）：A 的雷达——蓄势期出现小阳 + 量温和 +
  段后换手 5~20% 时进推荐页提醒盯盘（如恒尚节能 2026-08-17）。它预告未来
  数日可能出 N 字板，但**当天买入没有优势**（50.8%）——扣扳机要等板本身。
  不占回测仓位。
- **非涨停弱转强**（研究锚点）：B 的未确认形态。九个案例（兴业/科森 8-26/
  航天 11-27/梦天/安记/锋龙/哈药/传智/爱丽）形态都成立，但全市场两年
  37~42% 负边缘——只审计不推荐。
