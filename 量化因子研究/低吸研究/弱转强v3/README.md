# 趋势弱转强 V3 · 行情簇数据集

样本定义:**主板非ST宇宙内,某票走出 ≥2 连板 → 断板 → 断板后第 1~20 个交易日内再次开启一段 ≥2 连板**的全部历史行情。
每次这样的"二度走强"与其后续延伸(第三波、第四波…)聚合为一个**行情簇(cluster)**,簇内每个 ≥2 板段为一**波(wave)**。

- 事实源脚本: `量化因子研究/低吸研究/scripts/w2s_v3_wave_research.py`(explore/case/export 三命令)
- 生成时间: 2026-08-27 · 数据末端 2026-08-26

## 目录结构

```
弱转强v3/
├── README.md                 ← 本文件(验算前必读)
├── 01_双板往复_快速接续/YYYY-MM.md   n=108, 两波都是2板,断板后≤5交易日即再板
├── 02_双板往复_缓慢重启/YYYY-MM.md   n=168, 两波都是2板,新波在6~20交易日才启动
├── 03_第二波升级_高度超越/YYYY-MM.md n=134, h2>h1 (越战越勇型)
├── 04_第二波衰减_余威反抽/YYYY-MM.md n=191, h2<h1 (一波见顶后的余威反抽)
├── 05_三波及以上_多轮博弈/YYYY-MM.md n=179, 复杂接力结构
└── _汇总/
    ├── all_clusters.md       全部 780 簇索引(一行一簇,含组归属与日期)
    ├── all_waves.csv         全部波次长表(每波一行;唯一保留的机器验算入口)
    └── summary_组x月.md      组×锚定月 样本量透视
```

月度 md 布局: 页首为当月簇索引表(代码/名称/波数/起止/峰值波),其后**每簇一个小节**,
含该簇全部波次竖表(开启/确认/结束/板数/间隔/洗盘回撤/途中单板)。

五组互斥且全覆盖 780 簇;归档月 = **第一波首板日所在月**。

## 口径(与 w2s_replay.py v3.0 一致)

- 宇宙: 主板(代码非 300/301/688/689/8xx/4xx/92x 前缀)/非ST非退(按当前名)
- 涨停判定: 不复权收盘价 = round(昨收×1.10+1e-9, 2);上市前 5 个交易日不判定
- 连板段: 连续封板日为一段,height=板数;
  **start**=首板日(开启) / **confirm**=第2板日(达成≥2板确认) / **end**=末板日(结束)
- 20日窗口 = 交易日数(pos差);两波间隔 gap_tb = 下波首板pos − 上波末板pos(1=断板次日直接再板)

## 字段字典

**月度 md · 簇标题行**: `名称 \`代码\`　N波｜起点 ~ 终点　· 峰值第K波 [⚠️next_uncertain]`
峰值波=全簇最高一波的序号(1=一波见顶);⚠️=末波距数据末端<21交易日,"是否已终结"未定,**验算建议剔除**。

**月度 md · 波次竖表**

| 列 | 含义 |
|---|---|
| 波 | 波序(1=第一波) |
| 开启(首板) / 确认(二板) / 结束(末板) | 该波首板日 / 达成≥2板日 / 最后涨停日 |
| 板数 | 本波连板高度 height |
| 距上波(交易日/自然日) | 上波末板→本波首板的间隔;第一波无此值 |
| 波间最低回撤% | 两波之间最低价相对上波最高价的回撤(负值,-31.09 即最深洗到 -31%) |
| 波间孤立单板 | 两波之间出现的单日涨停板块数 |

**_汇总/all_waves.csv**(机器验算入口,每波一行): `cluster_id, code, name, group, anchor_month,
wave_no, n_waves, first_date, confirm_date, last_date, height, gap_prev_tb, gap_prev_cal,
between_low_dd, between_singles` — 与 md 表格同义,方便程序过滤。

## 已知近似与注意(验算时请知悉)

1. 涨停价用不复权昨收×1.10,遇除权除息日的段落边界存在近似(与 v2/v3.0 产品口径一致);
2. 2023 年之前仅个别老票有日线,样本主体在 2023-04 之后,早年零星样本如实保留;
3. ST/退市按当前名过滤,历史曾戴帽的段落可能与当年口径有出入;
4. 全库单簇最多 6 波;
5. 本数据集为**事后结构刻画**(第二波属于事后事实),不含入场执行约束;主人给出条件后,
   应在 `_汇总/all_waves.csv` 或全市场重算管线中验算查准/查全,而不是只在单一组内验算。
