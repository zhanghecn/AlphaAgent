# 低位一接二 · 研究需求与计划

（2026-10-06 立项。范式完全沿用 `量化因子研究/高位接力/`，
本文档 = 需求单 + 十步执行计划，主人已拍板，照此动手。）

## 〇、一句话定位

昨日恰好一个涨停（孤立首板）的票，今天冲二板时打板买入，研究什么情况下值得接。
这是打板接力谱系里唯一没做过的板位——向下衔接潜龙（首板当天的池子就是明天的候选），
向上衔接 hpr（今天封住二板，明天就进二接三）。

## 一、研究目标

1. 一接二**不挑就买**是什么成绩（先立靶子，预期为负）。
2. 存在**分年全正的正期望格**吗？在什么位置、什么底盘、什么首板质量、什么竞价档。
3. 最终收敛出**精简通用口诀（≤3~4 条）**——不是条件的堆叠，而是本质规律：
   精简不意味着效果打折，机制必须能解释格子、能预测没搜过的格子。

## 二、口径定义（已拍板）

1. **事件**：昨日涨停且前日不涨停（孤立首板；断板后再起的二波首板不排除，作分层维度），
   当日盘中碰到涨停价 → 按涨停价买入；当日一字板（全天没打开）买不进，剔除；T字可买。
2. **池子**：主板、非 ST 非退（按当前名称）、上市满 5 个交易日；
   涨停判定 = 不复权昨收 × 1.10 四舍五入到分。
   已实测：2023 起 8185 笔入池（hpr 同口径 3328 笔的 2.5 倍）。
3. **「低位」不做硬入池**：全谱分层，位置作为一级分组维度，让数据说话。
4. **窗口**：主窗 2023-01-01 ~ 数据末端（对齐 hpr）；2021-01-01 ~ 2022-12-31 纯样本外段
   （同批建样本、分开统计；日线库 1993 年起完整，回看窗 START_BARS=2020-06-01）。
5. **卖出**：全套沿用 hpr v6.7 纪律不改——E3（炸板当日收盘卖 / 封住拿到首次不再涨停日
   收盘卖 / 15 交易日兜底）+ D+2 深开竞价卖（昨天封板、今开≤-5% 竞价直接卖）+
   跌停口径修正（只有全天一字死封才顺延次日开盘，其余按跌停价卖出）。
   第 7 步专项验证一接二特殊性，有证据再改。
6. **收益口径**：坏票 = 买入后第二天收盘低于买价；数据末端未走到卖出日标「未完」不进统计；
   统计按月切分，验收 = 分年全正 + 不靠个别月份。
7. **无未来函数铁律**（原样继承 hpr）：入场只用前一晚静态信息 + 竞价（9:25 定型）+
   昨日涨停家数；**禁止用买入当天的量比/换手率**（收盘才定型）；当天走势字段只进卖出纪律。
8. **环境维度不进口诀**（主人规则：不加外部行情过滤，庄家敢拉已考虑行情）：
   昨日全市场涨停家数等只做分层观察与仓位层（情绪冰点减半仓那种），不作为入场条件。
9. **格子门槛**：最低笔数 ≥15，分年单年不得少于 2 笔；口诀合计月均 ≤8 笔（软上限，
   超了继续收紧——实盘一只手打不过来）。

## 三、研究框架

hpr 分组 = 板位 × 地基阴阳；一接二只有一个板位，框架升级为：

- **一级分组 = 地基阴阳 × 位置五档**
  （地基 = 首板前一天 K 线，收≥开=阳；位置 = 首板日收盘距 60 日最高价：
  跌透 <-30% / 低位 -30~-10% / 半山 -10~0% / 贴顶 0~+10% / 新高 >+10%）
- **二级分层 = 底盘纯度**（60 日板史：纯底盘无板 / 孤立单板 / 有过 ≥2 连板前波）
  ——直接衔接潜龙首板的底盘结论。

一接二天然只有一块板的历史（没有板型链、没有两板换手对比），判别重心压在：

| 类别 | 维度 | 说明 |
|---|---|---|
| 静态·位置 | 距 60 日高点五档、距 10/20 日线、均线形态（多头/纠缠） | 主人点题「低位」的主战场 |
| 静态·底盘 | 60 日板史、首板前 10/20 日涨幅 | hpr 阳组毒格尺子（半山腰 5~15% 最毒） |
| 静态·首板质量 | 板型（一字/T字/实体/下影）、首板换手分档、开口深度（最低价距涨停价）、量比（首板量/前5日均量） | 「宣言的诚意」 |
| 静态·盘子 | 流通市值分档 | stocks 表有则用 |
| 竞价 | 今开六档（低开<0 / 0~2 / 2~4 / 4~7 / 7~9.5 / 顶格≥9.5） | hpr 六档对齐 |
| 信息层 | 昨日涨停家数、首板日同板块涨停家数 | 只观察/仓位层，不进口诀 |

## 五、第十步 · 本质收敛与口诀化（最难也最关键）

### 5.1 机制追问
每条候选口诀必须回答「为什么赚钱」——这个结构里谁在卖、谁在买、主力想干什么。
一接二的天然机制候选（研究中验证，不预设答案）：
- 首板 = 主力的「宣言」，二板 = 市场是否相信这场宣言；
- 赚的是「宣言被相信」的钱 → 本质判别器大概率先落在**首板的诚意**（板型/换手/封板质量）
  和**位置的安全垫**（低位=有空间，高位=接飞刀）上。

### 5.2 机制外推检验（硬门禁）
**找到本质的标志是能预测没搜过的格子，而不只是能复现搜过的格子。**
机制定稿后，拿它预测研究过程中从未进过搜索清单的格子
（例：机制说「低位+锁仓=真启动」→ 去验「高位+锁仓」是否真的差、「低位+放量烂板」是否真的差）。
预测方向对了才算数；预测不动 = 统计巧合，回去重找。

### 5.3 机制统摄合并
几个候选格若是同一机制的不同分支，必须合并成一条母口诀
（如 hpr「跨阴阳铁律」一句话统摄整张速查树）。验收线：最终口诀 ≤3~4 条，
一条一句、正常语言、能背下来（禁研究黑话）。

### 5.4 精简 ≠ 效果打折
合并精简后的口诀全集，成绩不得明显低于最细格子最优组合。
精简掉一大截收益 = 还没找到本质，只是剪枝——回去继续挖，
不许用「简洁」当成绩变差的借口。

## 六、与现有线的关系（必须审计）

- **潜龙**：潜龙池（首板当天买）正是一接二的候选母体——统计口诀命中票与潜龙底盘口径
  的重合度，看是互补还是冗余。
- **hpr 二接三**：谱系上下游，口诀命中日天然不同日（板数不同），验证零重叠。
- **w2s / erbo / fbb**：结构不同（坑后再板/断板反包），理论零重叠，跑同票同日审计坐实。
- 注意：潜龙/w2s/erbo 产品已下线，审计用其历史研究明细表做（DB 物化表若在）。

## 七、最终交付物（按优先级）

1. **核心：精简通用口诀 ≤3~4 条**，每条四件套——
   ① 一句话口诀原文（正常语言）② 机制解释（为什么，谁在卖谁在买）
   ③ 跨行情验证记录（分年 + 2021-2022 样本外 + 环境分层下都成立）
   ④ 外推预测命中记录（预测了哪些未搜索格子、对了几成）。
2. 全景基线账本（8185+ 笔不挑就买，含分年按月）。
3. 逐维普查矩阵全集（正期望岛在哪一目了然）。
4. 结论两种终点都算研究成功：
   - **成立**：口诀上线（出手/观察分级）+ 产品化（问财条件句/判定层/页签/题库，另立项）；
   - **不成立**：诚实证伪报告（哪些格子接近、死在哪道检验），留档不再回头。
5. 毒格回避清单（含分年证据）。
6. 卖出纪律适配结论。
7. 好差票月度清单（每票标注口诀归属，未命中写明差在哪个条件；2021 起逐月）。
8. 谱系重叠审计表（× 潜龙/hpr/w2s/fbb 同票同日）。
9. 全套可重跑脚本 + 全量明细 CSV（口径与 hpr 对齐可横向对比）。
