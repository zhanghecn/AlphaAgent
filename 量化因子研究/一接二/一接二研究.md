## 二、样本口径

事件 = 昨日涨停且前日不涨停（streak_prev=1 孤立首板）× 当日盘中碰涨停价 × 非一字；
主板非ST非退、上市满5日、涨停=昨收×1.10四舍五入到分；卖出全套沿用 hpr v6.7
（E3 + D+2深开竞价卖 + 跌停口径修正，算法逐行取自产品 high_relay/backtest.py）。

主窗 8185 笔（月均182笔，hpr 同口径池的 2.5 倍）+ 样本外 4397 笔。
行号语义：i=买入日, p1=i-1首板日, p2=i-2地基日；位置口径=地基日收盘距60日最高价
（首板收盘=涨停价必然是窗口最高，用首板日口径恒≤0 无意义——立项时踩过此坑已修正）。

## 三、十步走完的结论（细节在各汇总文档）

1. **基线**：主窗不挑就买 8176 笔 E3 -0.90（胜率断板 35.8%、封板率 61.7%）、
   分年三负一平——和 hpr 一样不挑就亏，价值全在精选。
2. **单维亮点**：今开 7~9.5 是唯一分年全正大档（+1.32）；顶格 1700 笔 -3.54 毒王；
   贴顶 36 笔 -7.90 全灭；首板一字 -2.19（与 hpr 一字肥肉相反）；纯底盘 -1.26 最差
   （与潜龙相反）；阴地基 +0.04 > 阳 -1.57。
3. **交叉矩阵**：正期望岛全部聚在「今开细档 8.5~9.5」×「坑深族」；
   阴×今开7~9.5 = 340笔 +3.22 四年全正为最大可执行格。
4. **候选格晃动**：今开下界 6/6.5/7/7.5 全正不刀口；阴×7.5~9.5 = 250笔 +4.74 定为主格 G1；
   阳组全组无格（最好候选也不过 +1.68 薄且分年破）。
5. **联调**：P1 格内距MA20 呈 U 型（深下+7.56 / 骑线-0.26 / 上方+4.08）；
   换手 <8 肥（+4.95）8~20 毒（-0.17）；今开 7~7.5 是假强（-1.00）真金从 7.5 起；
   最好5笔全部深坑、最差5笔全部高位——机制侧写完美分离。
6. **五道检验**：G1/G2/G3 全过；阳地基对照组五道全不过（反证判别力真空）。
7. **样本外（照妖镜）**：G1 两年全正但缩水（+4.74→+1.21）；**G3 低位腿 2021 年翻车
   （-0.52）→ 降级信息层**；G2 换手腿无样本外增量 → 同降级。最终只剩一条主口诀——
   精简不是选择而是样本外逼出来的：更细的腿全死在 2021-2022，一条主格反而六年全活。
8. **卖出+门禁**：E3 沿用无需改（断板 vs E3 差 -0.16，封板率 81.2%，持有中位 1 天）；
   独立代码重算 10 票全对账。
9. **重叠审计**：hpr 0 笔 / fbb 0 笔同票同日（streak_prev=1 vs 2/3 结构互斥）；
   持有期内同票 hpr 信号 139 笔 = 谱系衔接（一接二封住→次日进 hpr 二接三池），非重复。
10. **机制收敛**：见下节。

## 四、机制（第十步 · 本质收敛）

**一句话：首板是主力的宣言；前一天阴线=宣言前把散户吓走的洗盘；次早竞价 7.5~9.5
是主力用真金白银宣告「宣言继续」——但没顶格，顶格=人人都看多=没有预期差只剩接炸板。
赚的是「洗过盘再确认」的二板溢价，尾部靠偶尔的连板妖股（新炬+128/美邦+93）。**

跨板位同构：与 hpr 二接三 B1「竞价确认」同一判别器（竞价强开但不透支）——
竞价是唯一 9:25 定型、人人可见、要掏真钱的确认信号。

三个「与相邻研究相反」的证据链（机制互洽）：
- 首板一字是毒（-2.19）vs hpr 二板一字是肥——首板一字=市场没参与、二板没人接力；
  二板一字=经过确认的锁仓。
- 纯底盘最差（-1.26）vs 潜龙纯底盘最好——首板次日接力要「有人做过」的票（前波连板
  +2.63），潜龙买首板要「从没人碰过」的票。同一底盘定义，两个动作两个结论。
- 阴地基肥（+4.74）vs hpr 阳组口诀多——板位越低，越要「挖坑启动」；板位越高，
  越要「锁仓续强」。

### 机制外推检验记录（预测没搜过的格子）

| 预测 | 结果 | 判定 |
|---|---|---|
| 首板换手锁住的好、分歧的差 | <8:+5.45 单调优于 8~20:-0.17 | ✓ |
| 顶格开是毒（无预期差+接炸板） | 主窗-3.54 / 样本外-1.10 | ✓ |
| 阳地基不碰（加速非启动） | 六年全负（对照组五道全不过） | ✓ |
| 贴顶是毒（力竭首板） | 主窗36笔-7.90全灭 / 样本外-2.37 | ✓ |
| 坑越深越肥 | 方向对但非单调（U型：深坑+多头回调两头肥、骑线烂）；「低位」硬条件样本外2021翻车 | 半✓（降级信息层） |

4.5 / 5 通过——机制成立但有边界：位置只加分不挡人。

## 五、供给与执行

- 月均 5.3 笔、68/69 月有票（软上限 8 以内）；单月最多 19 笔（2024-03）。

## 六、与现有线的谱系关系

- 潜龙（首板当天买）→ 一接二（次日接二板）→ hpr 二接三/三接四：同一只票的三段旅程，
  同票同日零重叠实证；一接二命中封住后，次日自然进入 hpr 池（139 笔衔接场景）。
- fbb（断板反包）结构互斥，0 重叠。
- w2s/erbo 已下线无研究明细表，结构上（坑后再板/断板反包）与首板次日接力不同日，
  未做实证——如需可后续补。
