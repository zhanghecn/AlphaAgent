> 分钟线 5m 自 2026-04、1m 自 2026-06 全市场稠密。分析脚本在 `scripts/`(fb_daily_variants /

## 最终条件公式(四层)

### L0 股票池(T-1 收盘后算好)
- 主板非 ST;**T-1 未涨停**;T-1 涨幅 `0% ~ 5%`
- T-1 收盘 > MA20;MA10 > MA20
- 距 MA20 `0% ~ 12%`;前 5 日涨幅 `0% ~ 15%`;T-1 换手 `< 8%`

### L1 情绪闸门(T-1 市场状态,决定当天做不做)
- 昨日主板涨幅 ≥5% 占比 **< 12%**(>12% 过热日次日晋级率仅 10.2%,硬止损线;v1 的 6% 偏严)
- 昨日炸板数 **≤ 60**(炸板潮次日 P(≥2板)=10.8%、P(≥5板)=0.36%,不做)
- 昨日市场最高连板 **≥ 5 板优先**(高度龙在场时 P(≥2板) 17.4~18.5% vs 无高度 14.5%)
- 昨日连板家数 > 30 家 = 过热,降级观察(P(≥2板) 降至 11.9%)

### L2 进场(T 日盘中,分钟级)
- 窗口:**09:31~09:45 主窗**;10:01~10:30、10:31~11:30 同样有效(封板率 89~91%);
  下午窗 84~87% 可作补充。越早触板越强。
- 触发:窗口内**首次**触及昨收 `+8%`;该分钟**收盘仍 ≥ +8%**(收住)。
- 进场:下一分钟开盘价买。**稳健版**:确认触发后连续 3 根 1m 收盘 ≥ +8%,以第 3 根收盘买进
  —— 封板率再抬 5~9pt(75%→84%、87%→92%),D+1 不降,MAE 更小。
- ~~量能持续/触发分钟放量要求~~:**实测证伪,删除**(同分钟量 2.5x 过滤砍掉一半样本且收益更差)。
- 上影线过滤冗余(收住已包含);高开 ≥+6% 不是减分项(反而更强,不要因高开放弃)。

### L3 出场(按收益分解定规则)
- 未封板:次日 D+1 平均 **-4.25%** → 次日竞价/早盘必须走。
- 封板但未晋级:D+1 开盘 +1.1~2.2%、收盘 -0.2% → **次日不快速封二板就走,开盘卖优于收盘卖**。
- 晋级 2 板+:D+1 +10.3%、3板+ D+3 +27.4% → 持有到断板。

## 期望值结构(钱的来源)

1m 全窗口合并(2026-06~08, n=332):
未封板 15%(-4.25%) / 止步1板 72%(-0.2%) / 2板 7%(+10.3%) / 3板+ 6%(D+3 +27.4%)。
**整体期望几乎全部来自 13% 的连板尾部**;过滤条件的价值 = 封板率从 51% 抬到 85%+
且 P(≥2板|封板) 从 17% 抬到 21~22%。

## 连板晋级因子(31,206 个首板,2023+,排除一字)

基准:P(≥2板)=16.4%,P(≥3板)=5.5%,P(≥5板)=1.2%。

| 因子 | 方向 |
|---|---|
| T 日缩量(量/5日均量<1) | **20.8% vs 15.4%**,最强个股因子 |
| 弱转强(前2~10日有连板记录) | 21.4% vs 16.0%,加分项 |
| T-1 换手 12%+ | 22~24%(晋级层面高换手是好;与 D+1 过滤目标不同,别混用) |
| 距 MA20 3~12% | 17~19%,甜区;>20% P(≥5板) 反而降到 0.87% |
| 前5日涨幅 0~15% | 17.6~18.3% 平台区;负值 14.2% |
| 低开首板 | 17.5%,略高于平开(14.9%) |
| 市场广度>12% | 10.2%,腰斩;炸板>60 → 10.8% |

组合过滤在首板样本内:P(≥2板) 16.4%→19.8%,P(≥3板) 5.5%→7.7%,P(≥5板) 1.2%→2.1%。

## 对 v1 的修订点

1. 「前日换手 5~8% 更优」未在样本外复现,只保留 `<8%`。
2. 「盘面 <6%」放宽为 `<12%` 过热线,并新增炸板潮(>60)与市场最高板(≥5)双闸。
3. 「09:31~09:45 主窗口」确认有效,且扩展至上午全天;新增「确认 3 分钟」稳健进场。
4. 「量能持续」证伪删除。
5. 新增弱转强、缩量首板两个晋级加分因子。

## 待办/风险

- 分钟全市场数据仅 2026-04(5m)/2026-06(1m) 起;继续积累,每月底重跑 scripts/ 验证。
- ST 判定用当前名称,历史 ST 切换日有少量误差;+8% 触发天然排除当日 ST(5% 限幅摸不到)。
- 日线为不复权价,除息日附近 MA/涨幅有跳变噪声(短线影响小)。
- 进场价=下一分钟开盘,未建模排队成交风险(触发后秒封的票可能买不进)。

## 过滤器格式速查(2026-08-22 按用户模板风格整理)

### 盘前选股池(昨日收盘数据)
```
主板
非ST
昨日未涨停
昨日涨幅 0% ~ +5%
昨日最低价在 20 日线上方
10 日线在 20 日线上方
距 20 日线 0% ~ +12%
前 5 日涨幅 0% ~ +15%
昨日换手率 < 8%
[加分] 前十日内出现过连板(弱转强, 晋级率 21.4% vs 16.0%)
```

### 今日市场闸门(昨日市场统计, 不过线就不做)
```
昨日主板涨幅 >= 5% 个股占比 < 12%
昨日炸板数 <= 60
昨日连板家数 <= 30
[加分] 昨日市场最高连板 >= 5 板
```

### 今日盘中买入(对照今日涨幅)
```
涨幅首次触及 +8%(价格 = 昨收 × 1.08)
且该 1 分钟 K 线收盘仍 >= +8%(收住, 不是单分钟脉冲)
激进: 下一分钟开盘直接买
稳健: 连续 3 根 1 分钟 K 线收 >= +8% 后再买(封板率 +5~9pt)
时段: 09:31~09:45 最强; 10:00~11:30 同样有效; 下午触发降级
```

### 卖出(吃溢价)
```
当日未封板 → 次日开盘必走(平均 -4.25%)
封板 → 次日不快速封二板就走, 开盘卖优于收盘卖
连板 → 持有到断板日卖(3板+ D+3 均 +27%)
```

### 模板条件实测备注
- 「昨日最低价在 20 日线上方」与「收盘在 20 日线上方」实测基本等价(晋级率 19.9% vs 19.6%),采用更严的昨低口径。
- 「昨日振幅 < 8%」方向反了: 振幅 >8% 的首板晋级率更高(8~12%→19.3%, >12%→24.6% vs <3%→17.2%),不采用。
- 「前十日出现过连板」有效但作为加分项, 不做硬条件(硬条件后高连板率 ge5 反降至 0.84% vs 基准 1.4%)。
- 池子日常 100~600 只, 极端行情日自动空仓(大涨日多数票涨超 5% 小阳上限)。
- 2026-08-21 实例: 池 242 只; 情绪 最高板3/炸板15/连板9/广度3.7% —— 闸门通过但无高度龙, 降级观察。
