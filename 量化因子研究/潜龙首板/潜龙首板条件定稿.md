## 一、策略逻辑

首板只有两种主力意图:**想连续拉升** 和 **想拉升出货**。判别不靠猜,靠底盘结构:
急着拉的主力 = 建仓短(≤10 天) + 前期安静(60 日无涨停或小阳慢建) + 首板不爆量;
想出货的主力 = 建仓过久(多头排列 >12 天) + 回锅贴脸(刚涨停断板没深跌又拉) + 首板爆量。

**A|B 分类的本质:底盘决定同一根 K 线的含义。**
同一天大跌 6%,长在空头排列底盘(A 类)上是"反抽失败的前兆"(连板率掉到 4.2%),
长在小阳建仓底盘(B 类)上只是"洗盘中的一次深蹲"(连板率 12.3% 引擎照转)——
这就是 D-1 涨幅带只挂 A 不挂 B 的原因(完整验证见 4.3)。

## 二、规则全集(死规则,与 contracts.py 对齐)

**盘前池(T-1 收盘后筛,月均 ~115 只触发口径):**

```
1. 主板  2. 非ST  3. 非退市
4. 底盘形态,二选一:
   A. 全新急建仓: 近 60 日涨停次数 = 0  且  多头排列(收>MA5>MA10>MA20)持续 ≤ 10 天
                  且  昨日涨幅 > -6% 且 近5日(T-5~T-1)单日涨幅均 < +7%
                  ← v6.1 加单日带(4.3);v6.2 把上界扩成 5 日窗口(4.6,蕴含昨日<+7,单日条目随之并入)
   B. 小阳建仓:   近 10 日阳线 ≥ 7 根  且  近 10 日涨幅 < 15%  且  近 20 日涨停次数 = 0
```

出货死规则不用另写:多头 >12 天 / 回锅贴脸的票天然不满足 A|B。

**盘中买入(全部死规则):**

```
5.  只做 09:30 ~ 11:30,午后一律不做
6.  高开 ≥ +8% 不做
7.  触发:涨幅首次触及 +8%(触发价 = 昨收 × 1.08)
8.  确认:该 1 分钟 K 线收盘仍 ≥ +8%;且当时累计量 ÷ 前5日均量 < 1.0(不爆量)
9.  进场:下一分钟开盘价买入(含 0.5% 滑点)
10. 同日多信号:小阳建仓(B 类)优先
```

量比是首板当天属性,同花顺表达不了,只能盘中执行,**不可省**(去掉后正月占比 95%→67%)。

**卖出:**

```
11. 当日未封板  → 次日开盘卖(未封板平均 -4.25%)
12. 封板未连板  → 次日开盘卖
13. 连板       → 持有,断板日开盘卖(利润几乎全部来自连板:2板D+1 +10.3%、3板+D+3 +27.4%)
```

**风控:** 14. 当月累计亏损达 -5% → 当月停止交易。

## 三、同花顺动态板块(手工跟单镜像)

⚠️ 动态板块分号 = "且"(AND),不支持跨括号 OR。池是 A∪B 并集,
**必须建两个板块**——合写一行会得到 A∩B 交集(仅 ~120 只 vs 并集 ~1,440 只)。

```
板块 A(全新急建仓):
主板;非ST;非退市;近60日涨停次数等于0;(均线空头排列 或 20日乖离率小于10%);昨日涨幅大于-6%;近5日单日涨幅均小于7%

板块 B(小阳建仓,约 190 只):
主板;非ST;非退市;近10日涨幅0到15%;近10日上涨天数大于等于7;近20日涨停次数等于0
```

三处近似(产品代码用精确条件,无此问题):
- 「多头排列≤10天」无原生字段 → 用「均线空头排列 或 20日乖离率<10%」。
  真实语义是"排除建仓过久":当前不在多头排列(趋势龄 0,空头排列是最大子集——与
  "多头≤10天"不矛盾)或刚起 1~10 天;镜像接住研究 A 池 85%、误纳仅 7 笔,量化见 4.4。
- 「近10日阳线≥7根」→「近10日上涨天数≥7」。
- 「近5日单日涨幅均小于7%」问财可能解析成累计涨幅——实测板块数对不上时改试
  「近5日每日涨幅小于7%」(v6.2 新增条目,待实测)。

问财实测注意:先试"多头排列持续天数小于等于10",能识别就用精确串替换 A 串括号段;
输入必须写"乖离率",写成"乖背离率"会被解析成背离类信号(2026-08-24 实测踩坑)。
