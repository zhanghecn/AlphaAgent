# 潜龙首板 · 打板条件定稿(v6.1,2026-08-24)

> **定位**:本文是潜龙首板策略的唯一规则事实源,与 `alphaagent/server/services/qianlong/contracts.py`
> 同源(版本 qianlong-v6.1)。结构:一~三节是**要执行什么**,四节是**为什么这样定**(证据库),五节是风险。
> 数据底座:主板非 ST,2023-01~2026-08;首板封住样本 30,945 只、+8% 触发 76,604 次、
> 分钟级 1m/5m 全市场(2026-04 起)。双段验证:2023-01~2025-06 训练 / 2025-07~2026-08 验证。
> 复跑脚本 `scripts/`(底盘 fb_chassis*、≥3板 fb_tall_*、镜像 fb_ths_leak.py、好差对比 fb_winner_loser.py)。

## 一、策略逻辑

首板只有两种主力意图:**想连续拉升** 和 **想拉升出货**。判别不靠猜,靠底盘结构:
急着拉的主力 = 建仓短(≤10 天) + 前期安静(60 日无涨停或小阳慢建) + 首板不爆量;
想出货的主力 = 建仓过久(多头排列 >12 天) + 回锅贴脸(刚涨停断板没深跌又拉) + 首板爆量。

**A|B 分类的本质:底盘决定同一根 K 线的含义。**
同一天大跌 6%,长在空头排列底盘(A 类)上是"反抽失败的前兆"(连板率掉到 4.2%),
长在小阳建仓底盘(B 类)上只是"洗盘中的一次深蹲"(连板率 12.3% 引擎照转)——
这就是 D-1 涨幅带只挂 A 不挂 B 的原因(完整验证见 4.3)。

## 二、规则全集(死规则,与 contracts.py 对齐)

**盘前池(T-1 收盘后筛,月均 ~115 只触发口径):**

```
1. 主板  2. 非ST  3. 非退市
4. 底盘形态,二选一:
   A. 全新急建仓: 近 60 日涨停次数 = 0  且  多头排列(收>MA5>MA10>MA20)持续 ≤ 10 天
                  且  昨日涨幅 ∈ (-6%, +7%)        ← v6.1 新增,依据见 4.3
   B. 小阳建仓:   近 10 日阳线 ≥ 7 根  且  近 10 日涨幅 < 15%  且  近 20 日涨停次数 = 0
```

出货死规则不用另写:多头 >12 天 / 回锅贴脸的票天然不满足 A|B。

**盘中买入(全部死规则):**

```
5.  只做 09:30 ~ 11:30,午后一律不做
6.  高开 ≥ +8% 不做
7.  触发:涨幅首次触及 +8%(触发价 = 昨收 × 1.08)
8.  确认:该 1 分钟 K 线收盘仍 ≥ +8%;且当时累计量 ÷ 前5日均量 < 1.0(不爆量)
9.  进场:下一分钟开盘价买入(含 0.5% 滑点)
10. 同日多信号:小阳建仓(B 类)优先
```

量比是首板当天属性,同花顺表达不了,只能盘中执行,**不可省**(去掉后正月占比 95%→67%)。

**卖出:**

```
11. 当日未封板  → 次日开盘卖(未封板平均 -4.25%)
12. 封板未连板  → 次日开盘卖
13. 连板       → 持有,断板日开盘卖(利润几乎全部来自连板:2板D+1 +10.3%、3板+D+3 +27.4%)
```

**风控:** 14. 当月累计亏损达 -5% → 当月停止交易。

## 三、同花顺动态板块(手工跟单镜像)

⚠️ 动态板块分号 = "且"(AND),不支持跨括号 OR。池是 A∪B 并集,
**必须建两个板块**——合写一行会得到 A∩B 交集(仅 ~120 只 vs 并集 ~1,440 只)。

```
板块 A(全新急建仓,约 1,380 只):
主板;非ST;非退市;近60日涨停次数等于0;(均线空头排列 或 20日乖离率小于10%);昨日涨幅大于-6%且小于7%

板块 B(小阳建仓,约 190 只):
主板;非ST;非退市;近10日涨幅0到15%;近10日上涨天数大于等于7;近20日涨停次数等于0
```

两处近似(产品代码用精确条件,无此问题):
- 「多头排列≤10天」无原生字段 → 用「均线空头排列 或 20日乖离率<10%」。
  真实语义是"排除建仓过久":当前不在多头排列(趋势龄 0,空头排列是最大子集——与
  "多头≤10天"不矛盾)或刚起 1~10 天;镜像接住研究 A 池 85%、误纳仅 7 笔,量化见 4.4。
- 「近10日阳线≥7根」→「近10日上涨天数≥7」。

问财实测注意:先试"多头排列持续天数小于等于10",能识别就用精确串替换 A 串括号段;
输入必须写"乖离率",写成"乖背离率"会被解析成背离类信号(2026-08-24 实测踩坑)。

### 4.2 底盘结构(出货死规则的原始证据)

| 规则 | 定义 | 证据 |
|---|---|---|
| 建仓过久不做 | 连续多头排列 >12 天 | 好票率 4.3%(基线 5.5%)、闷杀率 19.9%(基线 9.4%);≥15 天好票率 0%(n=90);甜区 4~12 天 7.1~8.3% |

### 4.3 D-1 涨幅带(v6.1 核心,fb_winner_loser.py 2026-08-24)

好票 W = 连板或 D+1≥+5%(965 笔 18.8%、+13.86);差票 L = 炸板且 D+1<0(2,068 笔 40.2%、-3.01)。
14 特征 × 全切点扫描 + 双特征交叉:**全池无负期望带,无损硬过滤空间为零**
(每杀 1% 差票必误伤 ~0.4% 好票);唯一例外 = A 类 D-1 涨幅两端。

每 1% 细切:悬崖在 +7~8(均 +0.98、差票率 52.6%);≥+8 唯一负档(均 -0.15、差票率 64.3%、

回升 10% 属半熄火,剔除是取舍)。语义:昨天 +7% 今天又冲板 = 两天 18%+ 过热接力出货形态。

## 五、风险与口径声明

- 量比日线口径含前视,实盘用触及量比近似,收益预期按分钟口径(+0.60)打折,两级不混用。
- 2026-06 是全口径共同最差月(市场连板转换率崩到 13.6%),本池 -0.24~+0.39%,属可接受浅亏。
- 日线未复权:|隔夜缺口|>11% 剔除(差票榜曾混入 -21.8% 伪暴跌)。
- 验证段 14/14 全正但单笔均收约为训练段 6 成;仓位按近 3 个月实盘动态调。
- 同花顺两处近似待问财实测回填校准(见第三节)。
- 版本沿革:v4(市值/价门槛)→v6 纯底盘(2026-08-23,证伪代理变量)→**v6.1 加 D-1 带(2026-08-24)**;
  任何阈值变更必须升 QIANLONG_RULES_VERSION 并触发回测重算。
