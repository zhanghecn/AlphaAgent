# 潜龙首板 · 打板条件定稿(v6 纯底盘版,2026-08-23)

> 池条件全部是底盘形态条件,不含市值/价门槛(代理变量已证伪:纯底盘池内加市值<50亿
> 单笔收益反从 +2.18 拖到 +1.51)。
> 数据底座:主板非 ST 首板封住样本 30,945 只 + +8% 触发样本 76,604 次(2023-01~2026-08);
> 分钟级 1m/5m 全市场(2026-04 起)。双段验证(2023-01~2025-06 训练 / 2025-07~2026-08 验证)。
> 复跑脚本 `scripts/`(fb_chassis.py / fb_chassis2.py / fb_chassis_pool.py / fb_v5_final.py / fb_tall_* 系列)。

---

## 一、核心逻辑(为什么这么筛)

首板只有两种主力意图:**想连续拉升** 和 **想拉升出货**。判别不靠猜,靠底盘结构:

- **主力急着连续拉升**的票:建仓时间短(刚启动 ≤10 天)、前期没反复炒过(近 60 日无涨停,
  或是连续小阳慢建仓)、首板当天不爆量(筹码锁定,没人借板出货)。
- **主力想出货**的票:建仓过久(多头排列持续超过 12 天,趋势已老)、回锅贴脸(前几天刚涨停
  断板、没深跌又拉涨停)、首板当天爆量(分歧巨大,有人借板砸盘)。

一句话:**首板前安静是所有首板票的共同背景(好票差票都安静),分胜负的是"趋势年龄+
涨停史形态+首板当天量能"。**

## 二、盘前选股池(每日收盘后筛)

```
1. 主板  2. 非ST  3. 非退市
4. 底盘形态,二选一:
   A. 全新急建仓: 近 60 日涨停次数 = 0  且  多头排列(收>MA5>MA10>MA20)持续 ≤ 10 天
   B. 小阳建仓:   近 10 日阳线 ≥ 7 根  且  近 10 日涨幅 < 15%  且  近 20 日涨停次数 = 0
```

月均 ~115 只(触发口径)。出货死规则已含在 A|B 的定义里:
多头排列 >12 天 / 回锅贴脸的票天然不满足 A|B,无需另写。

同花顺动态板块条件串(两处近似,待问财实测校准)。

⚠️ 同花顺动态板块的分号 = "且"(AND),不支持跨括号 OR——v6 池是 A∪B 并集,
**必须建两个动态板块,合并即全池**(合写一行会得到 A∩B 交集,仅 ~120 只 vs 并集 ~1,400 只):

板块 A(全新急建仓,约 1,400 只):
```
主板;非ST;非退市;近60日涨停次数等于0;(均线空头排列 或 20日乖离率小于15%)
```
板块 B(小阳建仓,约 190 只):
```
主板;非ST;非退市;近10日涨幅0到15%;近10日上涨天数大于等于7;近20日涨停次数等于0
```
⚠️ "多头排列≤10天"无原生字段,用"均线空头排列 或 20日乖离率<15%"近似;
"近10日阳线≥7根"用"近10日上涨天数≥7"近似。问财实测时先问一句
"多头排列持续天数小于等于10",若能识别,A 串括号段直接换成精确条件。

**镜像近似逻辑与漏网量化**(fb_ths_leak.py,2026-08-23,研究口径 4,501 笔 A 池):
"多头排列≤10天"的真实语义是"排除建仓过久(多头>10天)"——即趋势龄 0 天
(当前根本不在多头排列,**空头排列是其中最大子集**,与"多头≤10天"不矛盾)
或刚起 1~10 天。同花顺没有"持续天数"字段,用"空头排列"接趋势龄 0 的大头、
"乖离率<15%"接刚起没跑远的。量化结果:

| 分组 | 笔数 | 均收 | 胜率 | ≥3板率 | 结论 |
|---|---|---|---|---|---|
| A 池被镜像接住 | 3,810+344=4,154(92%) | +2.07/+2.37 | 57.7% | 2.7~4.4% | 质量无损 |
| A 池被镜像漏掉(乖离10版) | 691(15%) | +1.82 | 50.5% | 3.0% | 放宽到15%后大部分接回 |
| 其中 趋势龄0天但涨急 | 255 | +0.37(验段 -1.11) | 39.6% | 2.4% | **漏了反而好,毒票** |
| 乖离放宽15%的误纳(多头>10天) | 17 | +0.28 | 41.2% | 0% | 代价极小(0.5%) |
| B 池被"上涨天数≥7"接住/漏掉 | 522 / 480 | +3.75 / +3.69 | ~60% | 4.6~5.9% | 对称互漏、质量相同,不用改 |

注:产品池由本系统代码按精确条件计算,不存在镜像漏网;同花顺两板块仅是
手工跟单用的镜像。漏网的池外触发票每天在实时页下方"已封板首板复盘对照"可见。

## 三、盘中买入(死规则)

```
5. 只做 09:30~11:30,午后一律不做
6. 高开 ≥ +8% 不做
7. 触发:涨幅首次触及 +8%(价 = 昨收 × 1.08)
8. 确认:该 1 分钟 K 线收住 ≥ +8%;且触及时刻累计量 ÷ 前5日均量 < 1.0(不爆量)
9. 进场:下一分钟开盘价买入(研究口径含 0.5% 滑点)
10. 同日多信号:小阳建仓形态(B 类)优先
```

量比是首板当天属性,同花顺表达不了,只能盘中执行,**不可省**(纯盘前池正月占比掉到 67%)。

## 四、卖出(死规则)

```
11. 当日未封板 → 次日开盘卖
12. 封板但未连板 → 次日开盘卖
13. 连板 → 持有,断板日开盘卖
```

## 五、出货死规则(池条件 4 的原始形态与证据)

| 死规则 | 定义 | 证据 |
|---|---|---|
| R1 建仓过久不做 | 连续多头排列(收>MA5>MA10>MA20)>12 天 | 好票率 4.3%、闷杀率 19.9%(基线 5.5%/9.4%);≥15天好票率 0%(n=90);甜区 4~12 天好票率 7.1~8.3% |
| R2 回锅贴脸不做 | 前 2~12 日刚涨停过且期间最深回撤 >-5%(没洗干净) | 全期均 +0.21、正月占比 42%、≥3板率 2.04%;其中"涨停后几乎没回调又涨停"闷杀率 35%,全场最毒 |
| (保护性事实) | 涨停后洗盘越深越安全 | 深回>20% 闷杀率仅 9.2%,浅回 0~5% 为 13.8%,单调 |

## 七、已证伪/已删除清单(不要加回来)

- **市值/价门槛**:无底盘条件时有 lift(市值<50亿好票率 7.2% vs >300亿 3.2%),但纯底盘池内
  加市值<50 单笔收益反从 +2.18 拖到 +1.51。市值/价只是"拉得动"的代理,底盘接管后多余。**删。**
- **昨涨 0~5% 收阳**:好票只有 45.1% 落入,-5~+5% 区间好票率全平(5.4~6.6%),错杀一半好票
  (神剑股份首板前一日 -3.3%、传智教育 -2.3%、鲁信创投 -10%)。**删。**
- **昨日最低价>MA20 / 换手<8% / 距MA20≤12%(作独立条件)**:被底盘条件接管,删。
- **"低位首板溢价"直觉**:深度低位(60日区间位置<0.3)好票率 4.2~4.5%,全场最低;0.7~0.9 最佳 8.2%。
- **"深洗后再起"作入选形态**:正月仅 88%、均收+0.93,并入即稀释——回锅肉与真洗盘日线量价分不开。
- **前 N 日有无涨停当筛选**:无判别力(差票同样安静);只作形态细分用(回锅/洗盘,R2)。
- **多头排列作加入条件**:正月占比降到 46%(月度方差暴增),只当排除条件(>12天不做)。
- **小阳建仓作唯一硬条件**:正月占比降到 73%;作 B 类入选或盘中优先标记。
- **T+1 接力买入**:全部变体为负(裸接力 -0.35%/正月18%),负选择结构。
- **尾盘确认买点**:可成交的都是没封死的弱票(-0.91%)。
- **trailing 封板率闸门**:越紧越差(热后必凉,反向指标)。

## 八、风险声明

- 量比条件日线口径含前视(收盘才定型),实盘必须用盘中触及量比近似,收益预期按分钟口径打折。
- 2026-06 是全口径共同的最差月(市场连板转换率崩到 13.6%),任何首板策略都躲不掉;
  本池当月 -0.24~+0.39%(口径不同),属于可接受浅亏。
- 除权未复权数据:|隔夜缺口|>11% 必须剔除(差票榜曾混入 -21.8% 伪暴跌)。
- 验证段(近 14 个月)虽 14/14 全正,但单笔均收约为训练段 6 成;仓位按近 3 个月实盘动态调。
- 同花顺条件串有两处近似(多头排列天数/阳线天数),问财实测后必须回填校准。
