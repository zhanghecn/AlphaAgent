# 高位接力打板（二接三 / 三接四）· 研究需求

（2026-09-19 立项。最终规则见 `高位接力规则.md`，研究过程与依据见 `高位接力研究.md`。）

## 一、研究目标（主人原话）

昨日恰好 N 连板（N=2/3）的票，今天冲第 N+1 板时打板买入（涨停价、一字板买不进排除），
研究什么情况下二接三 / 三接四接力更好。只做二接三、三接四，四接五不做。

## 二、口径定义（主人拍板）

1. **事件**：昨日收盘恰好 2 连板（二接三）或 3 连板（三接四），当日盘中碰到涨停价 →
   按涨停价买入；一字板（全天没打开）买不进，排除；T 字（一字开盘盘中打开）可以买。
2. **阴阳** = 首板前一天（地基日）K线阴阳：收盘 ≥ 开盘 = 阳，否则 = 阴。
3. **分组框架** = 二接三 / 三接四 × 地基阴阳 = 四组；组内条件增减不动框架、不跨组复用。
4. **前置板不硬排除**：首板 ~ 买入前一日逐板标注板型（一字 / 下影线 / 换手实体阳）
   + 开盘涨幅 + 换手 + 开口段数，研究什么接力链更稳妥。
5. **竞价开盘 1~n 逐板标注**（9:25 定型，合法可用），与板型链相辅相成。
6. **炸板次数 1~n 逐板记录**（买入板另记买入后被打开次数）。
7. **所有统计按月切分**（每月龙头不一样、环境可能也有区别），
   验收 = 分年全正 + 不靠个别月份。

## 三、判定与收益口径

- 坏票 = 买入后第二天收盘低于买价（炸板但第二天涨回来的算好票）。
- 收益主算法 = 涨停价买入，持有到首次不再涨停日收盘卖出，15 个交易日兜底。
- 数据末端还没走到卖出日的票标「未完」，不进收益统计。
- 股票范围：主板非 ST 非退（按当前名称）；上市前 5 个交易日不参与。
- 涨停判定 = 不复权昨收 × 1.10 四舍五入到分。

## 四、铁律：无未来函数

- 入场条件只用买入前可知的信息：昨天及以前的静态信息 + 竞价（9:25 定型）+ 昨日涨停家数。
- **禁止用买入当天的量比 / 换手率**（收盘才定型、盘中动态变化，实际根本无法用）。
- 当天走势类字段（最深回落、开口段数等）只用于卖出纪律，不进买入条件。

## 五、验证要求（防过拟合）

- 阈值晃动测试：边界 ±1~2，刀口上的弃用。
- 五道稳健性检验：搜索级零假设 / 单格置换 / bootstrap / 去最好 3 笔 / 留一年。
- 案例门禁：独立代码路径重算抽样票全部字段。
- 好票坏票对比必须看 1~n 全过程、全部板型链家族、全部特征，不能只看聚合统计。
- 条件必须联调（组合看），不能单维下结论。

## 六、产品化要求

- 好差票验证月度文件：每票标方案点归属，未命中写明不符合在哪个条件。
- 最终因子方案：按方案合计口径、按月列举、区分单笔平均 vs 一年总收益。
- 问财条件句（同花顺动态板块）。
- 语言用正常中文，禁用研究黑话。
