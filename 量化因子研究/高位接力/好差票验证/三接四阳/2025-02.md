# 高位接力 · 三接四阳 · 2025-02 · 好票坏票清单（方案点已标记）

本月触发 15 笔 | 坏票 7（炸板没收回 4 + 封住次日跌 3） | 好票 8（继续连板 5） | 坏票率 47% | **命中 B3（二波贴线）2笔/胜率50%/+9.11**

**本组方案点（因子方案v1.3，买入前可知信息，命中才出手）**
- **A1 修复启动（出手级）**：地基距60日新高8~15% × 均线不整齐 × 60日内首次连板
- **B3 二波贴线（观察级）**：60日内有过≥2连板（二波） × 地基收盘距10日线不到5%（贴线或下方）
- 「—」= 未命中本组方案点，方案不出手
- 首刻列 = 开盘15分钟内首次触板（09:30~09:45）才算出手；非首刻=放弃；无数据=2024-08-15前无分钟存档

**判定标准**
- 买入 = 盘中碰到涨停价按涨停价买；一字板（全天没打开）买不进，已剔除
- 坏票 = 买入后第二天收盘低于买价（炸板但第二天涨回来的算好票）
- 持有到断板 = 涨停价买入，首次不再涨停的那天收盘卖出，15个交易日兜底

**列说明**
- 链 = 首板→买入前一天各板的「板型+开盘涨幅%」；板型分 一字 / 实体（下影<0.3%）/ 下影
- 地基 = 首板前一天阴阳和涨跌幅；位置 = 首板前一天收盘距60日新高%；均线 = 首板前一天5/10/20/30日线排列（+=短线在上）
- MA10% = 地基日收盘距10日线%；反包 = 首板前最近的板「断几天·前几板」（无板=60日内没有过涨停）
- 前波 = 近60天内前一波连板最高几板；环境 = 前一天全市场涨停家数
- 不符合在哪 = 未命中票对本组方案点的逐条判定，只列不满足的条件；命中票此列为空
- 月日序 = 买入日是当月第几个交易日；周 = 表内按当月第几个自然周（周一起算）分块
