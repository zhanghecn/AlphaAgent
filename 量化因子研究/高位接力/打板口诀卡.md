## 术语说明

（口诀里的"换手"= 二板当天换手率，打板前一晚收盘后就能查到；
四板口诀里的换手 = 三板当天换手率；"前20日" = 首板前20日涨幅；"今开" = 买入当天竞价开盘涨幅，9:25 出来后对照）

**换手心法**：二接三看二板换手——阳组锁着的板要小(贴零<12/一字<5)，阴组要活(≥5)；
三接四改看三板换手，阴阳不分——非一字 10~20最甜，一字系(二板或三板一字)锁仓天然低换手、3~5即可但今开须6~9.5，<5非一字没人气是毒，20+对倒出货不收；**一板换手永远不用看**。

## 打板速查树（只问一句：二板开在哪个档？）

```
二板贴零(<1)    → 阳打:今开6~9.5,换手锁(<12)           【双平贴零 69%】
今开<3         → 弱开系两种地基:                       【弱开系 82%】
                  一板低开=捡尸(二板贴地<0或承接2~3,今开须<0)
                  一板强开≥7=冒泡洗盘(二板3~7,阴阳都打)
二板强开(7~8.5) → 今开6~9.5打(阴),一板低开更好;一字开盘不算 【冒泡转强 82%】
                   或今开温3~5(要一板≥7+换手≥5,阴)      【强转弱 100%】
二板一字(≥9.5)  → 阳打:今开7~8.5,一板弱换手<5           【一字转强 67%】
─ 打四板(三接四) ─────────────────────────────
三板换手10~20    → 今开5~9.5,直接打(不分阴阳)            【四板便捷 71%】
                   一字系换手3~5即可,今开须6~9.5
四板捡漏两条     → 阳:三板强开5~7今天低开(<0)低吸         【四板捡漏 79%】
                   阴:二板贴零(<1)今天温开3~6
```

**跨阴阳铁律**：贴零/一字是阳的地盘（阴组同链全毒）；温开/弱开是阴的地盘（阳组同链 20~57%）；
强开×今开6~9.5 阴主打(82%)阳边缘(50%)；只有弱开系的冒泡洗盘阴阳通吃。

**阳组背景检查**：首板前20日已涨 5~15%（半山腰）最毒 63笔 37%/-2.30，刚启动(0~5%)最甜 21笔 62%/+6.86；阴组无此规律。
**阳组回避**：二板1~3死段；二板8.5~9.5剧强全场最毒；三连加速(一板≥3→二板强开7+→今开6+)7笔 0%/-10.27 全灭——强开接力一板必须低/平(洗过)。

## 用法
