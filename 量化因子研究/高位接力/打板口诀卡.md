## 术语说明

（口诀里的"换手"= 二板当天换手率，打板前一晚收盘后就能查到；
四板口诀里的换手 = 三板当天换手率；"前20日" = 首板前20日涨幅；"今开" = 买入当天竞价开盘涨幅，9:25 出来后对照）

**换手心法**：二接三看二板换手——阳组锁着的板要小(贴零<12/一字<5)，阴组要活(≥5)；
三接四改看三板换手，阴阳不分——10~20最甜，<5没人气是毒；**一板换手永远不用看**。

## 打板速查树（只问一句：二板开在哪个档？）

```
二板贴零(<1)    → 阳打:今开6~9.5,换手锁(<12)           【双平贴零 69%】
二板高开(3~7)   → 等今天弱开(<3)再打,阴阳都行           【冒泡转弱 71%】
二板强开(7~8.5) → 今开6~9.5打(阴),一板低开最纯          【冒泡转强 82%】
                   或今开温3~5(要一板≥7+换手≥5,阴)      【强转弱 100%】
二板一字(≥9.5)  → 阳打:今开7~8.5,一板弱换手<5           【一字转强 65%】
另有全低链(阴)   → 今天也低开,顺手打小仓                【三低 71%】
─ 打四板(三接四) ─────────────────────────────
三板换手10~20    → 今开5~9.5,直接打(不分阴阳)            【四板便捷版 65%】
三板高开(5~7)    → 等今天低开,低吸                      【高开低吸 71%】
二板贴零+今开温   → 温开3~6,慢热票                      【贴零温开 85%】
```

**跨阴阳铁律**：贴零/一字是阳的地盘（阴组同链全毒）；温开/弱开是阴的地盘（阳组同链 20~57%）；
强开×今开6~9.5 阴主打(82%)阳边缘(50%)。

**阳组背景检查**：首板前20日已涨 5~15%（半山腰）最毒 63笔 37%/-2.30，刚启动(0~5%)最甜 21笔 62%/+6.86；阴组无此规律。
**阳组回避**：二板1~3死段；二板8.5~9.5剧强全场最毒；三连加速(一板≥3→二板强开7+→今开6+)7笔 0%/-10.27 全灭——强开接力一板必须低/平(洗过)。

## 用法

1. **收盘后**：筛出昨日 2 连板（打3板，看二板开盘档位+二板换手+前20日）或 3 连板（打4板，看三板换手/三板开盘）的主板非ST票，对照速查树标出明天的候选口诀
2. **次日 9:25**：竞价出来后对照该口诀的「今开」窗，命中→准备
3. **盘中**：打板类首次触涨停价按涨停价打；低吸类（高开低吸）按低开直接买入
4. **卖出**：炸板当天收盘走；封住拿到不再涨停那天收盘（15个交易日兜底）
5. **仓位**：轻仓一票一份；三低/阳组冒泡转弱这类弱口诀小仓顺手打
