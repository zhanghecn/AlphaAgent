# 高位接力打板（二接三 / 三接四）· 最终规则 v1.3（结论）

（需求见 `高位接力需求.md`，研究过程与依据见 `高位接力研究.md`。
2026-09-19 定稿；历史检验窗 2023-01 ~ 2026-09-04。
**图文讲解：每个方案点一张真实K线标注图，见 `高位接力规则图解.md`。**）

## 一、最终规则（大白话版）

**买什么——每天收盘后筛，只有五种票值得明天打板：**

| 名字 | 条件（数字已写明） | 买点 |
|---|---|---|
| **A1 修复启动**（三接四阳） | 昨天3连板；首板前一天是阳线，且当天收盘比近60日最高价低8~15%；最近60天没有过连板；均线是乱的（不是5>10>20>30整齐多头） | 今天打第4板 |
| **A2 老龙缩量**（三接四阴） | 昨天3连板；首板前一天是阴线；近120天有过3连板以上；二板换手率比首板低5个百分点以上 | 今天打第4板 |
| **B1 竞价确认**（二接三阴） | 昨天2连板；首板前一天是阴线；二板开盘涨6~9.5%；二板换手率只比首板多0~2个百分点 | 今天打第3板 |
| **B2 低开转强**（二接三阳） | 昨天2连板；首板前一天是阳线，当天收盘比60日最高价低2~9%；二板开盘跌（低开，涨幅<0%）；今天竞价开盘涨4~7% | 今天打第3板 |
| **B3 二波贴线**（三接四阳） | 昨天3连板；首板前一天是阳线，当天收盘在10日均线下方或上方不到5%；近60天有过一波2连板以上（孤立一个涨停不算） | 今天打第4板 |

记法：**A1=跌透首启动，A2=老龙缩量，B1=高开确认，B2=低开转强，B3=贴线二波。**

**什么时候买——只看早盘15分钟：**
9:30~9:45 第一次碰到涨停价 → 涨停价打板买入；9:45之后才摸板的不买；
下午2:30后摸板的一律不买；午后1~2点才首次摸板的阳地基不买、阴地基可放宽；
一字板（开盘就封死）买不进就不追。

**命中也不买（回避）：** 三接四阴竞价开盘涨幅<0%或≥9.5%的不买（最优区间是0~6%）；
首板前一天收盘距60日最高价不到3%的三接四阳不买；板型链是「实体→实体」（二接三阴）、
「实体→下影→下影」（三接四阴）、「一字→一字且竞价开盘涨≥9.5%」（二接三阳）的不买。
（完整回避8条见第二节末。）

**怎么卖——纪律只有两条：**
买入当天没封住（炸板）→ 当天收盘卖掉认亏，不隔夜赌；
封住了 → 拿着不动，哪天收盘不再涨停了那天收盘卖，最多拿15天。

**仓位：** 轻仓分仓，一票一份，同月可能多票并行。收益靠少数连板妖股撑着，
大多数票赚小钱或微亏——靠的是不坏+偶尔大成。

**历史检验**（2023-01~2026-09-04，3328笔池子）：五点合计171笔、胜率69%、平均每笔+7.63、
四年分年全正；叠加早盘15分钟过滤后（2024-08起90笔）胜率76%、+8.86。
不挑就买是亏的（-1.33），所以**只打这五种，其余一概不碰**。

**毒格回避**（命中也不买）：三接四阴竞价开盘涨幅<0%或≥9.5%（最优区间0~6%）；
三接四阳首板前一天收盘距60日最高价不到3%；二接三阴链=实体→实体；三接四阴链=实体→下影；
二接三阳60日内无过连板前波、或竞价开盘涨幅不在4~7%；**二接三阳链=一字→一字且竞价开盘涨≥9.5%**

（板型强竞价弱=假强，16笔 12%/-9.4）；**三接四阴链=实体→下影→下影**
（实体首板后连续两根开口烂板，57笔 21%/-6.20，**四年全负** -4.35/-8.69/-3.26/-3.46）。

## 三、问财条件句（同花顺问财建五个动态板块；⚠️句子未经问财实盘解析验证，粘贴前先测）

**A1 板块（三接四阳·修复启动）**：
1. 主板，非ST
2. 截至昨日连续3天涨停
3. 4日前收盘价大于等于4日前开盘价（阳地基）
4. 4日前收盘价较60日最高价下跌8%到15%
5. 近63个交易日内涨停次数等于3（无前波的近似表达，会把带孤立单板的也排掉，偏严）
- 人工复核：4日前均线不整齐（排除全多头5>10>20>30，也排除一上一下的纠缠态）；
  问财表达不了「不整齐」，触发后看一眼K线均线。

**A2 板块（三接四阴·老龙缩量）**：
1. 主板，非ST
2. 截至昨日连续3天涨停
3. 4日前收盘价小于4日前开盘价（阴地基）
4. 近120日内连续涨停天数最大值大于等于3（老龙头）
5. 2日前换手率较3日前换手率下降超过5个百分点（二板缩量）
- 竞价过滤：竞价涨幅0%~9.5%才打（低开和顶格开是毒格）。

**B1 板块（二接三阴·竞价确认，观察级）**：
1. 主板，非ST
2. 近5日内连续涨停天数最大值等于2，且昨日涨停
3. 3日前收盘价小于3日前开盘价（阴地基）
4. 昨日开盘涨幅6%到9.5%
5. 昨日换手率较2日前换手率上升0到2个百分点

**B2 板块（二接三阳·低开转强，观察级）**：
1. 主板，非ST
2. 近5日内连续涨停天数最大值等于2，且昨日涨停
3. 3日前收盘价大于等于3日前开盘价（阳地基）
4. 3日前收盘价较60日最高价下跌2%到9%
5. 昨日开盘涨幅小于0%（二板低开洗盘）
6. 竞价涨幅4%到7%（进三竞价转强确认；竞价字段待问财实测，若无则用开盘后5分钟涨幅近似人工看）

**B3 板块（三接四阳·二波贴线，观察级，v1.3新增）**：
1. 主板，非ST
2. 截至昨日连续3天涨停
3. 4日前收盘价大于等于4日前开盘价（阳地基）
4. 近60个交易日内涨停次数大于等于5（当前3板之外前一波至少还有2个涨停的近似表达）
5. 4日前收盘价较4日前10日均线涨幅小于5%（地基贴10日线或在线下方；句式待问财实测，
   不行就人工看地基日K线是不是贴着10日线）
- 人工复核：前一波必须是「2连板以上」才算（孤立单板不算），问财表达不了前波形态，
  触发后翻一眼60日K线。

**问财注意事项**（沿用N型补涨经验）：比较句用「A较B下跌/上涨超过N%」的动词句式；
「连续N天涨停」原生支持，上限表达为「连续涨停天数最大值等于N」；
「较60日最高价下跌X%到Y%」的区间表达待实测，不行就拆两个板块并集。
