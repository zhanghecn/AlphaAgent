# 断板反包打板 · 研究需求

（2026-09-25 立项，同日三轮定稿。规则结论见 `反包规则.md`；执行计划见 `反包研究方向.md`。）

## 一、研究目标（主人原话）

「反包就是基于 2-3 或者 4-5 断板大概 1-3 天然后涨停反包。先归类 2板 3板 4板 5板的反包。
然后统计间隔多少天反包后胜率盈利 炸板率等等。」
「在分阴阳 反包。」「不排除4以上包括6 7 8 等」「只用 2 4 5+」

即：前一波连板（高度分段 2 / 4 / 5+，5+ 不设上限）→ 断板 1~3 天 → 反包日再次涨停，
研究反包日打板买入在什么情况下值得做，按跌幅阴阳分组管理。

## 二、口径定义

1. **事件结构**：前波恰好 N 连板 → 断板 g 天（g=1/2/3，每日收盘不涨停）→ 反包日盘中
   触及涨停价。末板日 = 前波第 N 板；断板期 = 末板次日 ~ 反包前一天；反包日 = 断板期后
   首个盘中触板的交易日。
2. **买入**：反包日盘中碰到涨停价按涨停价买入；一字板买不进，剔除；T 字可以买。
3. **分组框架（六组，终版）** = 高度段（2板 / 4板 / 5+板无上限，3板删除——四年皆弱）×
   **跌幅阴阳**（阴=反包前一天收盘低于前日收盘，阳=涨或平）。组内条件增减不动框架、
   不跨组复用。实体口径（N 型同款）已实测弃用：会被「低开高走假阳/假阴」搅浑。
4. **次分组** = 断板天数 1/2/3；断 4~5 天只作参考行。
5. **前波高度判定**：紧邻断板期之前的连板段高度；更早板史作标注维度，不硬排除。
6. **断板日定义**：收盘不涨停即断板日；盘中触板收盘未封的算断板日（标注「含炸板日」）；
   反包后再断再反包算新事件。
7. **股票范围**：主板非 ST 非退；上市前 5 个交易日不参与。
8. **涨停判定** = 不复权昨收 × 1.10 四舍五入到分（`+1e-9` 防浮点把 x.xx5 舍反）。
9. **数据范围**：事件 2023-01 起；日线 2022-06 起留回看窗口。

## 三、判定与收益口径（与高位接力一致）

- 坏票 = 买入后第二天收盘低于买价（炸板但第二天涨回来的算好票）。
- 收益主算法 = 涨停价买入，持有到首次不再涨停日收盘卖出，15 个交易日兜底；
  反包日炸板 = 当天收盘卖出。
- 炸板率 = 反包日触板收盘未封比例；胜率 = 好票率；连板率 = 反包封住后次日继续涨停比例。
- 未走到卖出日的标「未完」，不进收益统计。
- 所有统计按月切分，验收 = 分年全正 + 不靠个别月份。

## 四、铁律：无未来函数

- 入场条件只用反包日前可知信息：断板期及以前的静态信息 + 反包日竞价（9:25 定型）+
  昨日全市场涨停家数。
- 禁止用反包日当天的量比 / 换手率。
- 盘中走势字段只用于卖出纪律与事后归因。首刻口径仅 2024-08-15 后有分钟存档。

## 五、验证要求

- 阈值晃动 ±1~2，刀口上的弃用；五道稳健性检验；案例门禁独立重算。
- 好差票对比看断板期全过程全部字段家族；条件必须联调。
- Phase 0 已过三道（`汇总/对账记录.md`）。

## 六、产品化要求

- 好差票验证月度文件 `好差票验证/<组>/YYYY-MM.md`（六组），每票标方案点归属，
  未命中标「—」。
- 最终因子方案区分单笔平均 vs 一年总收益；问财条件句；正常中文不用黑话。
